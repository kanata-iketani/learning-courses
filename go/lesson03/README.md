# Lesson 03 数値と演算

Python入門編「数値と演算」に対応するレッスンです。Go の数値でつまずきやすいのは「int 同士の `/` は切り捨て」「`**` はない」「int と float64 は混ぜられない」の 3 点です。

## ch01 int と float64

Go の数値には主に `int`（整数型）と `float64`（64ビットの浮動小数点数型。Python の float 相当）があります。Python では `3 + 1.5` のように整数と小数を自由に混ぜられましたが、Go では int と float64 は混ぜられません。計算する前に `float64(x)` のような**型変換**（値を別の型に作り直すこと）でどちらかに揃えます。🟡 「型を揃えてから計算する」を理解しましょう。

Python ではこう書いた:

```python
print(3 + 1.5)  # 4.5
```

Go ではこう書く:

```go
n := 3
f := 1.5
fmt.Println(float64(n) + f) // 4.5
```

### `:=` について（先取り）

サンプルの `n := 3` は「変数 `n` を新しく作り、`3` を入れる」という意味です。型は右辺の値から自動で決まり、`3` なら int、`1.5` のように小数点があれば float64 になります。L01 の `var n int = 3` と同じ結果になる短い書き方で、L04 で詳しく学びます。

### サンプルを 1 行ずつ読む

- `n := 3` → 出力: なし ／ 説明: n は int
- `f := 1.5` → 出力: なし ／ 説明: f は float64
- `fmt.Println("n =", n)` → 出力: `n = 3`
- `fmt.Println("f =", f)` → 出力: `f = 1.5`
- `float64(n)+f` → 出力: `n + f = 4.5` ／ 説明: `float64(n)` で 3 を float64 の `3.0` に作り直してから足します。n 自体は int のままです
- `n+int(f)` → 出力: `n + int(f) = 4` ／ 説明: `int(f)` は小数部分を切り捨てて `1` にします（四捨五入ではありません）。3 + 1 で 4 です

`型名(値)` の形が型変換です。関数呼び出しと同じ見た目ですが、型の名前を使います。

### 混ぜたときのエラーの実物

`fmt.Println(n + f)` のコメントを外すと、次のコンパイルエラーになります。

```text
invalid operation: n + f (mismatched types int and float64)
```

「不正な演算: 型が合わない（int と float64）」という意味です。

### `float64` の 64 とは

値を 64 ビット（0/1 の桁が 64 個分）で表す、という大きさの指定です。`float32` もありますが、ふだんは float64 だけを使います。

## ch02 四則演算と %

`+ - * %` は Python と同じ感覚で使えます。最大の注意点は `/` です。Python の `/` は常に小数を返しましたが、Go の `/` は int 同士なら切り捨て（Python の `//` 相当）になります。小数の答えが欲しいときは float64 に変換してから割ります。`%` は割り算の余りで、これは Python と同じです。🔴 `7 / 2` が `3` になる感覚は、手が覚えるまで書いて慣れましょう。

Python ではこう書いた:

```python
print(7 / 2)   # 3.5
print(7 // 2)  # 3
```

Go ではこう書く:

```go
fmt.Println(7 / 2)                     // 3（int 同士は切り捨て）
fmt.Println(float64(7) / float64(2))   // 3.5
```

### 演算子の一覧と結果

- `7 + 2` → 結果: `9` ／ 意味: 足し算
- `7 - 2` → 結果: `5` ／ 意味: 引き算
- `7 * 2` → 結果: `14` ／ 意味: 掛け算（`×` ではなく `*`）
- `7 / 2` → 結果: `3` ／ 意味: int 同士の割り算。小数部分の `.5` が捨てられます
- `float64(7) / float64(2)` → 結果: `3.5` ／ 意味: float64 同士なら小数まで出ます
- `7 % 2` → 結果: `1` ／ 意味: 7 を 2 で割った余り（7 = 2×3 + 1）

`%` は「偶数か奇数か（2 で割った余りが 0 か 1 か）」「n 個ずつに分けた余り」を調べるときによく使います。

### サンプルの書き方について

`fmt.Println("7 / 2 =", 7/2)` の 1 つ目の引数は `"..."` で囲んだ文字列なので、中の `7 / 2 =` は計算されずにそのまま表示されます。2 つ目の `7/2` は `"` がないので計算され、結果の `3` が表示されます。gofmt は引数の中の演算子の両側の空白を詰めることがありますが、`7/2` と `7 / 2` の意味は同じです。

実行結果:

```text
7 + 2 = 9
7 - 2 = 5
7 * 2 = 14
7 / 2 = 3
7.0 / 2.0 = 3.5
7 % 2 = 1
```

### 負の数の割り算（Python と違う点）

Go の int の割り算は「0 の方向へ切り捨て」です。`-7 / 2` は Go では `-3`、Python の `-7 // 2` は `-4` です。余りも `-7 % 2` は Go で `-1`、Python で `1` になります。負の数を扱う問題では気を付けてください。

## ch03 math.Pow（** はない）

Go に累乗の演算子 `**` はありません。代わりに標準ライブラリの `math.Pow(x, y)` を使います。`math.Pow` は引数も戻り値も float64 なので、int で使いたいときは `int(math.Pow(2, 10))` のように変換します。2乗程度なら `x * x` と書くほうが Go らしいコードです。🟡 「** がない、math.Pow か掛け算で書く」を押さえましょう。

Python ではこう書いた:

```python
print(2 ** 10)  # 1024
```

Go ではこう書く:

```go
import "math"

fmt.Println(math.Pow(2, 10))      // 1024（float64）
fmt.Println(int(math.Pow(2, 10))) // 1024（int）
```

### 複数のパッケージを import する書き方

`fmt` と `math` の両方を使うときは、`import` の後ろに `( )` で囲んで 1 行に 1 つずつ並べます。

```go
import (
	"fmt"
	"math"
)
```

`import "fmt"` と `import "math"` を 2 行書いても同じ意味ですが、`( )` でまとめるのが Go の標準の形です。import したのに使わないパッケージがあるとコンパイルエラー（`"math" imported and not used`）になります。

### 戻り値とは

`math.Pow(2, 10)` は計算した結果の `1024` を呼び出し元に返します。この返ってくる値を**戻り値**と呼びます。`fmt.Println(math.Pow(2, 10))` は「Pow の戻り値を Println に渡して表示する」という 2 段階の処理です。

### サンプルの実行結果

- `math.Pow(2, 10)` → 出力: `1024` ／ 説明: 戻り値は float64 ですが、小数部分が 0 なので Println は `1024` と表示します
- `int(math.Pow(2, 10))` → 出力: `1024` ／ 説明: int に変換したもの。見た目は同じですが、int の変数と計算できるようになります
- `x * x`（x は 9） → 出力: `81` ／ 説明: 2 乗は掛け算で十分です
- `math.Sqrt(2)` → 出力: `1.4142135623730951` ／ 説明: 平方根（√2）

### `**` を書くとどうなるか

`2 ** 3` と書くと次のコンパイルエラーになります。Go は `*` を 2 つの別の記号と読むため、意味のわかりにくいメッセージになります。

```text
invalid operation: cannot indirect 3 (untyped int constant)
```

## ch04 演算子の優先順位

優先順位（複数の演算子が並んだときの計算順）は Python とほぼ同じで、`* / %` が `+ -` より先に計算され、括弧 `()` で順番を変えられます。Python と考え方は変わらないので、迷ったら括弧を付けて意図を明示するのが読みやすいコードのコツです。⚪ 「Python と同じ、迷ったら括弧」とだけ知っておけば十分です。

Python ではこう書いた:

```python
print((100 + 200) * 3)
```

Go ではこう書く:

```go
fmt.Println((100 + 200) * 3)
```

### サンプルの計算の順番

- `100 + 200*3` → 計算の順番: 先に `200*3 = 600`、次に `100 + 600` ／ 出力: `700`
- `(100+200)*3 == 900` → 計算の順番: 括弧の中 `300`、`300*3 = 900`、最後に `900 == 900` を比べる ／ 出力: `true`
- `(100 + 200) * 3` → 計算の順番: 括弧の中が先 ／ 出力: `900`
- `(500 + 300) / 2` → 計算の順番: `800 / 2` ／ 出力: `平均: 400`

`==` は「左と右が等しいか」を調べる比較の記号で、等しければ `true`（真）、違えば `false`（偽）になります（L11 で詳しく学びます）。算数の `+ - * /` は比較より先に計算されます。

### 同じ強さの演算子は左から

`* / %` どうし、`+ -` どうしは左から順に計算します。`100 / 10 * 2` は `(100 / 10) * 2 = 20` です。int の `/` は切り捨てなので、`(80 + 90 + 71) / 3` は `241 / 3 = 80`（小数部分は捨てられる）になる点も ch02 と同じです。
