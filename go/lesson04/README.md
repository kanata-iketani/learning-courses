# Lesson 04 変数

Python入門編「変数」に対応するレッスンです。Go の変数は型が固定で、宣言していない変数への代入はできず、使っていない変数が残っているだけでビルドエラーになります。

## ch01 var による宣言

Go で変数を作る基本形は `var 変数名 型 = 値` です。**宣言**（この名前の変数をこの型で使うとコンパイラに伝えること）が必須な点が Python との大きな違いです。初期値から型が明らかなときは `var name = "demo"` と型を省略できます。値を入れずに `var count int` と宣言すると、**ゼロ値**（型ごとの初期値。int は 0、string は ""）が入ります。🟡 「宣言してから使う」を理解しましょう。

Python ではこう書いた:

```python
name = "demo"
```

Go ではこう書く:

```go
var name string = "demo"
```

### 変数とは

**変数**は、値に名前を付けて覚えておく入れ物です。Go の変数は「名前」「型」「中身の値」の 3 つを持ち、型は一度決めたら変わりません。

### `var` の書き方 3 通り

- `var name string = "demo"` → 名前: name ／ 型: string（文字列） ／ 値: `"demo"`
- `var lang = "Go"` → 名前: lang ／ 型: string（`"Go"` が文字列なので自動で決まる） ／ 値: `"Go"`
- `var count int` → 名前: count ／ 型: int ／ 値: `0`（ゼロ値）

型を省略したとき、右辺が `"..."` なら string、`13` なら int、`1.5` なら float64 になります。

### ゼロ値の一覧

- `int`: `0`
- `float64`: `0`
- `string`: `""`（空文字列。Println で出すと何も表示されない）
- `bool`（L11 で学ぶ真偽の型）: `false`

Python で値を入れずに変数を使うと NameError でしたが、Go では宣言だけしておけばゼロ値が入っているので、そのまま使えます。

### サンプルの実行結果

```text
name: demo
age: 13
lang: Go
count: 0
```

### 宣言せずに使うと

`var` も `:=`（次の ch02）も使わずに `y = 3` と書くと、`undefined: y`（y は定義されていない）というコンパイルエラーになります。

## ch02 := による短縮宣言

関数の中では `name := "demo"` と書くだけで、宣言と代入を同時にできます。型は右辺から自動で決まります（型推論）。見た目は Python の代入とほぼ同じですが、`:=` は「新しい変数を作る」記号であり、作った変数の型はやはり固定です。実際の Go のコードでは var よりこちらが主流です。🔴 `:=` は今後全レッスンで使うので、手が覚えるまで書きましょう。

Python ではこう書いた:

```python
age = 20
```

Go ではこう書く:

```go
age := 20 // int と推論される
```

### `:=` の読み方

`:=` はコロンとイコールの 2 文字で 1 つの記号です。「左の名前で新しい変数を作り、右の値を入れる」と読みます。次の 2 行は同じ意味です。

```go
var age int = 13
age := 13
```

**型推論**とは、右辺の値を見てコンパイラが型を決めることです。`13` なら int、`158.3` なら float64、`"demo"` なら string になります。

### サンプルを 1 行ずつ読む

- `name := "demo"` → できる変数: name（string）
- `age := 13` → できる変数: age（int）
- `height := 158.3` → できる変数: height（float64）
- `fmt.Println(name, "は", age, "歳です")` → 出力: `demo は 13 歳です`
- `fmt.Println("身長:", height)` → 出力: `身長: 158.3`
- `x, y := 10, 20` → できる変数: x に 10、y に 20（どちらも int）
- `fmt.Println("x + y =", x+y)` → 出力: `x + y = 30`

`x, y := 10, 20` のように、左と右に同じ個数を並べると、左から順に対応して入ります。

### `:=` の制限

- **関数の中でしか使えません**。関数の外（`func main` の外側）で変数を作るときは `var` を使います
- **同じ名前で 2 回は使えません**。`x := 3` のあとにもう一度 `x := 4` と書くと `no new variables on left side of :=`（`:=` の左に新しい変数がない）というエラーになります。2 回目以降は次の ch03 の `=` を使います

## ch03 再代入と未使用変数エラー

一度作った変数に値を入れ直すときは `=` を使います（`:=` ではない点に注意）。型が固定なので、int の変数に文字列を再代入することはできません。もう 1 つ Python にない特徴として、宣言したのに一度も使わない変数はビルドエラーになります。「消し忘れの変数はバグのもと」という思想で、コンパイラが強制的に掃除させます。🟡 `:=` と `=` の使い分けを理屈で押さえましょう。

Python ではこう書いた:

```python
score = 80
score = "high"  # 型が変わっても平気
unused = 1      # 使わなくても何も起きない
```

Go ではこう書く:

```go
score := 80
score = 90        // 再代入は = （同じ int のみ）
// unused := 1    // 使わないとビルドエラー: declared and not used
```

### `:=` と `=` の使い分け

- `:=` → 意味: 新しい変数を作って値を入れる ／ 使う場面: その名前を初めて使うとき（1 回だけ）
- `=` → 意味: すでにある変数の中身を入れ替える ／ 使う場面: 2 回目以降

### `score = score + 5` の読み方

`=` は「右辺を計算して、その結果を左の変数に入れる」という命令で、数学の「等しい」ではありません。`score` が 95 のとき、右辺 `score + 5` は 100 になり、それが `score` に入ります。

同じことは `score += 5` とも書けます（Python と同じ）。`-=` `*=` `/=` もあります。

- `score = score + 5`: 100
- `score += 5`: 100
- `score -= 5`: 90

### サンプルの実行結果

```text
最初の score: 80
再代入後の score: 95
加点後の score: 100
```

### 未使用変数のエラーの実物

`unused := 1` のコメントを外すと、次のエラーで実行できなくなります。

```text
unused declared and not used
```

「unused は宣言されたが使われていない」という意味です（Go 1.22 の表示。新しいバージョンでは `declared and not used: unused` と語順が変わります）。使っていない変数は消すか、使うようにすれば直ります。
