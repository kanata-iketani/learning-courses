# Lesson 10 条件分岐

Python入門編「条件分岐」に対応するレッスンです。Go の `if` は条件に括弧を付けず、ブロックの `{}` を省略できません。`elif` は `else if` になり、`pass` の代わりは空ブロック `{}` です。

## ch01 if（条件に括弧なし・{} は必須）

Go の `if` は「条件が真のときだけ実行する」という意味は Python と同じですが、書き方が 2 点違います。第一に、条件を囲む括弧 `()` は書きません。第二に、ブロックはインデントではなく波括弧 `{}` で表し、処理が 1 行でも必ず `{}` を付けます。また Python の `pass`（何もしないことを示す文）に相当する語はなく、何もしないときは空ブロック `{}` を書きます。🔴 if は今後のすべてのコードで使うので、この形を手が覚えるまで書きましょう。

Python ではこう書いた:

```python
if x > 10:
    print("大きい")
```

Go ではこう書く:

```go
if x > 10 {
	fmt.Println("大きい")
}
```

### 用語の確認

- **条件**: `x > 10` のように、成り立つ（true）か成り立たない（false）かが決まる式です
- **真 / 偽**: 成り立つことを真（true）、成り立たないことを偽（false）と呼びます（L11 で詳しく学びます）
- **ブロック**: `{` から `}` までの、ひとまとまりの処理です

### 比較の記号

- `x > 10` → 意味: x は 10 より大きい ／ `x` が 42 のとき: true
- `x >= 80` → 意味: x は 80 以上 ／ `x` が 42 のとき: false
- `x < 10` → 意味: x は 10 より小さい ／ `x` が 42 のとき: false
- `x == 42` → 意味: x は 42 と等しい（`=` 1 つは代入なので 2 つ） ／ `x` が 42 のとき: true
- `x != 42` → 意味: x は 42 と等しくない ／ `x` が 42 のとき: false

### サンプルを 1 行ずつ読む（x は 42）

- `if x > 10 { ... }` → 条件の結果: 42 > 10 は true ／ 出力: `10より大きい`
- `if x%2 == 0 { ... }` → 条件の結果: 42 を 2 で割った余り（L03 ch02 の `%`）は 0。0 == 0 は true ／ 出力: `偶数`
- `if x > 100 { }` → 条件の結果: 42 > 100 は false。中は空なのでどちらでも何もしない ／ 出力: なし
- `fmt.Println("おわり")` → 条件の結果: if の外なので必ず実行 ／ 出力: `おわり`

`x%2 == 0` は、`%` が `==` より先に計算されます（L03 ch04）。

実行結果:

```text
10より大きい
偶数
おわり
```

## ch02 else if と else（elif の代わり）

複数の条件で分岐するとき、Python の `elif` は Go では `else if` と 2 語で書きます。`else` はそのままです。注意点は書く位置で、`else if` も `else` も直前の閉じ波括弧 `}` と同じ行に書きます。行を分けるとコンパイルエラーになります。条件に括弧を付けない点、`{}` を省略できない点は if と同じです。🔴 分岐は頻出なので、`} else if 条件 {` のつながりごと手が覚えるまで書きましょう。

Python ではこう書いた:

```python
if score >= 80:
    print("A")
elif score >= 60:
    print("B")
else:
    print("C")
```

Go ではこう書く:

```go
if score >= 80 {
	fmt.Println("A")
} else if score >= 60 {
	fmt.Println("B")
} else {
	fmt.Println("C")
}
```

### 上から順に調べ、最初に当たった 1 つだけを実行する

score が 72 のとき:

- 1 → 条件: `score >= 80` ／ 結果: false ／ 動き: 次へ
- 2 → 条件: `score >= 60` ／ 結果: true ／ 動き: `B` を出力し、残りは調べずに if 全体を終える
- 3 → 条件: `else` ／ 結果: （調べない） ／ 動き: どれにも当たらなかったときだけ実行

temp が 31 のときは 1 つ目の `temp >= 30` が true なので `暑い` だけが出ます。31 は `temp >= 15` も満たしますが、先に当たったものだけが実行されます。そのため、範囲の狭い条件（大きい数の `>=`）を先に書きます。

実行結果:

```text
B
暑い
```

### `}` と `else` を別の行にするとエラーになる理由

Go は、行が `}` で終わるとそこで文が終わったと見なします（行末に見えない `;` を自動で補う規則）。そのため次の行の `else` が「どの if にも続かない else」になり、エラーになります。

```text
syntax error: unexpected else, expected }
```

`} else {` と 1 行に書けば、`}` の後ろにまだ続きがあるので文は終わりません。

## ch03 条件の前の1文（if v := f(); v > 0）

Go の `if` は、条件の前にセミコロン `;` で区切って 1 文を書けます。「値を作って、すぐ判定する」ための形で、ここで宣言した変数はこの if と else の中だけで有効です。Python に対応する構文はなく、代入と if の 2 行に分けて書いていました。この形は後に学ぶエラー処理 `if err := ...; err != nil {` で多用される、Go らしい書き方です。🟡 まずは形と、変数が if の外では使えないという理屈を理解しましょう。

Python ではこう書いた:

```python
l = len(word)
if l >= 5:
    print("長い単語")
```

Go ではこう書く:

```go
if l := len(word); l >= 5 {
	fmt.Println("長い単語")
}
```

### `if 文; 条件 {` を分解する

```go
if l := len(word); l >= 5 {
```

- `l := len(word)`: 先に実行される 1 文。変数 l を作り、word のバイト数（L05 ch02）を入れる
- `;`: 「ここで 1 文が終わり」という区切り
- `l >= 5`: 判定する条件。直前で作った l を使える

次の 2 つは、l が if の外で使えるかどうか以外は同じ動きです。

```go
// 2 行に分けた形（l は if の後でも使える）
l := len(word)
if l >= 5 {
	fmt.Println("長い単語")
}
```

### スコープとは

変数を使える範囲を**スコープ**と呼びます。`if` の前の 1 文で作った変数のスコープは、その if と else の `{ }` の中だけです。if の後で `fmt.Println(l)` と書くと `undefined: l`（l は定義されていない）というコンパイルエラーになります。詳しくは L19 で学びます。

### サンプルを 1 行ずつ読む

`func double(n int) int` は、受け取った int を 2 倍にして 1 つ返す関数です（関数の書き方は L09 ch01）。

- `if v := double(21); v > 40 {` → 動き: v は 42。42 > 40 は true ／ 出力: `40より大きい: 42`
- `if l := len(name); l >= 6 {` → 動き: name は `"gopher"` で l は 6。6 >= 6 は true ／ 出力: `6文字以上です`

実行結果:

```text
40より大きい: 42
6文字以上です
```
