# Lesson 01 Goとは

Python入門編「Python3を学習しよう」に対応するレッスンです。

## ch01 Goはコンパイルして動かす

Go は**コンパイル**（ソースコードを機械語に変換すること）してから動かす言語です。Python はスクリプトをインタプリタがそのまま実行しましたが、Go はスクリプトではなくビルドして動かします。とはいえ `go run` コマンドがコンパイルと実行をまとめてやってくれるので、学習中の使い心地は Python とほぼ同じです。🟡 まずは「書く → go run で動かす」の流れを理解しましょう。

Python ではこう書いた:

```sh
python3 main.py
```

Go ではこう書く:

```sh
go run main.go
```

### 用語の確認

- **ソースコード**: 人が書くプログラムの文章。Go では拡張子 `.go` のファイルに書きます
- **機械語**: CPU が直接実行できる 0 と 1 の命令。人には読めません
- **インタプリタ**: ソースコードを 1 行ずつ読みながら実行するプログラム。`python3` がこれです
- **ビルド**: コンパイルして、単独で動く実行ファイル（Windows の `.exe` のようなもの）を作ること

### 動かすまでの流れ

1. `main.go` という名前のファイルにコードを書いて保存します
2. ターミナル（コマンドを打ち込む画面）でそのファイルがあるフォルダに移動し、`go run main.go` と打ちます
3. `go run` は裏で「コンパイル → できた実行ファイルを実行 → 後片付け」を一気に行い、結果を画面に出します

コードに文法の誤りがあると、手順 3 のコンパイルの段階で止まり、1 行も実行されません。Python は誤りのある行に来るまで前の行を実行しましたが、Go は実行前にすべての誤りを見つけます。

参考までに、`go build main.go` と打つと実行ファイル `main` だけが作られ、`./main` でいつでも実行できます。この講座では `go run` だけを使います。

### サンプルの実行結果

下のサンプルを `go run` すると、次の 3 行が表示されます。コードの各行の意味は次のチャプター（ch02）で 1 行ずつ見ます。

```text
Hello, Go!
Go はコンパイルして動かす言語です
go run がコンパイルと実行をまとめてやってくれます
```

## ch02 package main と func main

Python はファイルの先頭から順に実行されました。Go では、プログラムの入口が `func main`（main 関数）と決まっていて、さらにその関数は `package main` というパッケージ（コードの所属を表す宣言）に置く必要があります。この 3 点セット（package main・import・func main）はすべての Go プログラムの骨格です。🔴 何も見ずに書けるまで手を動かしましょう。

Python ではこう書いた:

```python
print("Hello")
```

Go ではこう書く:

```go
package main

import "fmt"

func main() {
	fmt.Println("Hello")
}
```

### 1 行ずつ読む

- `package main`: このファイルは `main` という名前のパッケージに属する、という宣言です。**パッケージ**は Go のコードをまとめる単位で、「実行できるプログラム」は必ず `main` パッケージにします。ファイルの 1 行目（コメントを除く）に書きます
- `import "fmt"`: 標準ライブラリ（Go に最初から付いている部品集）の `fmt` パッケージを使えるようにします。Python の `import` と同じ役目です。fmt は format の略で、画面への出力などを担当します
- `func main() {`: `main` という名前の**関数**（ひとまとまりの処理に名前を付けたもの）を定義します。`func` は Python の `def` に当たります。`()` は「受け取る値がない」こと、`{` は処理の始まりを表します
- `fmt.Println("Hello")`: fmt パッケージの `Println` 関数を呼び、`"Hello"` を出力して改行します。`.`（ドット）は「fmt の中の Println」という所属を表します。`"..."` で囲んだものが文字列です
- `}`: main 関数の処理の終わりです

### Python との書き方の違い

- **ブロックは `{ }` で囲む**: Python はインデント（字下げ）で処理のまとまりを表しましたが、Go は波括弧 `{` と `}` で表します。字下げは見やすさのためで、Go ではタブ 1 つで下げるのが標準です（後で出てくる整形ツール gofmt が自動で揃えます）
- **`{` は同じ行の末尾に書く**: `func main()` の次の行に `{` を書くとコンパイルエラーになります
- **行末に `;` は不要**: 文の区切りは改行で十分です

### 実行の順番

`go run` すると、Go は `main` 関数を探し、その `{` から `}` までを上から順に実行し、`}` に着いたらプログラムを終了します。サンプルを実行すると次のように出ます。

```text
1: main 関数の先頭から実行されます
2: 上から順に実行されます
3: main 関数が終わるとプログラムも終わります
```

## ch03 静的型付けと gofmt

Go は**静的型付け**（変数の型がコンパイル時に決まっていて、あとから変えられない仕組み）の言語です。Python では変数に何でも入れられましたが、Go で int の変数に文字列を入れるとコンパイルエラーになります。エラーが実行前に見つかるのが利点です。また Go には公式の整形ツール `gofmt` があり、インデントや空白はすべて機械が揃えます。🟡 「型は固定」「整形は gofmt に任せる」の2点を押さえましょう。

Python ではこう書いた:

```python
x = 10
x = "hello"  # 何でも入る
```

Go ではこう書く:

```go
var x int = 10
// x = "hello" // コンパイルエラー: int に文字列は入らない
```

### 型とは

**型**は「その値が何の種類か」を表すものです。このチャプターで使う型は 2 つです。

- `int` → 入るもの: 整数（小数点のない数） ／ 例: `20`、`-3`、`2026`
- `float64` → 入るもの: 小数（浮動小数点数） ／ 例: `171.5`、`1.22`

文字列の型 `string` も L04 で正式に扱います。

### サンプルを 1 行ずつ読む

- `var age int = 20`: `var`（variable＝変数 の略）で変数を作ります。「`age` という名前の、`int` 型の変数を作り、`20` を入れる」という意味です。順番は「var 名前 型 = 値」です（詳しくは L04）
- `var height float64 = 171.5`: 同じく float64 型の変数 `height` に `171.5` を入れます
- `fmt.Println("age:", age)`: カンマで並べた値を、間に空白 1 つを入れて出力します。`age: 20` と出ます
- `// age = "twenty"`: 先頭の `//` はコメント（実行されないメモ）です。`//` を消すとコンパイルエラーになる例を示しています
- `age = 21`: すでにある変数に新しい値を入れ直します（再代入）。同じ int なので問題ありません

実行結果:

```text
age: 20
height: 171.5
来年の age: 21
```

### コンパイルエラーの実物

`// age = "twenty"` の `//` を消して `go run` すると、何も実行されずに次のようなエラーが出ます（行と文字の位置の数字はファイルによって変わります）。

```text
./main.go:7:8: cannot use "twenty" (untyped string constant) as int value in assignment
```

`main.go:7:8` は「7 行目の 8 文字目」という場所、その後ろが理由（文字列は int の値として使えない）です。エラーはまず場所を見て、その行を確かめる癖を付けましょう。

### gofmt とは

`gofmt -w main.go` を実行すると、字下げや空白を Go の標準の形に自動で書き直します。多くのエディタは保存時に自動で実行します。Go のコードは誰が書いても見た目がそろうので、書き方の流儀で迷う必要がありません。
