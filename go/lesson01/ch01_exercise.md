# lesson01 ch01 演習: Goはコンパイルして動かす

`fmt.Println` を使って、次の 2 行をこの順番で出力するプログラムを書いてください。

1. `Hello, Go!`
2. `demo から来ました`

**期待出力**

```text
Hello, Go!
demo から来ました
```

**ひな形について**: 最初から書いてある `_ = fmt.Println` は仮置きの行です。Go は import したのに使っていないパッケージがあるとコンパイルエラーにするため、まだ何も書いていない状態でもエラーにならないよう `fmt` を「使ったこと」にしています。自分で `fmt.Println(...)` を書いたら、この行は消してかまいません（残っていても動作に影響はありません）。以降の演習のひな形も同じです。
