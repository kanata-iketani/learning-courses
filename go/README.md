# Go入門編（Python経験者向け）

demo「新・Python入門編」全25レッスンの構成のまま Go を学ぶ講座です。
Python で学んだ順番どおりに、対応する Go の書き方を身につけます。

## 進め方

各レッスン（`lesson01/`〜`lesson25/`）は複数のチャプターでできています。
1チャプターは demo と同じ 3 点セットです。

1. **説明** — `README.md` の該当チャプターを読む（Python との対比つき）
2. **サンプル** — `chNN_sample.go` を実行して動きを確かめる
3. **演習** — `chNN_exercise.md` を読み、自分でコードを書く。答え合わせは `answer/chNN_answer.go`

サンプルの実行方法:

```sh
go run ./lesson01/ch01_sample.go
```

説明中のマークは学習の深さの目安です。

- 🔴 手が覚えるまで書く
- 🟡 理屈を理解する
- ⚪ 存在だけ知っておく

## 教材データの構成

教材の正データはチャプターごとの JSON（`lessonNN/chMM.json`）です。
各レッスンの `README.md`・`chNN_sample.go`・`chNN_exercise.md`・`answer/chNN_answer.go` は
JSON から自動生成されます。教材を直すときは JSON を編集して次を実行してください。

```sh
go run ./tools/coursegen            # 全レッスンを検証して再生成
go run ./tools/coursegen -only 7    # lesson07 だけ
go run ./tools/coursegen -no-gen    # 検証のみ（go vet / go run / 期待出力照合）
```

## ブラウザで学ぶ（ブラウザ完結型の学習画面）

左に教科書、右にコードエディタが出て、実行するとその場で合否判定される
ローカルアプリを同梱しています。

```sh
cd app
go run .
```

起動したらブラウザで <http://localhost:8080> を開いてください。

### 質問対話（Claude 先生）

学習画面の右上「💬 質問」から、今開いているチャプターについて Claude に質問できます
（ローカルの Claude Code CLI をヘッドレス実行するので、API キーは不要です）。

- **質問する** — 教材・演習・エディタのコードを文脈として回答します。Q&A は `app/questions.json` に自動保存されます
- **質問ノート** — 保存した Q&A の一覧。「📝 疑問点をまとめる」で弱点ノート（`app/notes.md`）を生成、
  「🎯 復習問題を作る」で自分の質問傾向に合わせた復習チャプターを自動生成します
  （生成した問題は go run で検証してから `lesson90/` に保存され、通常のレッスンと同じように採点できます）
- 回答モデルは `go run . -claude-model <model>` で変更できます（既定: sonnet）
