# Lesson 06 文字列と数値の相互変換

Python入門編「文字列と数値の相互変換」に対応するレッスンです。`str()` `int()` `float()` に当たるのが `strconv` パッケージの関数です。最大の違いは `strconv.Atoi` が `(int, error)` の 2 値を返すことで、この講座ではここで初めて `err` が登場します。

## ch01 strconv.Itoa（数値→文字列）

数値を文字列に変換するには `strconv` パッケージ（文字列と数値の相互変換を集めた標準ライブラリ）の `strconv.Itoa` を使います。Python の `str(42)` に相当する関数です。Go は文字列と int を `+` で直接つなげられないため、連結する前に必ず文字列へ変換する必要があります。Itoa は Integer to ASCII の略です。🔴 数値を文章に埋め込む場面は頻出なので、手が覚えるまで書きましょう。

Python ではこう書いた:

```python
s = str(42)
print("値は" + s)
```

Go ではこう書く:

```go
s := strconv.Itoa(42)
fmt.Println("値は" + s)
```

### 数値の 42 と文字列の "42" は別物

`42` は計算できる int、`"42"` は `4` と `2` の 2 文字が並んだ string です。見た目は同じでも型が違うため、`"値は" + 42` はコンパイルエラーになります（L05 ch01）。`strconv.Itoa(42)` は int の 42 を受け取り、string の `"42"` を返します。

strconv は string conversion（文字列変換）の略です。使うには `import` に `"strconv"` を足します。

### サンプルを 1 行ずつ読む

- `s := strconv.Itoa(age)`: age（int の 28）から string の `"28"` を作って s に入れる
- `fmt.Println("年齢は" + s + "歳です")`: 文字列どうしなので連結できる。`年齢は28歳です`
- `ps := strconv.Itoa(price)`: ps は `"1200"`（4 文字の文字列）
- `strconv.Itoa(len(ps))`: `len(ps)` は int の 4。それを文字列 `"4"` にしてから連結する

実行結果:

```text
年齢は28歳です
1200 は 4 文字です
```

`fmt.Println("年齢は", age, "歳です")` と書けば変換なしでも表示はできますが、値の間に空白が入ります。空白なしの 1 本の文字列を作りたいときに Itoa（または L05 の Sprintf）を使います。

## ch02 strconv.Atoi と err（文字列→数値）

文字列を数値に変換する `strconv.Atoi` は、Python の `int("42")` に相当します。大きな違いは、Atoi が `(int, error)` の **2 つの値**を返すことです。`error` は「処理が失敗したかどうか」を表す型で、この講座ではここで初めて登場します。成功すると err には `nil`（何もないことを表す値）が入り、失敗すると理由が入ります。`if err != nil { ... }` で失敗を確認するのが Go の定型です。🔴 この形は今後ずっと使うので、手が覚えるまで書きましょう。

Python ではこう書いた:

```python
n = int("42")
```

Go ではこう書く:

```go
n, err := strconv.Atoi("42")
if err != nil {
	fmt.Println("変換できません")
}
```

Atoi は ASCII to Integer（文字列から整数へ）の略で、ch01 の Itoa の逆です。

### 2 つの値を受け取る

`n, err := strconv.Atoi("300")` は、Atoi が返す 2 つの値を左から順に `n` と `err` に入れます（L04 ch02 の `x, y := 10, 20` と同じ並べ方です）。

- 入力 `"300"` → n: `300`（int） ／ err: `nil`（失敗なし）
- 入力 `"abc"` → n: `0` ／ err: `strconv.Atoi: parsing "abc": invalid syntax`（失敗の理由）

Python の `int("abc")` は例外（ValueError）でプログラムが止まりましたが、Go は止まらずに「失敗した」という情報を err で返します。調べるのはプログラムを書く人の役目です。

### `if err != nil { ... }` を 1 つずつ読む

ここで初めて `if` が出てきます（詳しくは L10）。

- `if 条件 { ... }`: 条件が成り立つときだけ `{ }` の中を実行します。Python の `if 条件:` と同じです
- `err != nil`: `!=` は「等しくない」。「err が nil ではない」＝「失敗の理由が入っている」＝失敗した、という条件です
- `return`: main 関数をここで終わらせます。main が終わるとプログラムも終わるので、以降の行は実行されません

### `_` で値を捨てる

サンプル後半の `_, err = strconv.Atoi("abc")` の `_`（アンダースコア）は「この値は使わないので捨てる」という印です。Go は使わない変数をエラーにする（L04 ch03）ため、いらない戻り値は `_` で受けます。また err はすでに作ってあるので、ここは `:=` ではなく再代入の `=` です。

### サンプルの実行結果

```text
400
abc は数値に変換できません
```

1 行目は `"300"` の変換に成功して `300 + 100` を計算した結果、2 行目は `"abc"` の変換に失敗して if の中が実行された結果です。

## ch03 strconv.ParseFloat（文字列→float64）

文字列を小数に変換するには `strconv.ParseFloat` を使います。Python の `float("3.5")` に相当します。第 2 引数には精度を渡し、`float64` を使う Go では常に `64` と書きます。Atoi と同じく戻り値は `(float64, error)` の 2 値で、`if err != nil` のチェックもまったく同じ形です。🟡 「文字列→数値の変換は必ず 2 値で返る」という仕組みを理屈で理解しましょう。

Python ではこう書いた:

```python
x = float("2.5")
```

Go ではこう書く:

```go
x, err := strconv.ParseFloat("2.5", 64)
```

Parse は「文字列を読み取って意味のある値にする」という意味の英語で、ParseFloat は「文字列を読んで小数にする」関数です。

### 引数と戻り値

- 第 1 引数 `"2.5"`: 変換したい文字列
- 第 2 引数 `64`: float64 として読む、という指定（L03 ch01 の「64 ビット」）
- 戻り値 1 つ目 `x`: 変換できた float64 の値（`2.5`）
- 戻り値 2 つ目 `err`: 成功なら `nil`、失敗なら理由（例: `"1.x"` を渡すと `invalid syntax`）

### サンプルの実行結果

`x + 1.5` は `2.5 + 1.5 = 4`、それを `%.1f`（小数第 1 位まで、L02 ch03）で表示するので次のようになります。

```text
4.0
```

`fmt.Println(x + 1.5)` なら `4` と表示されます。小数点以下の桁をそろえたいときは Printf の `%.1f` や `%.2f` を使います。

## ch04 strconv.FormatFloat（float64→文字列）

float64 を文字列に変換するには `strconv.FormatFloat` を使います。Python では `str(3.14)` や f文字列の `:.2f` で済んだ変換です。引数は（値・表記の種類・小数桁数・精度）の 4 つで、ふだんは表記 `'f'` と精度 `64` を固定して桁数だけ変えれば十分です。同じことは `fmt.Sprintf("%.2f", x)` でもでき、実務ではそちらもよく使います。⚪ まずはこういう関数があると知っておくだけで十分です。

Python ではこう書いた:

```python
s = f"{3.14159:.2f}"
```

Go ではこう書く:

```go
s := strconv.FormatFloat(3.14159, 'f', 2, 64)
```

### 4 つの引数

`strconv.FormatFloat(pi, 'f', 2, 64)` の場合:

- 第 1 引数 → 値: `pi` ／ 意味: 変換したい float64 の値（3.14159）
- 第 2 引数 → 値: `'f'` ／ 意味: 表記の種類。`'f'` は `3.14` のような普通の小数の書き方。シングルクォートなのは 1 文字（rune、L05 ch03）だからです
- 第 3 引数 → 値: `2` ／ 意味: 小数点以下の桁数。`-1` なら「必要な分だけ」
- 第 4 引数 → 値: `64` ／ 意味: 元の値が float64 であることの指定

### サンプルの実行結果

- `strconv.FormatFloat(pi, 'f', 2, 64)`: `"3.14"`
- `strconv.FormatFloat(pi, 'f', -1, 64)`: `"3.14159"`（元の値の桁をそのまま）

```text
円周率はおよそ 3.14
3.14159
```

Format は「決まった形に整える」という意味で、ch03 の ParseFloat（文字列→数値）の逆向きの関数です。こちらは失敗することがないので、戻り値は文字列 1 つだけで err はありません。
