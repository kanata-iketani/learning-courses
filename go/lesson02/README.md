# Lesson 02 標準出力

Python入門編「標準出力」に対応するレッスンです。Python の `print()` は `sep=` や `end=` で出力を細かく調整できましたが、Go にその引数はなく、`Print` と `Printf` を使い分けて表現します。

## ch01 fmt.Println

`fmt.Println` は Python の `print()` に一番近い関数です。複数の値をカンマで並べると空白区切りで出力され、最後に自動で改行が付きます。Python と違い、括弧の前に `fmt.` というパッケージ名が必要な点だけ注意してください。🔴 一番よく使う関数なので、手が覚えるまで書きましょう。

Python ではこう書いた:

```python
print("score", 80)
```

Go ではこう書く:

```go
fmt.Println("score", 80)
```

### 名前の読み方

`fmt.Println` は「`fmt` パッケージ（L01 で import したもの）の中の `Println` 関数」という意味です。Println は Print line（1 行出力する）の略です。`P` は大文字で書きます。Go は大文字と小文字を区別するので、`fmt.println` と書くとエラーになります。

### サンプルを 1 行ずつ読む

- `fmt.Println("Hello, world!")` → 出力: `Hello, world!` ／ ポイント: `"` で囲んだ文字列は、`"` を除いた中身が出ます
- `fmt.Println(42)` → 出力: `42` ／ ポイント: 数値は `"` なしでそのまま渡せます
- `fmt.Println("score", 80)` → 出力: `score 80` ／ ポイント: カンマで並べた値の間に空白が 1 つ入ります
- `fmt.Println("x", 1, "y", 2)` → 出力: `x 1 y 2` ／ ポイント: いくつ並べても同じです

カンマで渡す 1 つ 1 つの値を**引数**（関数に渡す値）と呼びます。Println は引数をいくつでも受け取れます。

実行結果（各行の最後で改行されています）:

```text
Hello, world!
42
score 80
x 1 y 2
```

## ch02 fmt.Print（end="" の代わり）

Python では `print("a", end="")` で改行を止めました。Go では改行を付けない `fmt.Print` を使います。`end=` という引数は存在しないので、「改行したい行は `Println`、したくない行は `Print`」と関数そのものを使い分けます。改行だけしたいときは `fmt.Println()` と空で呼びます。🟡 2 つの関数の違いを理屈で押さえましょう。

Python ではこう書いた:

```python
print("Hello", end="")
print("World")
```

Go ではこう書く:

```go
fmt.Print("Hello")
fmt.Println("World")
```

### サンプルで出力がどう積み上がるか

画面には「いまカーソルがある位置」があり、出力はそこに続けて書かれます。`Print` はカーソルを行の途中に置いたまま、`Println` は最後に改行してカーソルを次の行の先頭へ移します。

- `fmt.Print("Hello")`: `Hello`
- `fmt.Print(", ")`: `Hello, `
- `fmt.Println("world!")`: `Hello, world!`（ここで改行）
- `fmt.Print("1行目のつもり")`: 2 行目に `1行目のつもり`（改行なし）
- `fmt.Println()`: 何も足さずに改行だけします
- `fmt.Println("2行目")`: 3 行目に `2行目`

実行結果:

```text
Hello, world!
1行目のつもり
2行目
```

### Print に複数の値を渡すとき

`Println` は値の間に必ず空白を入れますが、`Print` は「両隣がどちらも文字列ではないとき」だけ空白を入れる、という少し違う規則です。`fmt.Print("Go", "lang")` は `Golang` と空白なしで出ます。迷いやすいので、Print には値を 1 つずつ渡すか、次の ch03 の `Printf` を使うのが無難です。

## ch03 fmt.Printf（sep= と書式の代わり）

`fmt.Printf` は**書式指定**（`%d` などの記号で値の埋め込み方を指定する仕組み）を使う出力関数です。`%d` は整数、`%s` は文字列、`%f` は小数（`%.1f` で小数第1位まで）に対応します。Python の `sep="-"` のような区切り指定も、Go では書式の中に直接 `-` を書いて表現します。`Printf` は改行を付けないので、末尾に `\n` を書きます。🔴 コーディングテストでも多用します。

Python ではこう書いた:

```python
print(2026, 9, 20, sep="-")
```

Go ではこう書く:

```go
fmt.Printf("%d-%d-%d\n", 2026, 9, 20)
```

### 書式指定の仕組み

`Printf` の 1 つ目の引数は「ひな形の文字列」で、その中の `%d` や `%s` が穴になります。2 つ目以降の引数が、左から順に穴へ埋め込まれます。

```go
fmt.Printf("%sさんは%d歳\n", "佐藤", 28)
//          ↑1つ目の穴 ↑2つ目の穴   ↑1つ目  ↑2つ目
// 出力: 佐藤さんは28歳
```

- `%d` → 埋め込むもの: 整数（decimal＝10 進数） ／ 例: `Printf("%d", 13)` ／ 出力: `13`
- `%s` → 埋め込むもの: 文字列（string） ／ 例: `Printf("%s", "Go")` ／ 出力: `Go`
- `%f` → 埋め込むもの: 小数。何も指定しないと小数第 6 位まで ／ 例: `Printf("%f", 3.14159)` ／ 出力: `3.141590`
- `%.1f` → 埋め込むもの: 小数第 1 位まで（第 2 位で丸める） ／ 例: `Printf("%.1f", 3.14159)` ／ 出力: `3.1`
- `%.2f` → 埋め込むもの: 小数第 2 位まで ／ 例: `Printf("%.2f", 3.14159)` ／ 出力: `3.14`
- `\n` → これは穴ではなく改行の記号（ここで行を変える） ／ 例: `Printf("a\nb")` ／ 出力: `a` と `b` が 2 行に

`\n` は「バックスラッシュ＋n」の 2 文字で、改行 1 文字を表す決まりです（エスケープシーケンスと呼びます）。Python の文字列と同じです。

### サンプルの最初の 3 行について

サンプルの `name := "demo"` は「`name` という変数を作って `"demo"` を入れる」という意味です。L01 で見た `var name string = "demo"` の短い書き方で、型は右辺から自動で決まります。詳しくは L04 で学びます。

### サンプルの実行結果

```text
name は demo です
age は 13 歳です
pi はおよそ 3.141590 です
小数第1位までなら 3.1 です
2026-9-20
```

`%f` では小数第 6 位まで `0` で埋めて表示されること、最後の行は区切りの `-` がひな形にそのまま書かれているので出力にも出ることを確かめてください。

## ch04 コメント

コメント（実行されないメモ書き）は、Python では `#` でしたが、Go では 1 行コメントが `//`、複数行コメントが `/* */` です。Go には Python の docstring はなく、関数の説明も `//` を関数の直前に書くのが慣習です。⚪ 記号が違うことだけ知っておけば十分です。

Python ではこう書いた:

```python
# 1行コメント
```

Go ではこう書く:

```go
// 1行コメント
/* 複数行
   コメント */
```

### コメントの範囲

- `//` から**その行の終わりまで**がコメントです。`fmt.Println("x") // 説明` のように、コードの後ろに書けば、コードは実行され説明部分だけが無視されます
- `/*` から `*/` までは、何行にまたがってもすべてコメントです
- 行の先頭に `//` を付けて、その行のコードを一時的に無効にすることを**コメントアウト**と呼びます。演習ではこれを使います

### サンプルの実行結果

コメントの部分は何も出力されず、`fmt.Println` の 2 行だけが表示されます。

```text
コメントは出力されません
ここは実行されます
```
