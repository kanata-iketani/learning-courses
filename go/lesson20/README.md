# Lesson 20 引数と再帰

Python入門編「引数と再帰」に対応するレッスンです。Go の引数は値渡し（コピー）で、呼び出し元を変えるにはポインタを渡します。キーワード引数・デフォルト引数はなく、オプション構造体で代替します。

## ch01 値渡し（引数はコピーされる）

Go の関数の引数は**値渡し**です。関数を呼ぶと引数の値が**コピー**されて渡り、関数の中でコピーを書き換えても呼び出し元の変数は変わりません。Python でも数値や文字列は同じ振る舞いでしたが、Go では構造体（L9 で見た、複数の値に名前を付けてまとめる型）なども丸ごとコピーされます。変更した結果が欲しいときは、戻り値で返して受け取り直すのが基本です。🟡 「関数の中の n は別物」という理屈を理解しましょう。

Python ではこう書いた:

```python
def add_ten(n):
    n += 10  # 呼び出し元の x は変わらない

x = 5
add_ten(x)
print(x)  # 5
```

Go ではこう書く:

```go
func addTen(n int) int {
	n += 10 // 書き換わるのはコピーだけ
	return n
}

x := 5
x = addTen(x) // 戻り値で受け取り直す
```

### サンプルを1行ずつ読む

| 行 | main の x | addTen の n |
|---|---|---|
| `x := 5` | 5 | — |
| `addTen(x)` を呼ぶ | 5 | 5（x の値がコピーされて入る） |
| `n += 10`（addTen の中） | 5 | 15（コピーだけ増える） |
| `return n` → `result := ...` | 5 | （関数が終わって消える） |
| `x = addTen(x)` | 15 | — |

`n` と `x` は別々の箱です。`addTen` の中から `x` を変える方法はなく、変えたいときは戻り値を `x =` で受け取り直します。

### 実行結果

```text
15
5
15
```

## ch02 ポインタ渡し（*int と &）

呼び出し元の変数そのものを関数から書き換えたいときは**ポインタ**（変数のメモリ上の場所を指す値）を渡します。メモリは、プログラムの変数が置かれるコンピュータ内の記憶領域で、置き場所ごとに番号（アドレス）が付いています。`&x` で x のポインタを取り、受け取る引数の型は `*int`、関数の中では `*p` で指した先を読み書きします。Python ではリストなどミュータブルな値を渡して間接的に書き換えましたが、Go では「呼び出し元を変えたい」という意図を `&` と `*` で明示します。🟡 「ポインタを渡す＝場所を教える」という理屈を理解しましょう。

Python ではこう書いた:

```python
def double(nums):
    nums[0] *= 2  # リスト経由でしか書き換えられない

nums = [5]
double(nums)
```

Go ではこう書く:

```go
func double(p *int) {
	*p *= 2 // ポインタの指す先を書き換える
}

x := 5
double(&x) // x の場所を渡す
```

### 記号 `&` と `*` の意味

| 書き方 | 意味 | 例（`x := 5` のとき） |
|---|---|---|
| `&x` | x の場所（アドレス）を取り出す | `0xc000012345` のような番号 |
| `*int`（型の位置） | 「int の場所」を入れる型 | `p *int` は「int の場所を受け取る引数」 |
| `*p`（値の位置） | p が指す場所の中身 | 5 |

`*` は型の前に付くと「〜へのポインタ型」、変数の前に付くと「指す先の中身」と、置く場所で意味が変わります。`fmt.Println(&x)` とするとアドレスが `0xc000112020` のような 16 進数で出ますが、この番号は実行のたびに変わるので、値そのものに意味はありません。

### サンプルを1行ずつ読む

- `func double(p *int) {` … 引数 `p` は int の場所を受け取ります
- `*p *= 2` … 左の `*p` は「p が指す先」、`*= 2` は「2 倍して代入」（`+=` と同じ仲間）。つまり「指す先の値を 2 倍にする」です
- `double(&x)` … `x` の場所を渡します。`double` の中の `*p` は main の `x` そのものなので、`x` が 5 → 10 になります
- 2 回目の `double(&x)` … 10 → 20

### 実行結果

```text
5
10
20
```

`double(x)` と `&` を付け忘れると、`cannot use x (variable of type int) as *int value`（int を *int として使えない）というコンパイルエラーになります。

## ch03 可変長引数 ...int（*args の代わり）

引数の個数を決めずに受け取るには、最後の引数の型の前に `...` を付けます（**可変長引数**）。Python の `*args` に相当し、関数の中では普通のスライスとして扱えます。呼び出しは `total(1, 2, 3)` のように好きな個数で書け、スライスをばらして渡すときは Python の `total(*nums)` に当たる `total(nums...)` と書きます。可変長引数は引数リストの最後に 1 つだけ置けます。🟡

Python ではこう書いた:

```python
def total(*args):
    return sum(args)

nums = [1, 2, 3]
print(total(*nums))
```

Go ではこう書く:

```go
func total(nums ...int) int {
	t := 0
	for _, n := range nums {
		t += n
	}
	return t
}

fmt.Println(total(nums...)) // スライスをばらして渡す
```

### サンプルを1行ずつ読む

- `func total(nums ...int) int {` … `...int` は「int をいくつでも」の意味。関数の中で `nums` は `[]int`（スライス）になります
- `for _, n := range nums { t += n }` … スライスと同じく range で合計します

| 呼び出し | nums の中身 | 戻り値 |
|---|---|---|
| `total(1, 2, 3)` | [1 2 3] | 6 |
| `total(10, 20)` | [10 20] | 30 |
| `total()` | []（空） | 0 |
| `total(nums...)`（nums は [5 6 7]） | [5 6 7] | 18 |

- `total(nums...)` … スライスの後ろに `...` を付けると、要素をばらして渡せます。`...` を付けずに `total(nums)` と書くと、スライス 1 つを int として渡そうとしてコンパイルエラーになります。L7 で見た `append(s1, s2...)` の `...` と同じ記号です

### 実行結果

```text
6
30
0
18
```

`...` は「型の前」に付くと可変長引数の宣言、「スライスの後ろ」に付くと「ばらして渡す」です。

## ch04 キーワード引数・デフォルト引数はない

Python の `greet(name, prefix="Hello")` のような**デフォルト引数**や、`greet(name="太郎")` のような**キーワード引数**は、**Go にはありません**。引数はすべて順番どおりに渡します。省略できる設定が欲しいときは、設定をまとめた**オプション構造体**（構造体は L9 で見ました。詳しくは次のレッスンで学びます）を引数にして、ゼロ値（`""` や 0）だったら関数側でデフォルトを補う、という書き方で代替するのが定番です。🟡

Python ではこう書いた:

```python
def greet(name, prefix="Hello"):
    print(f"{prefix}, {name}!")

greet("Taro")
greet("Hana", prefix="Hi")
```

Go ではこう書く:

```go
type Options struct {
	Prefix string
}

func greet(name string, opt Options) {
	if opt.Prefix == "" {
		opt.Prefix = "Hello" // ゼロ値ならデフォルトを補う
	}
	fmt.Printf("%s, %s!\n", opt.Prefix, name)
}

greet("Taro", Options{})
greet("Hana", Options{Prefix: "Hi"})
```

### サンプルを1行ずつ読む

- `type Options struct { Prefix string }` … `Prefix` という文字列のフィールド（構造体の中の項目）を 1 つ持つ型 `Options` を定義します
- `func greet(name string, opt Options) {` … 2 つ目の引数は `Options` 型です
- `if opt.Prefix == "" { opt.Prefix = "Hello" }` … `opt.Prefix` で中の項目を読みます。何も指定されていなければ文字列のゼロ値 `""`（L4）なので、そのときだけ `"Hello"` を入れます
- `fmt.Printf("%s, %s!\n", opt.Prefix, name)` … 1 つ目の `%s` に Prefix、2 つ目に name が入ります
- `greet("Taro", Options{})` … `Options{}` は全項目がゼロ値の構造体。Prefix は `""` なので `"Hello"` が補われます
- `greet("Hana", Options{Prefix: "Hi"})` … `項目名: 値` で指定した構造体。Python の `prefix="Hi"` に当たります

### 実行結果

```text
Hello, Taro!
Hi, Hana!
```

`opt` は値渡し（ch01）なので、`greet` の中で `opt.Prefix` を書き換えても、呼び出し元の構造体には影響しません。

## ch05 再帰

関数が自分自身を呼び出すことを**再帰**といいます。書き方の考え方は Python と同じで、まず「これ以上自分を呼ばずに答えを返す条件（基底条件）」を書き、それ以外では少し小さくした問題で自分を呼びます。Go では引数と戻り値に型を書く点だけが違います。基底条件を忘れると自分を呼び続けてスタックオーバーフロー（関数を呼ぶたびに使う作業用メモリ「スタック」を使い切ること）で落ちるので、必ず先頭に書きましょう。🟡 再帰は理屈が命です。

Python ではこう書いた:

```python
def fact(n):
    if n == 0:
        return 1
    return n * fact(n - 1)
```

Go ではこう書く:

```go
func fact(n int) int {
	if n == 0 {
		return 1 // 基底条件
	}
	return n * fact(n-1)
}
```

### `fact(5)` の動き

| 呼び出し | 返す式 | 値 |
|---|---|---|
| fact(5) | 5 * fact(4) | 5 * 24 = 120 |
| fact(4) | 4 * fact(3) | 4 * 6 = 24 |
| fact(3) | 3 * fact(2) | 3 * 2 = 6 |
| fact(2) | 2 * fact(1) | 2 * 1 = 2 |
| fact(1) | 1 * fact(0) | 1 * 1 = 1 |
| fact(0) | 基底条件 | 1 |

上から順に呼ばれ、fact(0) が 1 を返したところから下→上へ値が戻ってきます。

### サンプルを1行ずつ読む

- `if n == 0 { return 1 }` … 基底条件。ここで自分を呼ぶのをやめます
- `return n * fact(n-1)` … n を 1 減らした自分を呼び、その答えに n を掛けます
- `countdown(n int)` … 戻り値のない再帰。`n < 0` で `return`（値なしで関数を終える）。それ以外は n を出してから `countdown(n - 1)` を呼びます。3, 2, 1, 0 と出て、-1 で止まります

### 実行結果

```text
120
3
2
1
0
```

基底条件を消すと、Go は次のように表示して止まります。

```text
runtime: goroutine stack exceeds 1000000000-byte limit
fatal error: stack overflow
```

（goroutine は Go の実行単位の名前です。ここでは「プログラムの実行」と読めば十分です。）
