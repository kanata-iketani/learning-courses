# Lesson 05 文字列

Python入門編「文字列」に対応するレッスンです。Go の文字列で最重要の注意点は、`s[i]` が文字ではなく**バイト**を返すことです。日本語を文字単位で扱うには `[]rune` に変換します。f文字列に相当するのは `fmt.Sprintf` です。

## ch01 文字列リテラルと + 結合

Go の文字列は `"..."`（ダブルクォート）で書きます。Python のようにシングルクォートで文字列は作れません（Go の `'a'` は 1 文字の rune という別物になります）。`+` で連結できるのは Python と同じです。改行を含めたいときは `\n`、そのまま複数行書きたいときはバッククォート（キーボードの Shift + @ で入力する記号）で囲みます。🔴 「文字列は必ずダブルクォート」を手に覚えさせましょう。

Python ではこう書いた:

```python
s = 'Hello' + "World"
```

Go ではこう書く:

```go
s := "Hello" + "World" // ダブルクォートのみ
```

### 用語の確認

- **文字列**: 文字の並び。型の名前は `string` です
- **リテラル**: コードに直接書いた値のこと。`"Hello"` は文字列リテラル、`42` は整数リテラルです
- **連結**: 文字列どうしを `+` でつなげて 1 本にすること。`"Go" + "lang"` は `"Golang"` になります

### 3 種類のクォート

- `"..."`（ダブルクォート） → 何になるか: 文字列。`\n` などの記号が働く ／ 例: `"1行目\n2行目"` は 2 行で表示
- バッククォートで囲む（キーボードの Shift + `@`） → 何になるか: 文字列。書いたとおりそのまま。改行も含められ、`\n` は 2 文字のまま ／ 例: Python の `"""..."""` に近い
- `'...'`（シングルクォート） → 何になるか: 文字列ではなく 1 文字（rune、ch03 で学ぶ）。2 文字以上入れるとエラー ／ 例: `'a'`

`'ab'` と書くと `more than one character in rune literal`（rune に 2 文字以上ある）というコンパイルエラーになります。

### サンプルを 1 行ずつ読む

- `fmt.Println(hello + ", " + world + "!")`: `Hello, World!`（4 つの文字列を順につないだもの）
- `fmt.Println("1行目\n2行目")`: `1行目` と `2行目` の 2 行（`\n` の位置で改行）
- バッククォートの 2 行: `複数行を` と `そのまま書けます` の 2 行（書いた改行がそのまま出る）

実行結果:

```text
Hello, World!
1行目
2行目
複数行を
そのまま書けます
```

### 数値とは直接つなげない

`"年齢" + 28` のように文字列と数値を `+` でつなぐとコンパイルエラー（`mismatched types`、型が合わない）になります。数値を文字列にする方法は L06 で学びます。

## ch02 len と s[i]（バイト）

`len(s)` は文字数ではなく**バイト数**（データの大きさの単位。ASCII 文字は 1 文字 1 バイト、日本語は UTF-8 で 1 文字 3 バイト）を返します。同様に `s[i]` も i 番目の文字ではなく i 番目のバイトを返します。英数字だけなら Python と同じ感覚で動きますが、日本語が混ざると期待とずれます。🟡 「文字列の実体はバイト列」という理屈を理解しましょう。

Python ではこう書いた:

```python
s = "こんにちは"
print(len(s))  # 5
```

Go ではこう書く:

```go
s := "こんにちは"
fmt.Println(len(s)) // 15（バイト数）
```

### 基礎の基礎: 文字はコンピュータの中では数

コンピュータは文字を数として保存します。どの文字をどの数にするかの決まりを**文字コード**と呼び、Go は **UTF-8** という文字コードを使います。

- **バイト**: 0〜255 の数 1 つ分の大きさ（8 ビット）
- **ASCII 文字**: 半角の英字・数字・記号。UTF-8 では 1 文字が 1 バイトです。例えば `H` は 72、`e` は 101
- **日本語の文字**: UTF-8 では 1 文字が 3 バイト（3 つの数の組）で表されます。`こ` は 227・129・147 の 3 バイトです

Go の文字列は、この「バイトの並び」をそのまま持っています。`len` はその並びの長さを数えるので、日本語 1 文字につき 3 と数えます。

- `"Hello"` → 文字数: 5 ／ `len` の結果: 5
- `"こんにちは"` → 文字数: 5 ／ `len` の結果: 15
- `"Go言語"` → 文字数: 4 ／ `len` の結果: 8（G と o で 2、言 と 語 で 6）

### サンプルを 1 行ずつ読む

- `len(en)` → 出力: `5` ／ 説明: Hello は 5 バイト
- `en[0]` → 出力: `72` ／ 説明: 0 番目のバイト。文字ではなく数（`H` の番号）が出ます
- `string(en[0])` → 出力: `H` ／ 説明: `string(...)` で数を文字に戻して表示
- `len(ja)` → 出力: `15` ／ 説明: 5 文字 × 3 バイト
- `ja[0]` → 出力: `227` ／ 説明: 「こ」を表す 3 バイトのうち 1 つ目にすぎません

`s[i]` の `[i]` は、Python と同じ「0 から数えて i 番目」を取り出す書き方です（**インデックス**と呼びます）。

実行結果:

```text
5
72
H
15
227
```

## ch03 []rune と日本語

日本語を文字単位で扱うには `[]rune(s)` で **rune**（1 文字を表す Go の型。Unicode のコードポイント 1 つ分）のスライスに変換します。変換後は `len` が文字数になり、`[i]` で i 番目の文字を取れます。取り出した rune を文字列として表示するには `string(r[0])` と戻します。「日本語が来たら []rune」は Go の定石です。🟡 なぜ変換が必要か（ch02 のバイトの話）とセットで理解しましょう。

Python ではこう書いた:

```python
s = "こんにちは"
print(s[0])  # こ
```

Go ではこう書く:

```go
r := []rune("こんにちは")
fmt.Println(len(r))       // 5（文字数）
fmt.Println(string(r[0])) // こ
```

### 用語と記号の確認

- **Unicode のコードポイント**: 世界中の文字 1 つ 1 つに振られた通し番号です。`A` は 65、`あ` は 12354、`駅` は 39365 です。rune はこの番号を 1 つ持つ型です
- **スライス**: 同じ型の値を順番に並べたもの。Python のリストに当たり、L07 で詳しく学びます
- **`[]rune`**: `[]` は「〜のスライス」という意味で、`[]rune` は「rune のスライス（文字の並び）」という型の名前です
- **`[]rune(s)`**: L03 の `float64(n)` と同じ型変換の形です。文字列 s を「1 文字 = 1 要素」の並びに作り直します

### 変換で何が変わるか

`s := "こんにちは世界"` のとき:

- `s`（文字列のまま） → 中身: 21 個のバイト（227, 129, 147, ...） ／ 長さ: `len(s)` は 21
- `[]rune(s)` → 中身: `こ` `ん` `に` `ち` `は` `世` `界` の 7 つの rune ／ 長さ: `len(r)` は 7

### サンプルを 1 行ずつ読む

- `r := []rune(s)` → 説明: r は 7 要素の rune のスライス
- `len(r)` → 出力: `文字数: 7` ／ 説明: 要素数＝文字数
- `string(r[0])` → 出力: `こ` ／ 説明: 0 番目の rune を文字列に戻して表示
- `string(r[5])` → 出力: `世` ／ 説明: 5 番目（0 から数えて 6 文字目）
- `string(r[5:7])` → 出力: `世界` ／ 説明: `[5:7]` は 5 番目から 6 番目まで（7 は含まない）を切り出す書き方。Python の `s[5:7]` と同じで、L07 で詳しく学びます

`string(...)` で戻さずに `fmt.Println(r[0])` と書くと、文字ではなく番号の `12371` が表示されます。rune の正体は番号だからです。

実行結果:

```text
文字数: 7
こ
世
世界
```

## ch04 strings.Repeat

Python の `"ab" * 3` のような文字列の掛け算は Go にはありません。代わりに `strings` パッケージの `strings.Repeat(s, n)` を使います。`strings` は文字列操作の関数を集めた標準ライブラリで、このあとのレッスンでも繰り返し登場します。⚪ 「* の代わりに strings.Repeat」と存在だけ知っておけば十分です。

Python ではこう書いた:

```python
print("=" * 10)
```

Go ではこう書く:

```go
import "strings"

fmt.Println(strings.Repeat("=", 10))
```

### 使うための準備

`strings` を使うには、L03 ch03 の `math` と同じく `import ( )` の中に `"strings"` を足します。

```go
import (
	"fmt"
	"strings"
)
```

### サンプルを 1 行ずつ読む

`strings.Repeat(s, n)` は「文字列 s を n 回つなげた新しい文字列」を戻り値として返します。

- `strings.Repeat("=", 20)`: `=` が 20 個の `====================`
- `"メニュー"`: `メニュー`
- `strings.Repeat("-*", 10)`: `-*` を 10 回で `-*-*-*-*-*-*-*-*-*-*`（20 文字）
- `line := strings.Repeat("=", 20)`: 戻り値を変数 line に入れておき、次の行で表示

実行結果:

```text
====================
メニュー
-*-*-*-*-*-*-*-*-*-*
====================
```

## ch05 fmt.Sprintf（f文字列の代わり）

Python の f文字列 `f"{name}さん"` に相当するのが `fmt.Sprintf` です。`Printf` と同じ書式（`%s` `%d` `%.1f` など）で文字列を**組み立てて返す**関数で、画面には出力しません。「表示するなら Printf、変数に入れるなら Sprintf」と使い分けます。🔴 実務でもコーディングテストでも頻出なので、手が覚えるまで書きましょう。

Python ではこう書いた:

```python
msg = f"{name}さんは{age}歳です"
```

Go ではこう書く:

```go
msg := fmt.Sprintf("%sさんは%d歳です", name, age)
```

### Printf と Sprintf の違い

名前の `S` は string（文字列）の S です。書式の書き方（L02 ch03 の `%s` `%d` `%.1f`）はまったく同じで、結果の行き先だけが違います。

- `fmt.Printf(...)` → 結果の行き先: 画面に表示する ／ 改行: 付かない（`\n` を書く）
- `fmt.Sprintf(...)` → 結果の行き先: 文字列として返す（戻り値）。画面には何も出ない ／ 改行: 付かない

### サンプルを 1 行ずつ読む

`name` は `"佐藤"`、`age` は `28`、`height` は `169.5` です。

- `msg := fmt.Sprintf("%sさんは%d歳です", name, age)`: msg に `佐藤さんは28歳です` が入る（まだ表示はされない）
- `fmt.Println(msg)`: `佐藤さんは28歳です` を表示
- `profile := fmt.Sprintf("身長 %.1f cm", height)`: profile に `身長 169.5 cm` が入る
- `fmt.Println(profile)`: `身長 169.5 cm` を表示
- `fmt.Println(msg + "（" + profile + "）")`: ふつうの文字列なので `+` でつなげられる

実行結果:

```text
佐藤さんは28歳です
身長 169.5 cm
佐藤さんは28歳です（身長 169.5 cm）
```
