# Lesson 09 多値とタプルの代替

Python入門編「タプル」に対応するレッスンです。**Go にタプルは存在しません**。`return a, b` に当たるのは多値返却、アンパックに当たるのは多値代入 `a, b := f()` で、「変更できない組」は配列 `[3]int` や構造体で代替します。

## ch01 Goにタプルはない（多値返却で代替）

**Go にタプルは存在しません。** Python では `return a, b` と書くとタプルが 1 つ返りましたが、Go では**多値返却**（関数が複数の値をそのまま返す仕組み）で代替します。戻り値の型は `(int, int)` のように並べて宣言します。返っているのは組というデータではなく「2 つの別々の値」です。`strconv.Atoi` の `(int, error)` もこの仕組みでした。🟡 タプルとの違いを理屈で理解しましょう。

Python ではこう書いた:

```python
def divmod2(a, b):
    return a // b, a % b  # タプルが 1 つ返る
```

Go ではこう書く:

```go
func divmod2(a, b int) (int, int) {
	return a / b, a % b // 2 つの値がそのまま返る
}
```

### 基礎の基礎: 自分で関数を作る書き方

ここまでは `main` 以外の関数を自分で作りませんでしたが、多値返却を見るために先取りします（詳しくは L18）。

```go
func divmod2(a, b int) (int, int) {
	return a / b, a % b
}
```

- `func`: 関数を定義する印（Python の `def`）
- `divmod2`: 関数の名前
- `(a, b int)`: 受け取る値（**引数**）の名前と型。`a int, b int` の省略形で、a も b も int です。Go では引数にも型を書きます
- `(int, int)`: 返す値（**戻り値**）の型。int を 2 つ返す、という宣言です。1 つだけ返すなら `int` と括弧なしで書きます
- `return a / b, a % b`: 商と余りの 2 つを返して、関数を終わります

関数は `func main` の外（前でも後でもよい）に書き、main の中から `divmod2(17, 5)` のように呼び出します。

### サンプルを 1 行ずつ読む

- `q, r := divmod2(17, 5)`: 17 ÷ 5 = 3 余り 2。1 つ目の戻り値 3 が q に、2 つ目の 2 が r に入る
- `fmt.Println(q)`: `3`
- `fmt.Println(r)`: `2`
- `fmt.Println(divmod2(9, 2))`: 戻り値の 4 と 1 が、そのまま Println の 2 つの引数として渡される。`4 1`

実行結果:

```text
3
2
4 1
```

### タプルと何が違うのか

Python の `t = divmod2(17, 5)` は、2 つの値を 1 つのタプルとして t に入れられました。Go の多値は 1 つの変数にまとめて入れることができず、`t := divmod2(17, 5)` はコンパイルエラーです。受け取るときは必ず戻り値の個数ぶん変数を並べます。

## ch02 多値代入とアンパック（a, b := f()）

Go にタプルは存在しないため、Python のアンパック `a, b = f()` に当たるのは**多値代入**です。`a, b := f()` で 2 つの戻り値を一度に受け取り、いらない値は `_`（ブランク識別子。受け取って捨てるための名前）に入れます。値の入れ替え `a, b = b, a` は Python とまったく同じ構文で書けます。🟡 タプルを経由せず、値が変数へ直接入ることを理解しましょう。

Python ではこう書いた:

```python
low, high = minmax()
a, b = b, a
```

Go ではこう書く:

```go
low, high := minmax()
a, b = b, a
```

### サンプルを 1 行ずつ読む

サンプルの `func minmax() (int, int)` は、引数なしで 1 と 9 を返す関数です（関数の書き方は ch01）。

- `low, high := minmax()`: low に 1、high に 9
- `fmt.Println(low, high)`: `1 9`
- `_, top := minmax()`: 1 つ目の 1 は `_` で捨て、top に 9
- `fmt.Println(top)`: `9`
- `a, b := 10, 20`: a に 10、b に 20
- `a, b = b, a`: 右辺の `b, a`（20 と 10）を先にすべて計算してから、a に 20、b に 10 を入れる
- `fmt.Println(a, b)`: `20 10`

実行結果:

```text
1 9
9
20 10
```

### 入れ替えが一時変数なしでできる理由

`a, b = b, a` は、右辺の値を全部取り出し終わってから左辺に入れます。もし `a = b` と `b = a` を 2 行に分けると、1 行目で a が 20 に上書きされるため、2 行目で b にも 20 が入ってしまいます。

### 個数が合わないとき

`x := minmax()` のように受け取る変数の数が戻り値の数と違うと、`assignment mismatch: 1 variable but minmax returns 2 values`（変数 1 つに対して戻り値が 2 つ）というコンパイルエラーになります。

## ch03 配列 [3]int（固定長・値型）

Go にタプルはありませんが、見た目が近いものに**配列**があります。`[3]int` は長さ 3 で固定された並びで、長さまで型の一部です（`[3]int` と `[4]int` は別の型）。追加も削除もできません。また**値型**（代入すると中身ごとコピーされる型）なので、コピー先を変えても元は変わりません。Python のタプルと違い、要素の書き換えは可能です。ふだんはスライスを使うため、⚪ 配列は「固定長・値型」という性質を知っておくだけで十分です。

Python ではこう書いた:

```python
t = (1, 2, 3)  # タプル。長さ固定
```

Go ではこう書く:

```go
a := [3]int{1, 2, 3} // 配列。長さ 3 で固定
```

### 配列とスライスの見分け方

違いは `[ ]` の中に数字があるかどうかだけです。

- `[3]int{1, 2, 3}` → 種類: 配列 ／ 長さ: 3 で固定。append できない ／ `b := a` したとき: 中身ごとコピーされる（別物になる）
- `[]int{1, 2, 3}` → 種類: スライス（L07） ／ 長さ: append で伸ばせる ／ `b := a` したとき: 中身を共有する（L07 ch08）

### サンプルで a と b がどう変わるか

- `a := [3]int{1, 2, 3}` → a: `[1 2 3]`
- `b := a` → a: `[1 2 3]` ／ b: `[1 2 3]`（コピー）
- `b[0] = 99` → a: `[1 2 3]` ／ b: `[99 2 3]`

実行結果:

```text
[1 2 3]
3
[99 2 3]
[1 2 3]
```

2 行目の `3` は `len(a)` です。最後の行で a が変わっていないことが、値型（コピー）である証拠です。

## ch04 構造体で「組」を表す

**Go にタプルは存在しない**ため、Python で `p = (3, 5)` と書いた「座標の組」のようなデータは**構造体**（複数の値に名前を付けてひとまとめにする型）で表します。`type Point struct { X, Y int }` と型を定義し、`p[0]` のような位置番号ではなく `p.X` と**名前**でアクセスします。構造体も値型なので、代入するとコピーされて元は守られます。なお、タプルと違って構造体の中身（`p.X` など）は書き換えられます。🟡 「組は構造体で表す」という Go の設計を理解しましょう。

Python ではこう書いた:

```python
p = (3, 5)
print(p[0])
```

Go ではこう書く:

```go
p := Point{X: 3, Y: 5}
fmt.Println(p.X)
```

### 型の定義を 1 行ずつ読む（L21 の先取り）

```go
type Point struct {
	X int
	Y int
}
```

- `type Point`: `Point` という名前の新しい型を作る宣言
- `struct { ... }`: 中身が「名前の付いた値の集まり」である型、という意味
- `X int`: `X` という名前の int の値を持つ。中の 1 つ 1 つを**フィールド**と呼びます

この定義は `func main` の外に書きます。定義したあとは `int` や `string` と同じように型の名前として使えます。

### 値の作り方と取り出し方

- `p := Point{X: 3, Y: 5}`: X が 3、Y が 5 の Point を作って p に入れる。`フィールド名: 値` を並べます
- `p.X`: p の X フィールドを取り出す（`3`）。`.` は「p の中の X」という意味
- `q.X = 100`: q の X フィールドだけを書き換える

### サンプルの実行結果

- `fmt.Println(p.X)`: `3`
- `fmt.Println(p.Y)`: `5`
- `q := p` のあと `q.X = 100`、`fmt.Println(p.X)`: `3`（q はコピーなので p は変わらない）

```text
3
5
3
```

`fmt.Println(p)` と書くと、構造体は `{3 5}` と表示されます。
