# Lesson 12 for（while相当）

Python入門編「while文」に対応するレッスンです。Go に `while` はなく、`for 条件 {}` と無限ループの `for {}` が while の役割を兼ねます。`break` と `continue` は Python と同じ単語です。

## ch01 for 条件 {}（while の代わり）

Go に `while` はありません。繰り返しはすべて `for` が担当し、`for 条件 {}` と書くと Python の `while 条件:` と同じ動きになります。条件に括弧は不要で、ブロックは `{}` で囲みます。条件が false になるまで本体を繰り返すため、本体でカウンタを更新し忘れると止まらなくなる点も while と同じです。なお Python の `i += 1` は Go では `i++` とも書けます。🔴 while の置き換えとして最頻出の形なので、手が覚えるまで書きましょう。

Python ではこう書いた:

```python
i = 1
while i <= 3:
    print(i)
    i += 1
```

Go ではこう書く:

```go
i := 1
for i <= 3 {
	fmt.Println(i)
	i++
}
```

### 用語と記号の確認

- **ループ**: 同じ処理を繰り返すこと、またはその繰り返しの仕組みです
- **カウンタ**: 何回目かを数えるための変数（ここでは i）です
- `i++`: i に 1 を足します。`i += 1`、`i = i + 1` と同じ意味です。1 を引くのは `i--` です。Go の `i++` は 1 つの文なので、`x := i++` のように値として使うことはできません
- `i += 3`: i に 3 を足します（L04 ch03）

### 繰り返しの流れ

`for 条件 { 本体 }` は次の順で動きます。

1. 条件を調べる。false なら for を抜けて、`}` の次の行へ進む
2. true なら本体を上から最後まで実行する
3. 1 に戻る

### サンプルで i がどう変わるか

- 1 回目: 条件 `1 <= 3` は true → `1` を出力 → i が 2 になる
- 2 回目: `2 <= 3` は true → `2` を出力 → i が 3 になる
- 3 回目: `3 <= 3` は true → `3` を出力 → i が 4 になる
- 4 回目の確認: `4 <= 3` は false → ループを抜ける

サンプル後半の `for n < 10 {` は、最初に条件 `10 < 10` を調べた時点で false なので、本体は 1 回も実行されません。

実行結果:

```text
1
2
3
おわり
```

### 止まらなくなったとき

`i++` を書き忘れると i が 1 のまま条件がずっと true になり、プログラムが終わりません（**無限ループ**）。ターミナルで実行中なら `Ctrl + C` で強制終了できます。

## ch02 for {} 無限ループと break

条件を書かない `for {}` は無限ループになり、Python の `while True:` に相当します。抜けるには `break`（いま実行中のループを即座に終了する文）を使います。単語は Python と同じです。「無限ループの中で処理し、条件を満たしたら break で抜ける」という形は、後で学ぶ標準入力の処理でも使う定番の書き方です。🟡 break が終わらせるのはループ 1 つ分だけ、という範囲を理解しましょう。

Python ではこう書いた:

```python
while True:
    total += 3
    if total >= 12:
        break
```

Go ではこう書く:

```go
for {
	total += 3
	if total >= 12 {
		break
	}
}
```

### break で飛ぶ先

`break` が実行されると、本体の残りを実行せずに、そのループの閉じ `}` の次の行へ進みます。`if` の `}` ではなく、`for` の `}` の次です。

### サンプルで count がどう変わるか

`count++` は count に 1 を足す書き方です（L12 ch01）。

- 1 周目: count が 1 → `count = 1` を出力 → `1 == 3` は false なので続ける
- 2 周目: count が 2 → `count = 2` を出力 → false なので続ける
- 3 周目: count が 3 → `count = 3` を出力 → `3 == 3` は true なので break
- for の `}` の次の行へ進み、`ループを抜けました` を出力

実行結果:

```text
count = 1
count = 2
count = 3
ループを抜けました
```

演習で使う `total += 3` は「total に 3 を足す」です（L04 ch03）。

## ch03 continue（次の繰り返しへ進む）

`continue` は、ループ本体の残りを飛ばして次の繰り返しへ進む文です。意味は Python と同じですが、`for 条件 {}` の形で使うときは注意が必要です。カウンタの更新より前に `continue` すると更新まで飛ばされ、無限ループになります。更新を本体の先頭に書いてから continue するのが安全な形です。🟡 continue がどこへ飛ぶのかを、カウンタ更新の位置とあわせて理解しましょう。

Python ではこう書いた:

```python
i = 0
while i < 5:
    i += 1
    if i == 3:
        continue
    print(i)
```

Go ではこう書く:

```go
i := 0
for i < 5 {
	i++
	if i == 3 {
		continue
	}
	fmt.Println(i)
}
```

### break と continue の違い

- `break`: ループそのものを終わらせ、for の `}` の次の行へ進む（ch02）
- `continue`: 今回の周回の残りだけを飛ばし、for の先頭（条件の確認）へ戻る。ループは続く

### サンプルで i がどう変わるか

- 1 周目: 条件 `0 < 5` は true → i が 1 → 3 ではない → `1` を出力
- 2 周目: i が 2 → `2` を出力
- 3 周目: i が 3 → `i == 3` は true なので continue。Println を飛ばして先頭へ
- 4 周目: i が 4 → `4` を出力
- 5 周目: i が 5 → `5` を出力
- 次の確認: `5 < 5` は false → ループを抜けて `おわり` を出力

実行結果:

```text
1
2
4
5
おわり
```

### 更新が後ろにあると止まらない理由

次のように `i++` を最後に置くと、i が 3 になった周で continue が `i++` まで飛ばしてしまい、i は 3 のまま、条件 `3 < 5` は true のまま、毎回また continue …と同じことが永遠に続きます。

```go
i := 1
for i < 5 {
	if i == 3 {
		continue // i++ に届かない
	}
	fmt.Println(i)
	i++
}
```

演習では「偶数かどうか」を `i%2 == 0`（2 で割った余りが 0、L10 ch01）で判定します。

## ch04 ループのネスト

ループの中にループを書く**ネスト**（入れ子構造のこと）は、Python と同じ考え方で `for` を重ねるだけです。外側が 1 周する間に、内側は最後まで回ります。内側で `break` や `continue` を使うと、内側のループだけに効きます。Python で二重ループを一気に抜けるにはフラグ変数が必要でしたが、Go にはラベルという目印があり、`break outer` のように外側ごと抜けられます。🟡 いま内側と外側のどちらが回っているのかを追えるようになりましょう。

Python ではこう書いた:

```python
for i in range(1, 3):
    for j in range(1, 4):
        print(i, j)
```

Go ではこう書く:

```go
i := 1
for i <= 2 {
	j := 1
	for j <= 3 {
		fmt.Println(i, j)
		j++
	}
	i++
}
```

### サンプルで i と j がどう変わるか

外側の i が 1 のとき、内側で j が 1, 2 と回ってから内側を抜け、i が 2 になります。内側に入るたびに `j := 1` で j は 1 から作り直されます。

```text
i=1 → j=1, j=2 → 内側を抜けて i++
i=2 → j=1, j=2 → 内側を抜けて i++
i=3 → j=1, j=2 → 内側を抜けて i++
i=4 → 外側の条件 4 <= 3 が false で終了
```

出力は 3 × 2 = 6 行です。`Printf` の `%d` と `\n` は L02 ch03 で学んだ書式指定です。

```text
i=1 j=1
i=1 j=2
i=2 j=1
i=2 j=2
i=3 j=1
i=3 j=2
ネストおわり
```

`j := 1` を外側のループの前に 1 回だけ書くと、2 周目以降の j は 3 から始まって内側が 1 回も回らなくなります。内側のカウンタは内側のループの直前で毎回作るのがポイントです。

### ラベルで外側ごと抜ける

ループの前に `名前:` と書くと、そのループに名前（**ラベル**）が付きます。`break 名前` はそのループごと抜けます。

```go
i := 1
outer:
for i <= 3 {
	j := 1
	for j <= 3 {
		if i*j == 4 {
			break outer // 内側だけでなく、outer と名付けた外側のループも抜ける
		}
		fmt.Println(i, j)
		j++
	}
	i++
}
fmt.Println("抜けた")
```

実行結果（i=2、j=2 で `2*2 == 4` になった時点で両方のループを抜けます）:

```text
1 1
1 2
1 3
2 1
抜けた
```

ラベルなしの `break` なら内側だけを抜けて、外側は i=3 の周に進みます。
