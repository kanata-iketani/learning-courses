# AWSセキュリティどうじょう カリキュラム(全24レッスン)

## ゴール
**セキュリティの超初心者を、AWS のセキュリティを実務で設計・運用・説明できるプロに育てる。** その延長線上で AWS Certified Security - Specialty(SCS-C03)に合格できる状態にする。資格は目的ではなく結果。

対象: Python を少し書いた程度のエンジニア。セキュリティ・ネットワーク・暗号・AWS の基礎は浅い。前提知識ゼロでも読めるようにする。

## 章立ての方針
SCS-C03 の6分野・16項目(外部の問題集の分類と同じ並び)に1レッスンずつ対応させる。ただし学ぶ順番は、土台になる IAM・暗号を先にする。最初の4レッスンは「基礎の基礎」。

| 分野 | 項目 | レッスン |
|---|---|---|
| 分野1 検知 | ロギングの設計と実装 / モニタリングとアラート / モニタリングとロギングのトラブルシューティング | L13 / L14 / L15 |
| 分野2 インシデント対応 | インシデント対応計画の策定とテスト / セキュリティイベントへの対応 | L16 / L17 |
| 分野3 インフラストラクチャのセキュリティ | ネットワークセキュリティ / ネットワークエッジのセキュリティ / コンピューティングワークロードのセキュリティ | L10 / L11 / L12 |
| 分野4 アイデンティティとアクセス管理 | 認証戦略 / 認可戦略 | L5 / L6 |
| 分野5 データ保護 | 保管中データの保護 / 転送中データの保護 / 機密データ・シークレット・暗号化キーの保護 | L7 / L8 / L9 |
| 分野6 セキュリティの基盤とガバナンス | アカウントの一元管理 / セキュアで一貫したデプロイ戦略 / リソースのコンプライアンス評価 | L18 / L19 / L20 |

## 各レッスンの形
- 各チャプター 20〜30 分で読み終わる分量(本文 3000〜6000 字)。1レッスン 3〜4 チャプター
- 各チャプターの流れ: **基礎**(前提ゼロから)→ **AWS での仕組み**(ポリシーの JSON・CLI の出力・ログの1行など実物で)→ **実務での使い方と判断**(案の比較・よくある事故・プロならどうするか)→ **試験ではこう問われる** → まとめ
- 問題: SCS 形式のシナリオ4択(「最も運用負荷が低い」「最小権限で」など)+ 記述式(AI 採点)。模擬試験は別レッスン
