# lesson03 ch01 演習: variableとvar.

variable `project` を定義してください。`type` は `string`、`default` は `"myapp"` とします。さらに output `project_name` で `var.project` を表示してください。

(ヒント: `type = string` の `string` は引用符で囲みません。`default` の値は文字列なので `"..."` で囲みます。この講座の `▶ 実行` では外から値を渡せないので、default の値がそのまま表示されます)

**期待出力**

```text
project_name = "myapp"
```
