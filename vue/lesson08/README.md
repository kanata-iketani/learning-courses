# Lesson 08 JavaScript基礎5：関数

処理に名前を付けて使い回す「関数」を学びます。Python の def にあたるものです。特にアロー関数とコールバックは、Vue のイベント処理や map / filter で毎回登場する書き方なので、ここでしっかり慣れておきましょう。

## ch01 function 宣言と呼び出し

**関数**は、ひとまとまりの処理に名前を付けて何度でも使えるようにする仕組みです。Python の `def greet():` は、JavaScript では `function greet() { }` と書きます。定義しただけでは何も起きず、`greet();` のように**呼び出し**(関数名に `( )` を付けて実行させること)をして初めて中の処理が動きます。同じ処理を 2 回書きたくなったら関数にまとめるのが基本です。🔴 「定義しただけでは動かない。呼び出して動く」を覚えましょう。

```js
// Python: def greet():
function greet() {
  console.log("こんにちは");
}
greet();  // ここで初めて実行される
```

### 定義の部品

| 部品 | 意味 |
|---|---|
| `function` | 「これから関数を定義します」というキーワード |
| `greet` | 関数の名前。変数と同じくキャメルケース(`showMenu` のように 2 語目の頭を大文字)で付けます |
| `()` | 受け取る値(引数)を書く場所。今回は何も受け取らないので空です。引数は次の ch02 で学びます |
| `{` 〜 `}` | 関数の**本体**。呼び出されたときに実行する処理を書きます |

L05 の if と同じく、範囲はインデントではなく `{ }` で決まります。

### 呼び出しの部品

`greet();` は、関数名 `greet` の後に `()` を付けて「いま実行して」と命じる書き方です。`()` を忘れて `greet;` と書くと、何も実行されません。

### サンプルが動く順番

Node.js は上から順に読みますが、関数の定義は「覚えておく」だけで、中身はまだ実行しません。

1. `function greet() { … }` を読み、greet という関数を覚える(何も表示しない)
2. `greet();` → greet の本体へ移り、`こんにちは` を表示 → 呼び出した行に戻る
3. `greet();` → もう一度本体を実行して `こんにちは` を表示
4. `function showMenu() { … }` を覚える(何も表示しない)
5. `showMenu();` → 本体の 3 行を上から実行して、3 行を表示

実行結果(Node.js で実際に動かした出力):

```text
こんにちは
こんにちは
--- メニュー ---
1. コーヒー
2. 紅茶
```

関数の本体が実行されるのは、呼び出しを書いた回数と同じだけです。演習では `morningCall();` を 2 回書くので、本体の 2 行が 2 回分、合計 4 行が出ます。

### 補足: 定義より前で呼んでもよい

`function` で定義した関数は、ファイルの中で定義より上の行から呼び出しても動きます(JavaScript が実行の前にファイル全体の function 定義を先に読み込むため)。それでも、読みやすさのために「定義してから呼ぶ」順で書くのがおすすめです。

## ch02 引数と戻り値

**引数**(関数に渡す値。`( )` の中で受け取る)と**戻り値**(`return` で呼び出し元に返す値)を使うと、関数が「値を受け取って値を返す」部品になります。戻り値は変数に入れたり、そのまま console.log に渡したりできます。`return` を実行するとその場で関数が終わるため、return より後の行は動きません。このあたりの考え方は Python とまったく同じです。🔴 「console.log は画面に表示するだけ、return は値を呼び出し元に返す」という違いを意識しましょう。

```js
function add(a, b) {
  return a + b;  // Python: return a + b
}
const sum = add(3, 5);  // sum は 8
```

### 値の受け渡しを追う

`const sum = add(3, 5);` は次の順で動きます。

1. `add(3, 5)` で add を呼び出す。1 つ目の値 3 が `a` に、2 つ目の値 5 が `b` に入る(順番で対応します)
2. 本体の `return a + b;` を実行。`a + b` は 3 + 5 で 8
3. `return` が 8 を呼び出し元に返し、関数はここで終わる
4. 呼び出した場所 `add(3, 5)` が 8 に置き換わったと考えて、`const sum = 8;` が実行される

`a` と `b` は関数の中だけで使える変数で、呼び出すたびに新しい値が入ります。`add(10, 20)` なら a が 10、b が 20 です。

### サンプルの実行結果

```text
こんにちは、たろうさん
こんにちは、はなこさん
8
30
```

| 呼び出し | 引数 | 関数の中で起きること | 出力 |
|---|---|---|---|
| `greet("たろう")` | name = `"たろう"` | console.log で表示する(return は無い) | `こんにちは、たろうさん` |
| `greet("はなこ")` | name = `"はなこ"` | 同じ | `こんにちは、はなこさん` |
| `add(3, 5)` | a = 3, b = 5 | 8 を返す。sum に入り、次の行で表示 | `8` |
| `add(10, 20)` | a = 10, b = 20 | 30 を返す。それを console.log が表示 | `30` |

### console.log と return の違い

| | console.log | return |
|---|---|---|
| 何をするか | 画面に文字を出す | 呼び出し元に値を返す |
| その値を後で計算に使えるか | 使えない | 使える(`add(1, 2) * 10` など) |

`greet` のように return を書かない関数を `console.log(greet("たろう"))` と表示させると、`こんにちは、たろうさん` の次の行に `undefined` が出ます。return が無い関数は、値が無いことを表す `undefined`(L07 ch01)を返すからです。

### return の後の行は動かない

```js
function add(a, b) {
  return a + b;
  console.log("ここは表示されない");  // return で関数が終わるので実行されない
}
```

### 引数を渡し忘れると

`greet()` のように引数を渡さずに呼ぶと、エラーにはならず、name は `undefined` になります。表示は `こんにちは、undefinedさん` です。表示に `undefined` が出たら、引数の渡し忘れを疑います。

## ch03 アロー関数 〜 =>

**アロー関数**は `=>` を使った関数の短い書き方で、`const add = (a, b) => a + b;` のように変数に入れて使います。処理が 1 行の式なら `{ }` と `return` を省略でき、`=>` の右の式がそのまま戻り値になります。複数行の処理を書くときは `{ }` で囲んで `return` を書きます。前レッスンの map / filter に渡していたのがまさにこの形で、Vue のイベント処理でも最もよく見る書き方です。🔴 「function 宣言と同じもの、短く書けるだけ」と理解した上で `=>` の形に目を慣らしましょう。

```js
function add1(a, b) { return a + b; }  // function 宣言
const add2 = (a, b) => a + b;          // 同じ意味のアロー関数
```

### `const add2 = (a, b) => a + b;` を部品に分ける

| 部品 | 意味 |
|---|---|
| `const add2 =` | 変数 add2 を作り、右側の関数を入れる。呼ぶときは `add2(2, 3)` |
| `(a, b)` | 受け取る引数。function 宣言の `function add1(a, b)` の `(a, b)` と同じ |
| `=>` | 「引数を受け取って、右側を実行する」という印。`=` と `>` を続けて書きます(アローは矢印の意味) |
| `a + b` | 計算結果がそのまま戻り値になる。`return` は書かない |
| `;` | 変数を作る文の終わり |

JavaScript では、関数も数値や文字列と同じく変数に入れられる「値」です。アロー関数は名前を持たないので、変数に入れて名前を付けます。

### 省略のルール

| 書き方 | 使える場面 | 例 |
|---|---|---|
| `( )` を省略 | 引数がちょうど 1 つ | `n => n * 2` |
| `( )` が必要 | 引数が 0 個、または 2 つ以上 | `() => "やあ"`、`(a, b) => a + b` |
| `{ }` と `return` を省略 | 本体が 1 つの式 | `n => n * 2` |
| `{ }` と `return` が必要 | 本体が複数行 | 下の `hello` |

```js
const hello = (name) => {
  const message = `こんにちは、${name}さん`;
  return message;
};
```

`{ }` で囲んだ場合は、L08 ch02 の function と同じく `return` を書かないと値が返りません。`const bad = (a, b) => { a + b };` は `bad(1, 2)` が `undefined` になります(Node.js で確認済み)。`{ }` を付けたら `return` も付ける、と覚えます。

### サンプルの実行結果

```text
5
5
20
こんにちは、みきさん
```

- 1・2 行目: `add1(2, 3)` と `add2(2, 3)` は書き方が違うだけで、どちらも 5 を返します
- 3 行目: `double(10)` は n に 10 が入り、`10 * 2` の 20 を返します
- 4 行目: `hello("みき")` は本体の 2 行を実行し、`return message;` で文字列を返します

### function 宣言との違い(1 つだけ)

`const` で作ったアロー関数は、定義の行より前で呼び出すとエラー(`ReferenceError: Cannot access 'add2' before initialization`)になります。L08 ch01 の function 宣言と違い、定義してから呼ぶ順番を守ります。

## ch04 コールバック 〜関数を渡す

JavaScript では、関数を値として別の関数に渡せます。渡された側で呼び出される関数を**コールバック**と呼びます。代表例が配列の **forEach**(各要素を順にコールバックに渡して実行するメソッド)です。前レッスンの map / filter も、実はコールバックを受け取るメソッドでした。Vue の「ボタンが押されたらこの関数を実行」というイベント処理も、この「関数を渡す」発想でできています。🟡 いまは forEach の形を写して動かし、「関数そのものを渡している」感覚をつかみましょう。

```js
const names = ["さくら", "たろう"];
names.forEach(name => {
  console.log(`${name}さん、こんにちは`);
});
```

### 関数を「渡す」と「呼ぶ」の違い

| 書き方 | 意味 |
|---|---|
| `hello` | 関数そのもの(値として扱う。まだ実行しない) |
| `hello()` | 関数をいま実行して、その戻り値を得る |

コールバックとして渡すときは、`()` を付けずに関数そのものを渡します。`names.forEach(name => { … })` は、`name => { … }` というアロー関数(L08 ch03)をその場で作り、forEach に渡しています。実行するのは forEach の側です。

### forEach の動き

`names.forEach(コールバック)` は、配列の要素を先頭から 1 つずつコールバックに渡して呼び出します。

| 回 | コールバックの name | 実行される行 | 表示 |
|---|---|---|---|
| 1 | `"さくら"` | `console.log(…)` | `さくらさん、こんにちは` |
| 2 | `"たろう"` | `console.log(…)` | `たろうさん、こんにちは` |

L06 ch03 の `for (const name of names) { … }` と同じ結果になります。forEach は配列のメソッドなので、配列名の後ろに `.forEach(...)` と付けて書きます。map と違って新しい配列は作らず、戻り値は `undefined` です。

### 2 つ目の引数 index

コールバックに引数を 2 つ書くと、forEach は 2 つ目に添字(L07 ch01。0 から始まる番号)を入れてくれます。

```js
names.forEach((name, index) => {
  console.log(`${index}: ${name}`);
});
```

| 回 | name | index | 表示 |
|---|---|---|---|
| 1 | `"さくら"` | 0 | `0: さくら` |
| 2 | `"たろう"` | 1 | `1: たろう` |

引数は順番で決まります。1 つ目が要素、2 つ目が添字です。名前は自由ですが、`(index, name)` と逆に書くと、index という名前の変数に要素が入ってしまいます。

### 自作の関数で関数を受け取る

```js
function repeat(times, action) {
  for (let i = 0; i < times; i++) {
    action();  // 渡された関数をここで呼び出します
  }
}
repeat(2, () => console.log("ワン！"));
```

1. `repeat(2, () => console.log("ワン！"))` を呼ぶ。times に 2、action に「`ワン！` を表示する関数」が入る
2. for で i が 0 と 1 の 2 回くり返し、そのたびに `action()` で受け取った関数を実行する
3. `ワン！` が 2 回表示される

`() =>` は「引数を 1 つも受け取らない」アロー関数です。repeat は「何をくり返すか」を知らず、渡された関数を呼ぶだけです。何をするかを呼び出す側が決められる点がコールバックの便利なところです。

サンプルの実行結果(Node.js で実際に動かした出力):

```text
さくらさん、こんにちは
たろうさん、こんにちは
0: さくら
1: たろう
ワン！
ワン！
```

### 演習のヒント

index は 0 から始まるので、1 から番号を付けるには `${index + 1}` と書きます。`${ }` の中では計算ができます(L04 ch04)。
