# lesson09 ch01 演習: DOM とは・getElementById と textContent

JavaScript だけを使って「プロフィールカード」の中身を埋めましょう。HTML 側の要素は空のままにして、`getElementById` と `textContent` で名前と趣味を書き込んでください。

**確認ポイント**

1. プレビューに自分の名前が表示される(`id="name"` の要素に JS で書き込む)
2. プレビューに自分の趣味が表示される(`id="hobby"` の要素に JS で書き込む)
3. HTML 側の `<span>` タグの中は空のままである(文字はすべて `<script>` 内で書き込んでいる)

すべて満たせたら「✔ できた」を押してください。
