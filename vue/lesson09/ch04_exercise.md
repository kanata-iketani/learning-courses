# lesson09 ch04 演習: classList で見た目を切り替える

「重要マーカー」を作りましょう。ボタンを押すたびに、文章に `highlight` class が付いたり外れたりして、黄色いマーカーが引かれたり消えたりするようにしてください。CSS の `.highlight` は starter に用意してあります。JS 側は `classList.toggle` を使います。

**確認ポイント**

1. 最初はマーカーが引かれていない
2. ボタンを押すと文章に黄色いマーカーが引かれる
3. もう一度押すとマーカーが消える(何度でも切り替わる)

すべて満たせたら「✔ できた」を押してください。
