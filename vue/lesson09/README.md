# Lesson 09 DOMとイベント

JavaScript からページの中身を読み書きするしくみ(DOM)と、クリックなどの出来事(イベント)に反応する方法を学びます。ここで「JS で画面を書きかえる大変さ」を体験しておくと、次のレッスンで学ぶ Vue のありがたみがよく分かります。

## ch01 DOM とは・getElementById と textContent

**DOM**(Document Object Model。ブラウザが HTML を読み込んで作る「ページの部品の一覧表」)を使うと、JavaScript からページの中身を読み書きできます。`document.getElementById("ID名")` で **要素**(タグ 1 つ分の部品)を取り出し、`textContent` でその中の文字を読み書きします。🔴 「取り出して、書きかえる」の 2 ステップは今後ずっと使う基本なので、手が覚えるまで練習しましょう。

```js
// id="msg" の要素を取り出して、文字を書きかえる
const el = document.getElementById("msg");
el.textContent = "こんにちは！";
```

HTML 側の要素には目印として `id` 属性を付けておきます。

### 基礎の基礎: HTML の中で JS が動くタイミング

`<script>` タグの中に書いた JavaScript は、ブラウザが HTML を上から順に読んでいき、その `<script>` まで来たときに実行されます。サンプルで `<script>` を `<body>` のいちばん最後に置いているのは、上にある `<h1>` や `<p>` が先にできあがっている状態で JS を動かすためです。`<script>` を先頭に置くと、まだ要素ができていないので `getElementById` は `null`(「何もない」を表す値)を返し、書きかえに失敗します。

### DOM の中身の例

ブラウザは、次の HTML を読み込むと、タグ 1 つずつを「要素」として一覧に登録します。

```html
<h1 id="greeting">(ここは JS が書きかえます)</h1>
<p>今日は <span id="today">?</span> です。</p>
```

| タグ | id | いまの textContent |
|---|---|---|
| `<h1>` | `greeting` | `(ここは JS が書きかえます)` |
| `<p>` | (なし) | `今日は ? です。` |
| `<span>` | `today` | `?` |

`getElementById` は、この一覧から id が一致する要素を 1 つ探して返します。id は 1 ページの中で重複させないのが決まりです。

### 記法を 1 つずつ

- `document`: いま表示しているページ全体を表すオブジェクトです。ブラウザが最初から用意しているので、宣言せずに使えます
- `.getElementById("msg")`: document のメソッド(L7 で見た「オブジェクトに属する関数」)です。id が `msg` の要素を返します。引数には `#` を付けず、id の名前だけを書きます
- `const el = ...`: 取り出した要素を変数に入れておきます(L4 で見た const)。同じ要素を何度も使うときに便利です
- `el.textContent = "こんにちは！"`: 要素の中の文字を丸ごと置きかえます。`=` の右に書いた文字列が、そのまま画面に出ます。`el.textContent` と読むだけなら、いまの文字を取り出せます

### サンプルを 1 行ずつ

- `const greeting = document.getElementById("greeting");`: id が `greeting` の `<h1>` を取り出します
- `greeting.textContent = "こんにちは、DOM！";`: その中の文字を書きかえます。画面の見出しが「こんにちは、DOM！」に変わります
- `const now = new Date();`: `new Date()` は「いまの日時」を表すオブジェクトを作る書き方です
- `(now.getMonth() + 1) + "月" + now.getDate() + "日"`: `getMonth()` は月を **0 始まり**(1 月が 0、11 月が 10)で返すので 1 を足します。`getDate()` は日にちです。数と文字列を `+` でつなぐと文字列になり、たとえば `"11月13日"` ができます
- `document.getElementById("today").textContent = todayText;`: 変数に入れずに、取り出してすぐ書きかえる書き方です

### 画面はどう変わるか

| 要素 | HTML に書いた文字 | JS 実行後の表示 |
|---|---|---|
| 見出し | (ここは JS が書きかえます) | こんにちは、DOM！ |
| 日付 | 今日は ? です。 | 今日は 11月13日 です。(開いた日による) |
| メッセージ | (空) | この文章は JavaScript が書き込みました。 |

JS は一瞬で実行されるので、プレビューでは最初から書きかえ後の文字が見えます。

## ch02 ボタンと addEventListener("click")

**イベント**(クリックやキー入力など、ページ上で起きる出来事)に反応するには、要素の `addEventListener("click", 関数)` を使います。「この要素がクリックされたら、この関数を実行して」という予約です。渡す関数には、L8 で見たアロー関数がよく使われます。🔴 「イベントが起きたら関数が動く」という流れは Vue でもそのまま登場する重要な考え方です。

```js
const btn = document.getElementById("btn");
btn.addEventListener("click", () => {
  // クリックされるたびに、ここが実行される
  document.getElementById("msg").textContent = "押されました！";
});
```

### 記法を 1 つずつ

- `btn.addEventListener(...)`: 要素 btn に「イベントが起きたときの処理」を登録するメソッドです
- 1 つ目の引数 `"click"`: どのイベントを待つかを文字列で指定します。`"click"` はクリックです
- 2 つ目の引数 `() => { ... }`: イベントが起きたときに呼ばれる関数です。L8 ch03 で見たアロー関数(引数なし)を、L8 ch04 で見たコールバックとして渡しています
- `});` の閉じ方: `{` はアロー関数の中身の終わり、`)` は addEventListener の引数の終わりです

大事なのは、**登録した時点では `{ }` の中は実行されない**ことです。ページを開いたときには「予約」だけが行われ、クリックされるたびに中身が 1 回ずつ実行されます。

### サンプルを 1 行ずつ

- `const results = ["大吉", "中吉", "小吉", "末吉", "凶"];`: おみくじの結果を配列で用意します(L7)
- `const btn = document.getElementById("draw-btn");`: ボタンの要素を取り出します
- `Math.random()`: 0 以上 1 未満のランダムな小数を返します
- `Math.random() * results.length`: 配列の長さ 5 をかけて、0 以上 5 未満の小数にします
- `Math.floor(...)`: 小数点以下を切り捨てます。これで 0〜4 の整数になり、配列の添字(L7 で見た「何番目か」の番号)として使えます
- `"結果: " + results[i]`: 選ばれた結果を文字列につなげて表示します

| Math.random() の値 | × 5 | Math.floor | 表示 |
|---|---|---|---|
| 0.12 | 0.6 | 0 | 結果: 大吉 |
| 0.73 | 3.65 | 3 | 結果: 末吉 |
| 0.99 | 4.95 | 4 | 結果: 凶 |

### 画面はどう変わるか

| いつ | 起きること | 表示 |
|---|---|---|
| ページを開いた | 関数を登録するだけ | ボタンを押してください |
| 1 回目のクリック | 関数が実行される | 結果: 中吉(例) |
| 2 回目のクリック | 関数がもう一度実行される | 結果: 凶(例) |

演習のカウンターでは、回数を `let` で作った変数に覚えておきます。書きかえる(再代入する)変数なので const ではなく let です。1 増やすには `count = count + 1;` か、L6 の for 文で見た `count++;` を使います。表示は `count + " 回"` のように数と文字列をつなげます。

## ch03 input の値を読む(.value)

`<input>`(文字や数を入力する欄)にユーザーが入力した内容は、要素の `.value` プロパティで取り出せます。取り出した値は必ず**文字列**なので、数として計算したいときは `Number()` で変換します。🔴 「入力欄から .value で読む → 加工する → textContent で表示する」の流れは、フォームを扱うページの基本形です。

```js
const input = document.getElementById("name-input");
btn.addEventListener("click", () => {
  const name = input.value;  // 入力された文字列
  msg.textContent = "こんにちは、" + name + "さん！";
});
```

(`btn` と `msg` は、ch02 と同じように getElementById で取り出してある前提です)

### textContent と value の違い

`<p>` や `<span>` は、文字を `<p>ここ</p>` のようにタグの間に持つので `textContent` で読みます。一方 `<input>` は閉じタグがなく、打ち込まれた文字は要素の中に別に保存されます。それを読むのが `.value` です。

### 記法を 1 つずつ

- `input.value`: いま入力欄に書かれている文字列です。何も書かれていなければ空文字 `""` です
- `placeholder="名前を入力"`: 入力欄が空のときにうすく出る案内文です。value には入りません
- `type="number"`: 数字を入力するための欄にします。ただし、それでも `.value` は文字列です
- `Number("3")`: 文字列を数に変換する関数です

| 式 | 結果 | 説明 |
|---|---|---|
| `"3" + "5"` | `"35"` | 文字列どうしの + は連結 |
| `Number("3") + Number("5")` | `8` | 数どうしの + は足し算 |
| `Number("")` | `0` | 空欄は 0 になる |
| `Number("abc")` | `NaN` | 数にできない文字は NaN(Not a Number=数ではない値) |

### サンプルを 1 行ずつ

- `const input = ...` / `const greeting = ...`: 入力欄と表示先の要素を先に取り出しておきます
- `addEventListener("click", () => { ... })`: あいさつボタンのクリックを待ちます(ch02)
- `const name = input.value;`: **クリックされたときに** 入力欄の文字を読みます。クリックの外(ページを開いた瞬間)で読むと、まだ何も打たれていない `""` のままになるので、読む場所が大事です
- `if (name === "") { ... } else { ... }`: 空欄なら注意を、そうでなければあいさつを表示します(L5 で見た if と ===)

### 画面はどう変わるか

| 入力欄 | ボタンを押した後の表示 |
|---|---|
| (空) | 名前を入力してください |
| さくら | こんにちは、さくらさん！ |

## ch04 classList で見た目を切り替える

JS で色や装飾を変えたいとき、スタイルを 1 つずつ書きかえるより、CSS で用意した class を付け外しするほうがきれいです。要素の `classList`(その要素に付いている class の一覧を操作する道具)を使い、`add("名前")` で付け、`remove("名前")` で外し、`toggle("名前")` で「付いていれば外す・なければ付ける」を切り替えます。🟡 「見た目は CSS に書き、JS は class を切り替えるだけ」という役割分担を意識しましょう。

```js
const box = document.getElementById("box");
box.classList.toggle("dark");  // 押すたびに .dark が付いたり外れたり
```

### class のおさらい

class は L3 ch04 で見た、タグに付ける「グループ名」です。CSS で `.dark { ... }` と書いておくと、`class="dark"` が付いた要素だけにその見た目が付きます。classList で付け外しすると、CSS の見た目もその場で付いたり外れたりします。classList の名前には `.` を付けず、`"dark"` とだけ書きます。

### 3 つのメソッドの違い

| いまの class | add("dark") | remove("dark") | toggle("dark") |
|---|---|---|---|
| なし | `dark` が付く | なしのまま | `dark` が付く |
| `dark` | `dark` のまま | 外れる | 外れる |

### サンプルを 1 行ずつ

- `<style>` の `body.dark { ... }`: 「class dark が付いた body」だけを選ぶセレクタです。背景を濃い灰色(`#222`)、文字を白っぽい色(`#eee`)にする配色を用意しておきます
- `transition: ...`: 色が変わるときに 0.3 秒かけてなめらかに変える CSS です
- `document.getElementById("mode-btn").addEventListener("click", () => { ... })`: ボタンのクリックを待ちます(ch02)
- `document.body`: `<body>` 要素のことです。body は 1 ページに 1 つしかないので、id なしで直接取り出せます
- `.classList.toggle("dark")`: body に dark が付いていれば外し、なければ付けます

### 画面はどう変わるか

| いつ | body の class | 見た目 |
|---|---|---|
| ページを開いた | なし | ふつうの配色 |
| 1 回目のクリック | `dark` | 背景が暗く、文字が明るくなる |
| 2 回目のクリック | なし | ふつうに戻る |

開発者ツール(L1 ch03)の Elements(要素)タブを開いたままボタンを押すと、`<body class="dark">` の表示が付いたり消えたりするのが見えます。

もし class を使わずに書くと、`document.body.style.backgroundColor = "black";` のように、変えたい見た目を 1 つずつ JS に書き、元に戻す処理も別に書くことになります。class を切り替える方法なら、JS は 1 行で済みます。
