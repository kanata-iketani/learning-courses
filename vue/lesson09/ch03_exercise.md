# lesson09 ch03 演習: input の値を読む(.value)

2 つの数を足し算する「ミニ電卓」を作りましょう。2 つの入力欄に数を入れて「計算」ボタンを押すと、合計が表示されるようにしてください。`.value` は文字列なので、`Number()` で数に変換してから足すのがポイントです(変換しないと `"3" + "5"` は `"35"` になってしまいます)。

**確認ポイント**

1. 3 と 5 を入力して「計算」を押すと「答え: 8」と表示される(35 にならない)
2. 数を入れ直して押すと、結果も新しい合計に変わる
3. 10 と 20 で「答え: 30」になる

すべて満たせたら「✔ できた」を押してください。
