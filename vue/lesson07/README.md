# Lesson 07 JavaScript基礎4：配列とオブジェクト

複数のデータをまとめて扱う配列とオブジェクトを学びます。Python のリストと辞書に対応する仕組みで、Vue でも画面に表示するデータはほぼこの 2 つの形で持ちます。最後に学ぶ map と filter は、Vue アプリのデータ加工で毎日のように使う道具です。

## ch01 配列の基本 〜 [ ]・添字・length

**配列**は複数の値を順番に並べて入れる箱で、`[ ]` で作ります。Python のリストと同じ発想です。各要素は**添字**(要素の位置を表す番号。0 から始まる)で取り出します。要素数は `length` で調べます(Python の `len(fruits)` は JavaScript では `fruits.length` です)。配列をそのまま console.log すると、Node.js では `[ 'りんご', 'みかん' ]` のようにスペース入りで表示されます。🔴 「先頭は 0 番、最後は length - 1 番」を覚えましょう。

```js
const fruits = ["りんご", "みかん", "ぶどう"];
console.log(fruits[0]);      // りんご
console.log(fruits.length);  // 3
```

### 添字と要素の対応

`const fruits = ["りんご", "みかん", "ぶどう"];` は、`[ ]` の中に `,` で区切って 3 つの**要素**(配列に入っている 1 つ 1 つの値)を並べています。

| 添字 | 0 | 1 | 2 |
|---|---|---|---|
| 要素 | りんご | みかん | ぶどう |

- `fruits[0]`: 配列名の後ろに `[添字]` を付けると、その位置の要素を取り出せます。先頭は 1 ではなく 0 です
- `fruits.length`: 要素の数。3 つなので `3` です。`length` はかっこを付けずに書きます(`fruits.length()` ではありません)
- 最後の要素の添字は、要素数より 1 小さい `length - 1`(ここでは 2)です

### `fruits[fruits.length - 1]` の読み方

かっこの内側から順に計算します。

1. `fruits.length` → 3
2. `3 - 1` → 2
3. `fruits[2]` → `ぶどう`

要素の数が 4 つ、5 つと増えても、この書き方なら常に最後の要素を取り出せます。

### Python との違い

| 書いたコード | Python | JavaScript |
|---|---|---|
| 要素数 | `len(fruits)` | `fruits.length` |
| 範囲外 `fruits[3]` | IndexError で止まる | エラーにならず `undefined` |
| マイナス `fruits[-1]` | 最後の要素 | `undefined`(後ろから数える意味はない) |

**undefined** は「値が無い」ことを表す JavaScript の特別な値です。範囲外を指定してもエラーで止まらないので、添字の書き間違いに気付きにくい点に注意します。

### サンプルの実行結果

```text
りんご
ぶどう
3
ぶどう
[ 'りんご', 'みかん', 'ぶどう' ]
```

最後の行は配列を丸ごと表示したものです。Node.js は配列を `[ ]` の内側に半角スペースを入れ、文字列を `'` で囲み、`, ` で区切って表示します。プログラムでは `"` で書いていても、表示は `'` になります。後の演習の期待出力もこの形なので、自分で文字を組み立てるのではなく `console.log(配列)` で表示します。

## ch02 push・pop・includes

配列には**メソッド**(値にひも付いた命令。`配列.push(値)` のようにドットで呼び出す)が用意されています。**push** は末尾に要素を追加(Python の `append`)、**pop** は末尾の要素を取り出して返す、**includes** はその値が含まれていれば true を返します(Python の `in` に相当)。なお、`const` で宣言した配列でも中身の追加や削除はできます。禁止されるのは配列そのものの再代入だけです。🔴 push と pop は「末尾」に対する操作だと覚えましょう。

```js
const todos = ["掃除"];
todos.push("買い物");            // 末尾に追加
console.log(todos.includes("掃除"));  // true
```

### メソッドの呼び出し方

`todos.push("買い物")` は次の部品でできています。

- `todos`: 操作する配列
- `.`: 「この配列の」
- `push`: メソッドの名前
- `("買い物")`: メソッドに渡す値

L04 から使っている `console.log(...)` も、console に用意された log というメソッドを呼んでいる形です。L07 ch01 の `length` はかっこが付かない(命令ではなく「要素数」という情報)ので、メソッドとは区別します。

### 3 つのメソッド

| メソッド | 何をするか | 返す値(**戻り値**) | 配列の中身は |
|---|---|---|---|
| `push(値)` | 末尾に値を追加 | 追加後の要素数 | 変わる |
| `pop()` | 末尾の要素を取り除く | 取り除いた要素 | 変わる |
| `includes(値)` | 値が入っているか調べる | `true` / `false` | 変わらない |

**戻り値**は、メソッドを実行した結果として返ってくる値です。`const last = todos.pop();` のように変数に入れたり、`console.log(todos.includes("掃除"))` のように直接表示したりできます。

### サンプルで中身がどう変わるか

| 実行した行 | 実行後の todos | 表示 |
|---|---|---|
| `const todos = ["掃除", "洗濯"];` | `["掃除", "洗濯"]` | |
| `todos.push("買い物");` | `["掃除", "洗濯", "買い物"]` | |
| `console.log(todos.length);` | 同じ | `3` |
| `console.log(todos[2]);` | 同じ | `買い物` |
| `const last = todos.pop();` | `["掃除", "洗濯"]` | (last に `"買い物"` が入る) |
| `console.log(last);` | 同じ | `買い物` |
| `console.log(todos.length);` | 同じ | `2` |
| `console.log(todos.includes("掃除"));` | 同じ | `true` |
| `console.log(todos.includes("料理"));` | 同じ | `false` |

### const の配列を変更できる理由

`const` が禁止するのは「変数 todos に別の配列を入れ直すこと」(再代入)です。

```js
const todos = ["掃除"];
todos.push("買い物");   // OK: 同じ配列の中身を増やしている
todos = ["料理"];       // NG: TypeError: Assignment to constant variable.
```

push や pop は「同じ配列」の中身を変える操作なので、const のままで使えます。

### 演習のヒント

配列を丸ごと表示すると、L07 ch01 で見たとおり Node.js では `[ '犬', '猫', '鳥' ]` の形で出ます。演習の 1 行目はこの形が期待出力です。

## ch03 オブジェクト 〜 {key: value}

**オブジェクト**は、値に名前(キー)を付けてまとめて入れる箱で、`{key: value}` の形で作ります。Python の辞書に相当しますが、キーをクォートで囲む必要がなく、取り出しも `user["name"]` ではなく**ドット記法**(`user.name` のようにドットでキーを指定する書き方)を使うのが基本です。値の変更も `user.age = 23;` のように書けます。Vue では画面に表示するデータをオブジェクトの形で持つため、この書き方は今後ずっと使います。🔴 「作るときは `キー: 値`、使うときはドット」と覚えましょう。

```js
const user = { name: "さくら", age: 22 };
console.log(user.name);  // Python: user["name"]
```

### 作り方の部品

```js
const user = {
  name: "さくら",
  age: 22,
  city: "大阪",
};
```

| 部品 | 意味 |
|---|---|
| `{` 〜 `}` | オブジェクトの始まりと終わり |
| `name` | **キー**(値に付けた名前)。**プロパティ名**とも呼びます |
| `:` | キーと値の区切り |
| `"さくら"` | 値 |
| `,` | 次の「キー: 値」との区切り |

最後の `city: "大阪",` の後ろの `,` はあっても無くてもかまいません。行を足すときに `,` の付け忘れを防げるので、縦に書くときはよく付けます。配列が「番号で取り出す箱」なのに対し、オブジェクトは「名前で取り出す箱」です。

### 取り出し・変更・追加

| 書き方 | 意味 | 結果 |
|---|---|---|
| `user.name` | キー name の値を取り出す | `さくら` |
| `user["name"]` | 同じ意味(Python と同じ書き方も使える) | `さくら` |
| `user.age = 23;` | キー age の値を入れ替える | age が 23 になる |
| `user.email = "a@example.com";` | 無いキーに代入すると、新しく追加される | email が増える |
| `user.tel` | 無いキーを取り出す | `undefined`(エラーにはならない) |

Python の辞書は無いキーを取り出すと KeyError で止まりましたが、JavaScript は `undefined` を返して先に進みます。キー名のつづり間違いに気付きにくいので注意します。

`user` は `const` ですが、L07 ch02 の配列と同じく、中身の変更(`user.age = 23;`)はできます。禁止されるのは `user = { … };` のような再代入だけです。

### サンプルの実行結果

```text
さくら
22
23
さくらさんは大阪在住です
```

- 1・2 行目: `user.name` と `user.age` を取り出して表示
- 3 行目: `user.age = 23;` で値を変えた後の `user.age`
- 4 行目: テンプレートリテラルの `${ }` の中にもドット記法を書けます。`${user.name}` が `さくら`、`${user.city}` が `大阪` に置き換わります

オブジェクトを丸ごと `console.log(user)` すると、Node.js では `{ name: 'さくら', age: 23, city: '大阪' }` のように表示されます。

## ch04 map と filter

配列を加工する 2 大メソッドを紹介します。**map** は全要素を変換した新しい配列を作り、**filter** は条件に合う要素だけを集めた新しい配列を作ります。どちらも、もとの配列は変わりません。`( )` の中の `n => n * 2` は**アロー関数**(関数の短い書き方。「n を受け取って n * 2 を返す」という意味。次のレッスンで詳しく学びます)です。map と filter は Vue で一覧データを加工するときに毎日のように使うので、形だけでも先に見ておきましょう。🟡 いまは「map = 全部変換、filter = 選別」というイメージをつかめれば十分です。

```js
const numbers = [1, 2, 3];
console.log(numbers.map(n => n * 2));           // [ 2, 4, 6 ]
console.log(numbers.filter(n => n >= 2));       // [ 2, 3 ]
```

### `n => n * 2` の読み方(いまはこれだけ)

**関数**は「値を受け取って、決まった処理をして、結果を返す」ひとまとまりの処理です(L08 で詳しく学びます)。

```js
n => n * 2
```

- `=>` の左の `n`: 受け取る値の名前。map や filter が配列の要素を 1 つずつ入れてくれます
- `=>` の右の `n * 2`: 計算した結果がそのまま「返す値」になります

### map の動き

`numbers.map(n => n * 2)` は、要素を 1 つずつ `n` に入れて `n * 2` を計算し、その結果を並べた新しい配列を作ります。

| n(もとの要素) | n * 2(返す値) |
|---|---|
| 1 | 2 |
| 2 | 4 |
| 3 | 6 |
| 4 | 8 |
| 5 | 10 |

新しい配列: `[ 2, 4, 6, 8, 10 ]`。要素の数はもとの配列と必ず同じです。

### filter の動き

`numbers.filter(n => n % 2 === 0)` は、要素を 1 つずつ `n` に入れて条件を調べ、`true` になった要素だけを集めます。`n % 2` は 2 で割った余り(L04 ch03)で、`=== 0` は「それが 0 に等しい」(L05 ch02)なので、全体で「偶数なら true」という条件です。

| n | n % 2 | `n % 2 === 0` | 残る? |
|---|---|---|---|
| 1 | 1 | false | 残らない |
| 2 | 0 | true | 残る |
| 3 | 1 | false | 残らない |
| 4 | 0 | true | 残る |
| 5 | 1 | false | 残らない |

新しい配列: `[ 2, 4 ]`。要素の値はそのままで、数だけが減ります。

### もとの配列は変わらない

map と filter は新しい配列を作って返すだけで、`numbers` 自体は書きかえません。L07 ch02 の push / pop がもとの配列を変えるのとは対照的です。結果を使いたいときは `const doubled = numbers.map(...)` のように変数に入れるか、そのまま console.log に渡します。

サンプルの実行結果(Node.js で実際に動かした出力):

```text
[ 2, 4, 6, 8, 10 ]
[ 2, 4 ]
[ 1, 2, 3, 4, 5 ]
```

3 行目で `numbers` を表示すると、map と filter の後でも `[ 1, 2, 3, 4, 5 ]` のままです。

### 演習のヒント

演習の配列は `prices` なので、`=>` の左の名前は `p` や `price` にすると読みやすくなります(名前は自由です)。「100 円以上」は `price >= 100`、「2 倍」は `price * 2` です。
