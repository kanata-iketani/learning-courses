# lesson16 ch02 演習: 完了チェック：打ち消し線と残り件数

starter は ch01 で作った土台です。ここに完了チェック機能を追加しましょう。CSS の `.done` クラスは用意してあります。

**確認ポイント**

1. 各 TODO のチェックボックスにチェックを付けると、文字に打ち消し線が付いて灰色になり、外すと元に戻る
2. 見出しの「残り ○ 件」が computed で計算され、チェックの付け外しのたびに自動で変わる
3. 新しく追加した TODO は未完了(チェックなし)の状態で一覧に入り、残り件数も 1 増える

すべて満たせたら「✔ できた」を押してください。
