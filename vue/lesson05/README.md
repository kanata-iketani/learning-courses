# Lesson 05 JavaScript基礎2：条件分岐

条件によって処理を切り替える if 文を学びます。Python の if / elif / else と考え方は同じで、書き方だけが違います。「比較には必ず === を使う」という JavaScript ならではの約束もここで覚えます。

## ch01 if と else

**if 文**(条件によって実行する処理を切り替える構文)を学びます。Python との違いは書き方です。条件を `( )` で囲み、実行する処理のかたまりを**ブロック**(`{ }` で囲んだ範囲)で表します。Python のようにコロンとインデントで範囲を決めるのではなく、`{ }` が範囲を決めます(インデントは読みやすさのために付けます)。条件が成り立たないときの処理は `else` に書きます。🔴 `( )` と `{ }` の位置を意識して書きましょう。

```js
if (score >= 60) {
  console.log("合格");
} else {
  console.log("不合格");
}
```

### 1 行ずつの意味

| 行 | 意味 |
|---|---|
| `if (score >= 60) {` | `( )` の中の条件「score が 60 以上」を調べます。成り立てば、すぐ後の `{` から `}` までを実行します |
| `  console.log("合格");` | 条件が成り立ったときだけ実行される行 |
| `} else {` | `}` で if のブロックを閉じ、続けて「成り立たなかったとき」のブロックを開きます |
| `  console.log("不合格");` | 条件が成り立たなかったときだけ実行される行 |
| `}` | else のブロックを閉じます |

`>=` は「以上」を表す**比較演算子**です。`score >= 60` を調べた結果は `true`(正しい)か `false`(正しくない)のどちらかになり、`true` なら if のブロック、`false` なら else のブロックが実行されます。比較演算子は次の ch02 で詳しく学びます。

### Python との対応

| | Python | JavaScript |
|---|---|---|
| 条件 | `if score >= 60:` | `if (score >= 60) {` |
| 範囲の決め方 | インデント | `{ }`(インデントは見やすさのため) |
| そうでなければ | `else:` | `} else {` |

JavaScript ではインデントがずれても動きは変わりませんが、`{` と `}` の数が合わないと SyntaxError になります。開いた `{` には必ず対応する `}` を書きます。

### サンプルが動く順番

1. `const score = 75;`: score に 75 を入れます
2. `if (score >= 60)`: 75 >= 60 を調べると `true`
3. if のブロックの `console.log("合格");` を実行し、else のブロックは飛ばします
4. `const stock = 0;`: stock に 0 を入れます
5. `if (stock > 0)`: 0 > 0 を調べると `false`(0 は 0 より大きくない)
6. if のブロックを飛ばし、else のブロックの `console.log("在庫なし");` を実行します

実行結果(Node.js で実際に動かした出力):

```text
合格
在庫なし
```

### else は省略できる

「成り立ったときだけ何かする」なら、else は書かなくてかまいません。条件が `false` なら何も実行せずに次の行へ進みます。

```js
const point = 120;
if (point >= 100) {
  console.log("ボーナス獲得");  // 120 >= 100 は true なので表示される
}
```

## ch02 比較演算子と ===

**比較演算子**(2 つの値を比べた結果を返す記号)には `>` `<` `>=` `<=` があり、結果は**真偽値**(正しいか正しくないかを表す `true` / `false` という値)になります。「等しい」は **===**、「等しくない」は **!==** で調べます。`===` は値だけでなく型も比べるので、`5 === "5"` は false です。JavaScript には `==` もありますが、型を勝手に変換して事故のもとになるため、必ず `===` を使ってください(覚えるのはこの 1 行だけで十分です)。Python の `==` にあたるのが JavaScript の `===` です。🔴 「等しいはイコール 3 つ」と覚えましょう。

```js
console.log(5 === 5);    // true
console.log(5 === "5");  // false (型が違う)
```

### 比較演算子の一覧

| 記号 | 意味 | 例 | 結果 |
|---|---|---|---|
| `>` | より大きい | `10 > 3` | `true` |
| `<` | より小さい | `10 < 3` | `false` |
| `>=` | 以上 | `10 >= 10` | `true`(等しいときも含む) |
| `<=` | 以下 | `3 <= 2` | `false` |
| `===` | 等しい | `5 === 5` | `true` |
| `!==` | 等しくない | `5 !== 3` | `true` |

`>=` と `<=` は `=` を後ろに書きます。`=>` と書くと別の意味(L08 で学ぶアロー関数)になります。`!` は「〜ではない」を表す記号です。

`true` と `false` はクォートで囲まない特別な値です。Python の `True` / `False` と違い、すべて小文字で書きます。

### 型とは

**型**は値の種類のことです。ここまでに出てきた型は次の 3 つです。

| 型 | 例 | 書き方 |
|---|---|---|
| 数値(number) | `5`、`2.5` | クォートなし |
| 文字列(string) | `"5"`、`"abc"` | クォートで囲む |
| 真偽値(boolean) | `true`、`false` | クォートなし・小文字 |

`5` と `"5"` は、見た目は似ていても型が違うので、`===` で比べると `false` になります。

### `=`、`==`、`===` の違い

| 記号 | 意味 | 例 |
|---|---|---|
| `=` | 代入(右の値を左の変数に入れる) | `let x = 5;` |
| `===` | 型も値も同じなら `true` | `5 === "5"` は `false` |
| `==` | 型を自動で変換してから比べる(使わない) | `5 == "5"` は `true`、`0 == ""` も `true` |

`==` は `0 == ""`(数値の 0 と空の文字列)まで `true` にしてしまいます(Node.js で確認済み)。こうした予想外の結果を避けるために `===` だけを使います。

### サンプルの実行結果

```text
true
false
true
true
false
true
true
```

最後の `true` は `const isAdult = 20 >= 18;` の後の `console.log(isAdult);` の出力です。`=` は右側を先に計算するので(L04 ch02)、まず `20 >= 18` が `true` になり、その `true` が `isAdult` に入ります。比較の結果も、数値や文字列と同じように変数に入れられる値です。

## ch03 else if と && ||

3 つ以上に分岐したいときは **else if** を使います(Python の `elif` にあたります)。上から順に条件を調べ、最初に成り立ったブロックだけが実行されます。また、複数の条件を組み合わせるときは **&&**(かつ。両方 true なら true)と **||**(または。どちらかが true なら true)を使います。Python の `and` / `or` にあたる記号です。🔴 else if は「上から順に判定される」ことを意識して条件の順番を決めましょう。

```js
if (score >= 80) {
  console.log("優");
} else if (score >= 60) {
  console.log("良");
} else {
  console.log("がんばろう");
}
```

### else if が判定される順番

score が 65 のとき、次の順で進みます。

1. `score >= 80` を調べる → 65 >= 80 は `false`。「優」のブロックは飛ばします
2. `score >= 60` を調べる → 65 >= 60 は `true`。「良」のブロックを実行します
3. 1 つ成り立ったので、残りの else は調べずに if 全体を抜けます

出力は `良` の 1 行だけです。score を変えたときの結果は次のとおりです。

| score | 1 つ目 `>= 80` | 2 つ目 `>= 60` | 出力 |
|---|---|---|---|
| 95 | true | (調べない) | 優 |
| 65 | false | true | 良 |
| 30 | false | false | がんばろう |

95 は 60 以上でもありますが、先に 1 つ目が成り立つので「優」だけが出ます。もし条件の順番を逆(`>= 60` を先)にすると、95 点でも「良」になってしまいます。大きい条件から先に書くのはこのためです。

### && と || の結果の表

`&&` はアンド、`||` はオアと読みます。`|` は縦棒の記号で、日本語キーボードでは Shift + ¥ で入力します。2 本続けて書きます。

| A | B | A && B(かつ) | A または B |
|---|---|---|---|
| true | true | true | true |
| true | false | false | true |
| false | true | false | true |
| false | false | false | false |

右端の列が `||` の結果です。`&&` は「両方 true のときだけ true」、`||` は「1 つでも true なら true」です。

### サンプルの残りの部分

- `age >= 18 && hasTicket`: `age >= 18` は 25 >= 18 で true、`hasTicket` は true。両方 true なので全体も true になり、`入場できます` が出ます
- `day === "土" || day === "日"`: day は `"日"` なので、1 つ目 `day === "土"` は false、2 つ目 `day === "日"` は true。どちらかが true なので全体は true になり、`休みです` が出ます

`hasTicket` のように変数に真偽値が入っていれば、`hasTicket === true` と書かずに変数だけを条件に使えます。

実行結果(Node.js で実際に動かした出力):

```text
良
入場できます
休みです
```

### よくある間違い

`day === "土" || "日"` と書くと、「day が土、または day が日」という意味にはなりません。`||` の左右はそれぞれ独立した条件なので、右側にも `day === "日"` と完全な比較を書きます。
