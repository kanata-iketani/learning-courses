# Lesson 04 JavaScript基礎1：変数と型

ここからは JavaScript の基礎を学びます。コードは Node.js(ブラウザの外で JavaScript を動かす実行環境)で実行され、console.log の出力が期待出力と自動照合されます。Python で学んだ考え方と対比しながら、変数・数値・文字列の扱いを身につけましょう。

## ch01 console.log で文字列を表示する

ここから JavaScript を書いていきます。**console.log**(画面に値を表示する命令)は、Python の `print()` に相当します。**文字列**(文字の並びのデータ)はクォートで囲みます。JavaScript のクォートは 3 種類ありますが、まずは `'` と `"` の 2 つを覚えれば十分です(どちらも意味は同じ。この教材では `"` で統一します)。文末には**セミコロン** `;` を付けるスタイルで統一します。🔴 まずは console.log で文字を表示できるようになりましょう。

```js
console.log("こんにちは");   // Python の print("こんにちは") と同じ
console.log('シングルでも同じ');
```

## ch02 let と const 〜変数をつくる

**変数**(値に名前を付けて入れておく箱)を作るとき、Python では `name = "太郎"` と書くだけでしたが、JavaScript では宣言のキーワードが必要です。**const**(再代入できない宣言)と **let**(再代入できる宣言)の 2 つがあります。**再代入**とは、あとから別の値を入れ直すことです。🔴 基本は const で書き、あとで値を変えたい変数だけ let にする、と覚えましょう。古い書き方の `var` は使いません。

```js
const name = "太郎";  // 再代入できない(基本はこちら)
let count = 0;        // 再代入できる
count = count + 1;    // OK
```

## ch03 数値と計算 〜 + - * / %

数値は Python と同じくクォートなしで書きます。計算に使う記号は `+ - * /` と、**%**(割り算の余りを求める演算子)です。割り算 `/` は整数どうしでも小数の結果になります(Python 3 の `/` と同じ)。注意したいのは `+` です。文字列に `+` を使うと**連結**(文字列どうしをつなげること)になり、`"10" + 5` は `105` という文字列になってしまいます。🔴 数値のつもりがクォートで囲まれていないか、サンプルの `"10" + 5` で確認しましょう。

```js
console.log(10 + 5);    // 15
console.log("10" + 5);  // 105 (文字列の連結！)
```

## ch04 テンプレートリテラル 〜 `${}` で埋め込む

3 種類目のクォートがバッククォート `` ` `` です。これで囲んだ文字列を**テンプレートリテラル**(文字列の中に `${式}` で変数や計算結果を埋め込める書き方)と呼びます。Python の f-string `f"こんにちは、{name}さん"` に相当します。`+` でつなぐより読みやすく、Vue のテンプレートでも同じ「埋め込み」の発想が出てくるため、とても重要な書き方です。🔴 `${}` の中に変数も計算式も書けることを覚えましょう。

```js
const name = "花子";
console.log(`こんにちは、${name}さん`);  // Python: f"こんにちは、{name}さん"
```
