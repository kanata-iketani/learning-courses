# Lesson 04 JavaScript基礎1：変数と型

ここからは JavaScript の基礎を学びます。コードは Node.js(ブラウザの外で JavaScript を動かす実行環境)で実行され、console.log の出力が期待出力と自動照合されます。Python で学んだ考え方と対比しながら、変数・数値・文字列の扱いを身につけましょう。

## ch01 console.log で文字列を表示する

ここから JavaScript を書いていきます。**console.log**(画面に値を表示する命令)は、Python の `print()` に相当します。**文字列**(文字の並びのデータ)はクォートで囲みます。JavaScript のクォートは 3 種類ありますが、まずは `'` と `"` の 2 つを覚えれば十分です(どちらも意味は同じ。この教材では `"` で統一します)。文末には**セミコロン** `;` を付けるスタイルで統一します。🔴 まずは console.log で文字を表示できるようになりましょう。

```js
console.log("こんにちは");   // Python の print("こんにちは") と同じ
console.log('シングルでも同じ');
```

### 基礎の基礎: このレッスンから JavaScript はどこで動くのか

L01〜L03 では、JavaScript を HTML の `<script>` に書き、ブラウザの中で動かしていました。L04〜L08 では JavaScript の文法そのものに集中するため、HTML を使わずに **Node.js**(ブラウザの外で JavaScript を実行するプログラム。Python に対する `python3` コマンドにあたります)で動かします。

| | L01〜L03(ブラウザ) | L04〜L08(Node.js) |
|---|---|---|
| 書く場所 | HTML の `<script>` の中 | JavaScript だけのファイル(`main.js`) |
| 動かし方 | 「▶ プレビュー」 | 「▶ 実行」(裏で `node main.js` を実行) |
| `console.log` の表示先 | 開発者ツールの Console タブ | 学習画面の右下の出力欄 |
| 合否 | 自分で確認して「✔ できた」 | 「✔ 採点」で出力が期待出力と一致すれば合格 |

文法は同じ JavaScript です。ブラウザの外なので、`document.getElementById` のようなページを操作する命令は使えませんが、変数・計算・if・くり返し・関数はすべて同じように書けます。

「✔ 採点」は、あなたのコードを実行した出力と、演習の「期待出力」を 1 行ずつ比べます。文字が 1 つでも違うと不合格になるので、全角・半角やスペースの有無まで期待出力に合わせてください(行末の余分なスペースは無視されます)。

### サンプルを 1 行ずつ

| 行 | 意味 |
|---|---|
| `// console.log は …` | `//` から行の終わりまでは**コメント**(実行されないメモ) |
| `console.log("こんにちは、JavaScript！");` | `( )` の中の文字列を表示して改行します |
| `console.log('シングルクォートでも同じです');` | `'` で囲んでも同じ文字列です |
| `console.log("好きな言語:", "JavaScript");` | `,` で区切った 2 つの値を、間に半角スペースを 1 つはさんで 1 行に並べます |
| `console.log("ようこそ");` | Python の `print("ようこそ")` と同じ働きです |

実行結果(Node.js で実際に動かした出力):

```text
こんにちは、JavaScript！
シングルクォートでも同じです
好きな言語: JavaScript
ようこそ
```

`console.log` 1 回で 1 行が出て、自動で改行されます。囲んでいるクォート `"` `'` は表示されません。

### Python との書き方の違い

| | Python | JavaScript |
|---|---|---|
| 表示 | `print("こんにちは")` | `console.log("こんにちは");` |
| 文の終わり | 改行 | `;`(省略しても動くことが多いが、この教材では必ず書く) |
| コメント | `# メモ` | `// メモ` |

### よくあるエラー

クォートを閉じ忘れると、Node.js は 1 行も実行せずにエラーを出します。

```js
console.log("こんにちは);
```

```text
SyntaxError: Invalid or unexpected token
```

**SyntaxError**(文法エラー)は「書き方が JavaScript のルールに合っていない」という意味です。エラーの上には問題の行が表示されるので、その行のクォートやかっこの対応を確かめます。

## ch02 let と const 〜変数をつくる

**変数**(値に名前を付けて入れておく箱)を作るとき、Python では `name = "太郎"` と書くだけでしたが、JavaScript では宣言のキーワードが必要です。**const**(再代入できない宣言)と **let**(再代入できる宣言)の 2 つがあります。**再代入**とは、あとから別の値を入れ直すことです。🔴 基本は const で書き、あとで値を変えたい変数だけ let にする、と覚えましょう。古い書き方の `var` は使いません。

```js
const name = "太郎";  // 再代入できない(基本はこちら)
let count = 0;        // 再代入できる
count = count + 1;    // OK
```

### 1 行の読み方

`const name = "太郎";` は次の部品でできています。

- `const`: 「これから新しい変数を作ります(再代入はしません)」という宣言
- `name`: 変数の名前
- `=`: **代入**。右側の値を左側の変数に入れる記号です。数学の「等しい」ではありません
- `"太郎"`: 入れる値
- `;`: 文の終わり

宣言(`const` / `let`)を書くのは、変数を最初に作るときの 1 回だけです。2 回目以降は名前だけで使います。

### `count = count + 1;` の読み方

`=` は右側を先に計算してから、その結果を左側に入れます。

1. 右側の `count + 1` を計算する。いまの `count` は 0 なので 0 + 1 で 1
2. その 1 を左側の `count` に入れ直す(再代入)

これで `count` は 1 になります。「count と count + 1 が等しい」という意味ではありません。

### サンプルの実行結果

```text
JavaScript
0
1
太郎
```

| 行 | 出力 | 理由 |
|---|---|---|
| `console.log(language);` | `JavaScript` | 変数名を `" "` で囲まずに書くと、中に入っている値が表示されます |
| 1 回目の `console.log(count);` | `0` | 作った直後なので 0 |
| `count = count + 1;` の後の `console.log(count);` | `1` | 再代入で 1 になった |
| `console.log(name);` | `太郎` | |

`console.log(language)` と `console.log("language")` は違います。前者は変数の中身 `JavaScript`、後者は文字列 `language` そのものを表示します。

### const に再代入するとどうなるか

サンプルでコメントにしてある `language = "Python";` を有効にして実行すると、その行で止まり、次のエラーが出ます(Node.js で実際に出るメッセージ)。

```text
TypeError: Assignment to constant variable.
```

「定数(const の変数)に代入しようとした」という意味です。このほかにも、変数まわりでよく見るエラーがあります。

| 書いたコード | エラー | 原因 |
|---|---|---|
| `let x = 1;` の後に `let x = 2;` | `SyntaxError: Identifier 'x' has already been declared` | 同じ名前を 2 回宣言した。2 回目は `x = 2;` と書く |
| 宣言していない `score` を使う | `ReferenceError: score is not defined` | 変数を作り忘れた、または名前のつづりが違う |

### 変数の名前の付け方

- 使えるのは英字・数字・`_`・`$`。数字から始めることはできません
- 大文字と小文字は別の名前として扱われます(`name` と `Name` は別物)
- 2 語以上をつなぐときは、`totalPrice` のように 2 語目から先頭を大文字にする書き方(**キャメルケース**)が JavaScript の慣習です。Python の `total_price` とは書き方が違います

## ch03 数値と計算 〜 + - * / %

数値は Python と同じくクォートなしで書きます。計算に使う記号は `+ - * /` と、**%**(割り算の余りを求める演算子)です。割り算 `/` は整数どうしでも小数の結果になります(Python 3 の `/` と同じ)。注意したいのは `+` です。文字列に `+` を使うと**連結**(文字列どうしをつなげること)になり、`"10" + 5` は `105` という文字列になってしまいます。🔴 数値のつもりがクォートで囲まれていないか、サンプルの `"10" + 5` で確認しましょう。

```js
console.log(10 + 5);    // 15
console.log("10" + 5);  // 105 (文字列の連結！)
```

### 演算子の一覧

**演算子**は計算や比較に使う記号のことです。

| 記号 | 意味 | 例 | 結果 |
|---|---|---|---|
| `+` | 足し算 | `10 + 3` | `13` |
| `-` | 引き算 | `10 - 3` | `7` |
| `*` | かけ算 | `10 * 3` | `30` |
| `/` | 割り算 | `10 / 4` | `2.5` |
| `%` | 割り算の余り | `10 % 3` | `1`(10 ÷ 3 = 3 余り 1) |

計算の順番は算数と同じで、`*` `/` `%` が `+` `-` より先です。先に計算させたい部分は `( )` で囲みます。

```js
console.log(1 + 2 * 3);    // 7  (2 * 3 が先)
console.log((1 + 2) * 3);  // 9  (かっこの中が先)
```

### 数値の型は 1 種類

Python には整数(`int`)と小数(`float`)の区別がありましたが、JavaScript の数値は **number** という 1 つの型だけです。`10` も `2.5` も同じ number なので、`10 / 4` は自然に `2.5` になります。割り切れないときは `10 / 3` が `3.3333333333333335` のように長い小数で表示されます(最後の桁が 5 になるのは、コンピュータが小数を 2 進数で近似して持つためです)。Python の `//`(切り捨て割り算)はありません。

### `"10" + 5` で何が起きているか

`"10"` はクォートで囲まれているので数値ではなく文字列です。`+` の片方が文字列だと、JavaScript はもう片方の 5 も文字列 `"5"` に変えてからつなげます。

1. `"10" + 5`
2. 5 を文字列にする → `"10" + "5"`
3. 文字列どうしをつなげる → `"105"`

Python では `"10" + 5` はエラー(TypeError)でしたが、JavaScript はエラーを出さずに連結してしまうので気付きにくい点に注意します。console.log で表示するとクォートは付かず `105` と出るので、見た目では数値の 105 と区別できません。

### サンプルの実行結果

```text
13
7
30
2.5
1
105
360
```

最後の `price * count` は、変数に入っている 120 と 3 を取り出してかけ算し、360 になります。変数の名前を書くと、その中身の値で計算されます。

### 演習のヒント

- おつりは「払った額 − 合計金額」です。合計金額は `price * count` なので、`1000 - price * count` と書けます(`*` が先に計算されます)
- 余りは `%` を使います。6 個を 4 人に配ると 1 人 1 個で 2 個余るので、`count % 4` で 2 になります

## ch04 テンプレートリテラル 〜 `${}` で埋め込む

3 種類目のクォートが**バッククォート**(下のコードで文字列の前後に付いている、左上がりの点のような記号)です。これで囲んだ文字列を**テンプレートリテラル**(文字列の中に `${式}` で変数や計算結果を埋め込める書き方)と呼びます。Python の f-string `f"こんにちは、{name}さん"` に相当します。`+` でつなぐより読みやすく、Vue のテンプレートでも同じ「埋め込み」の発想が出てくるため、とても重要な書き方です。🔴 `${}` の中に変数も計算式も書けることを覚えましょう。

```js
const name = "花子";
console.log(`こんにちは、${name}さん`);  // Python: f"こんにちは、{name}さん"
```

### バッククォートの入力方法

バッククォートは `'`(シングルクォート)とは別の文字です。日本語キーボードでは **Shift + @**、英語キーボードでは左上の数字 1 の左隣のキーで入力します。半角で入力してください。

### 記号の意味

上のコードの 2 行目の文字列を部品に分けます。

```js
`こんにちは、${name}さん`
```

| 部品 | 意味 |
|---|---|
| 最初と最後のバッククォート | テンプレートリテラルの始まりと終わり |
| `こんにちは、` と `さん` | そのまま表示される文字 |
| `${` 〜 `}` | 埋め込みの印。`$` と `{` の間は空けずに書きます |
| `name` | 埋め込む中身(**式**)。変数 `name` の値 `花子` に置き換わります |

**式**とは、計算すると 1 つの値になるものです。変数 `name`、計算 `age + 1`、数値 `3` などがすべて式です。

### 実行される順番

サンプルの次の行は、4 つの手順で表示されます。

```js
console.log(`${age}歳、来年は${age + 1}歳です`);
```

1. 1 つ目の `${age}` を計算 → `20`
2. 2 つ目の `${age + 1}` を計算 → `21`
3. まわりの文字とつなげて `20歳、来年は21歳です` という文字列を作る
4. console.log がその文字列を表示する

### サンプルの実行結果

```text
こんにちは、花子さん
20歳、来年は21歳です
こんにちは、花子さん
```

1 行目と 3 行目は同じ結果です。3 行目の `"こんにちは、" + name + "さん"` は L04 ch03 の連結で、`+` とクォートが増えて読みにくくなります。

### よくある間違い

```js
const name = "花子";
console.log(`${name}さん`);   // 花子さん     ← 正しい
console.log("${name}さん");   // ${name}さん  ← " で囲むと埋め込みは働かず、記号がそのまま出る
console.log(`{name}さん`);    // {name}さん   ← $ を忘れると埋め込みにならない
```
