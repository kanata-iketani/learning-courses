# Lesson 01 Webページのしくみ

Vue を学ぶ前に、Web ページがどう動いているかをゼロから理解するレッスンです。HTML・CSS・JavaScript の役割分担と、ブラウザでの確認方法を学びます。

## ch01 Webページは3つの言語でできている

ブラウザに表示されるページは、役割の違う 3 つの言語でできています。**HTML**(ページの中身と構造を書く言語)、**CSS**(色や配置など見た目を整える言語)、**JavaScript**(ボタンを押したら動く、などの動きを付ける言語)です。料理にたとえると、HTML が食材、CSS が盛り付け、JavaScript が調理の仕掛けです。これから学ぶ **Vue** は、JavaScript でページを効率よく作るための道具(フレームワーク)です。🟡 まずは 3 つの役割の違いを理解しましょう。

下のサンプルは 3 つが 1 ファイルに入った最小のページです。`<style>` の中が CSS、`<script>` の中が JavaScript です。

```html
<p>これは HTML(中身)</p>
<style>p { color: red; }  /* CSS(見た目) */</style>
<script>console.log("JS(動き)");</script>
```

## ch02 HTMLタグのきほんのかたち

HTML は**タグ**(`<` と `>` で囲んだ目印)を使って、文章に意味を付けていきます。基本の形は `<タグ名>中身</タグ名>` です。前側の `<p>` を**開始タグ**、後ろ側の `</p>` を**終了タグ**と呼び、2 つで中身をはさみます。タグの中に別のタグを入れる**入れ子**もよく使います。🔴 「開いたタグは必ず閉じる」「内側のタグから先に閉じる」の 2 つが最重要ルールなので、ここでしっかり身につけましょう。

```html
<p>これは <strong>大事</strong> な文です</p>
```

`<strong>` は文字を太字にして強調するタグです。ほかのよく使うタグは、下のサンプルをプレビューして体験してみてください。

## ch03 ブラウザの開発者ツールと console.log

ブラウザには**開発者ツール**(ページの中身や動きを調べる画面)が付いています。Windows では **F12** キー、Mac では Command + Option + I で開き、**Console(コンソール)** というタブを選びます。JavaScript の `console.log()` は、かっこの中の値をこのコンソールに表示する命令で、プログラムの動きを確かめる基本の道具です。🟡 プレビューを表示したら F12 でコンソールを開き、メッセージを自分の目で確認しましょう。

```html
<script>
  console.log("こんにちは、コンソール！");
  console.log(1 + 2);
</script>
```

文字列(文字の並び)は `"` で囲みます。`1 + 2` のような計算は、結果の `3` が表示されます。
