# Lesson 01 Webページのしくみ

Vue を学ぶ前に、Web ページがどう動いているかをゼロから理解するレッスンです。HTML・CSS・JavaScript の役割分担と、ブラウザでの確認方法を学びます。

## ch01 Webページは3つの言語でできている

ブラウザに表示されるページは、役割の違う 3 つの言語でできています。**HTML**(ページの中身と構造を書く言語)、**CSS**(色や配置など見た目を整える言語)、**JavaScript**(ボタンを押したら動く、などの動きを付ける言語)です。これから学ぶ **Vue** は、JavaScript でページを効率よく作るための道具(フレームワーク)です。🟡 まずは 3 つの役割の違いを理解しましょう。

| 言語 | 役割 | このページでの例 |
|---|---|---|
| HTML | 中身と構造(見出し・段落・ボタンなど) | `<h1>こんにちは、Web！</h1>` |
| CSS | 見た目(色・大きさ・余白・並べ方) | `h1 { color: steelblue; }` |
| JavaScript | 動き(あとから文字を書き込む、クリックに反応する) | `document.getElementById(...)` |

下のサンプルは 3 つが 1 ファイルに入った最小のページです。`<style>` の中が CSS、`<script>` の中が JavaScript です。

```html
<p>これは HTML(中身)</p>
<style>p { color: red; }  /* CSS(見た目) */</style>
<script>console.log("JS(動き)");</script>
```

### 用語の確認

- **ブラウザ**: Chrome・Edge・Safari など、Web ページを表示するアプリ
- **タグ**: `<h1>` のように `<` と `>` で囲んだ HTML の目印。次のチャプターで詳しく学びます
- **プレビュー**: 書いたコードをブラウザで表示した結果。この学習画面では右下の枠に出ます

### サンプルを 1 行ずつ

| 行 | 意味 |
|---|---|
| `<!DOCTYPE html>` | 「このファイルは HTML です」という宣言。ファイルの 1 行目に必ず書きます |
| `<html lang="ja">` 〜 `</html>` | ページ全体を囲むタグ。`lang="ja"` は「日本語のページ」という情報です |
| `<head>` 〜 `</head>` | 画面には出ない設定を書く場所(文字コード・タブの題名・CSS など) |
| `<meta charset="utf-8">` | 文字コード(文字を数値で保存する方式)が UTF-8 だと伝えます。書かないと日本語が文字化けすることがあります |
| `<title>はじめてのページ</title>` | ブラウザのタブに出る題名。ページの本文には出ません |
| `<style>` 〜 `</style>` | ここに CSS を書きます |
| `h1 { color: steelblue; }` | 「`h1` の文字色を steelblue(くすんだ青)にする」という CSS |
| `p { font-size: 18px; }` | 「`p` の文字の大きさを 18px にする」という CSS |
| `<body>` 〜 `</body>` | 画面に表示される中身を書く場所 |
| `<h1>こんにちは、Web！</h1>` | 大見出し。大きな太字で表示されます |
| `<p>この文章は…</p>` | 段落(ひとまとまりの文章) |
| `<p id="message"></p>` | 中身が空の段落。`id="message"` はこの段落に付けた名前で、JavaScript から探すときに使います |
| `<script>` 〜 `</script>` | ここに JavaScript を書きます |
| `document.getElementById("message")` | ページの中から `id` が `message` の部品を探します |
| `.textContent = "…";` | 探した部品の中身の文字を、右側の文字列に置き換えます |

`/* … */`(CSS)、`<!-- … -->`(HTML)、`// …`(JavaScript)は**コメント**(人が読むためのメモ。ブラウザは無視します)です。言語ごとに書き方が違う点に注意してください。

### ブラウザの中で起きる順番

「▶ プレビュー」を押すと、ブラウザはファイルを上から順に読んで、次の順で画面を作ります。

1. `<head>` を読み、文字コードとタブの題名を設定します。`<style>` の CSS を覚えておきます
2. `<body>` を読み、見出し `h1`、段落 `p` を 2 つ作ります。2 つ目の `p` は中身が空なので、この時点では何も見えません
3. 覚えておいた CSS を当てはめ、`h1` を青色に、`p` を 18px にします
4. `<script>` にたどり着くと、中の JavaScript を実行します。空だった段落に「この行は JavaScript が書きました。」が書き込まれます

結果として、プレビューには次の 3 行が出ます。

```text
こんにちは、Web！            ← 青い大見出し(HTML + CSS)
この文章は HTML で書かれています。
この行は JavaScript が書きました。  ← JavaScript があとから書き込んだ文
```

`<script>` を `<body>` の最後に置いているのは、手順 4 の時点で `id="message"` の段落がもう作られている必要があるからです。

## ch02 HTMLタグのきほんのかたち

HTML は**タグ**(`<` と `>` で囲んだ目印)を使って、文章に意味を付けていきます。基本の形は `<タグ名>中身</タグ名>` です。前側の `<p>` を**開始タグ**、後ろ側の `</p>` を**終了タグ**と呼び、2 つで中身をはさみます。タグの中に別のタグを入れる**入れ子**もよく使います。🔴 「開いたタグは必ず閉じる」「内側のタグから先に閉じる」の 2 つが最重要ルールなので、ここでしっかり身につけましょう。

```html
<p>これは <strong>大事</strong> な文です</p>
```

`<strong>` は文字を太字にして強調するタグです。ほかのよく使うタグは、下のサンプルをプレビューして体験してみてください。

### タグの部品の名前

```html
<p>これは <strong>大事</strong> な文です</p>
```

- `<p>`: 開始タグ。`p` がタグ名です(paragraph = 段落の頭文字)
- `</p>`: 終了タグ。タグ名の前に `/`(スラッシュ)が付きます
- 開始タグから終了タグまでのひとまとまりを**要素**と呼びます。上の例は「p 要素の中に strong 要素が入っている」形です
- 表示結果: 「これは **大事** な文です」と 1 行で出て、「大事」だけが太字になります

### 入れ子の正しい閉じ方

内側で開いたタグは、外側のタグより先に閉じます。

```html
<!-- 正しい: strong の中で開いた em を、strong より先に閉じる -->
<strong>太字の中に <em>斜体</em> を入れる</strong>

<!-- 誤り: em が開いたまま strong を閉じている -->
<strong>太字の中に <em>斜体</strong> を入れる</em>
```

誤った書き方でも、ブラウザはエラーを出さずに推測で直して表示します。そのため間違いに気付きにくく、意図しない見た目になります。書く側が必ず正しい順に閉じる必要があります。

### サンプルで使うタグ

| タグ | 意味 | 表示 |
|---|---|---|
| `<h1>` | 大見出し(heading) | 大きな太字 |
| `<p>` | 段落 | 前後に少し間が空いた文章 |
| `<strong>` | 強く強調 | 太字 |
| `<em>` | 強調(emphasis) | 斜体(ななめの文字) |
| `<mark>` | 目立たせる印 | 黄色い背景 |
| `<small>` | 補足・注意書き | 少し小さい文字 |
| `<hr>` | 話題の区切り | 横線 |

`<hr>` のように中身を持たないタグもあります。はさむ中身がないので終了タグ `</hr>` は書きません。このようなタグを**空要素**と呼び、L02 で `<br>`(改行)や `<img>`(画像)にも出てきます。

### プレビューで起きること

ブラウザは上から順にタグを読み、タグの種類ごとに決まった見た目で表示します。サンプルの最後から 2 つ目の段落は、`<strong>` の中に `<em>` が入っているので、「斜体」の 2 文字は太字と斜体の両方の見た目になります。タグそのもの(`<strong>` などの文字)は画面には表示されません。

## ch03 ブラウザの開発者ツールと console.log

ブラウザには**開発者ツール**(ページの中身や動きを調べる画面)が付いています。Windows では **F12** キー、Mac では Command + Option + I で開き、**Console(コンソール)** というタブを選びます。JavaScript の `console.log()` は、かっこの中の値をこのコンソールに表示する命令で、プログラムの動きを確かめる基本の道具です。🟡 プレビューを表示したら F12 でコンソールを開き、メッセージを自分の目で確認しましょう。

```html
<script>
  console.log("こんにちは、コンソール！");
  console.log(1 + 2);
</script>
```

文字列(文字の並び)は `"` で囲みます。`1 + 2` のような計算は、結果の `3` が表示されます。

### console.log の書き方

`console.log("こんにちは");` を部品に分けると次のとおりです。

- `console`: 開発者ツールのコンソールを指す名前です
- `.log`: 「コンソールに記録(表示)する」という命令です。`.`(ドット)は「console の中の log」という意味です
- `( )`: 表示したい値をかっこの中に書きます
- `;`(セミコロン): 1 つの命令の終わりの印です

### コンソールの開き方と見え方

1. 「▶ プレビュー」を押して、右下にページを表示します
2. F12(Mac は Command + Option + I)を押すと、ブラウザの右側か下側に開発者ツールが開きます
3. 上部に並ぶタブから **Console** をクリックします
4. サンプルなら、次の 3 行が表示されています

```text
ようこそ、コンソールへ！
計算もできます: 30
ここが JavaScript の作業場です
```

- 1 行目と 3 行目は、`" "` で囲んだ文字列がそのまま出ています(`"` 自体は表示されません)
- 2 行目の `console.log("計算もできます:", 10 + 20);` のように `,`(カンマ)で区切って複数の値を渡すと、間に半角スペースを 1 つはさんで横に並べて表示します。`10 + 20` は計算されて `30` になります
- 各行の右端には、その出力がどのファイルの何行目から出たかが小さく表示されます(気にしなくてかまいません)

`console.log` はページの画面には何も出しません。表示先はコンソールだけなので、プレビューの見た目は変わりません。

### 文字列と計算式の違い

```html
<script>
  console.log("1 + 2");  // → 1 + 2   (" で囲んだので、ただの文字)
  console.log(1 + 2);    // → 3       (囲んでいないので計算される)
</script>
```

### よくあるつまずき

- 何も表示されない: Console 以外のタブ(Elements など)を見ていないか確かめます。プレビューを押し直すと、もう一度出力されます
- 赤い文字が出た: JavaScript の書き間違い(**エラー**)です。たとえば `"` の閉じ忘れがあると `Uncaught SyntaxError` のような赤いメッセージが出て、その `<script>` の中は 1 行も実行されません。メッセージの右端の行番号を手がかりに直します
