# lesson01 ch01 演習: Webページは3つの言語でできている

サンプルを参考に、自分のページを作ってみましょう。エディタのコードを編集して「▶ プレビュー」で確認しながら、次の 3 点をすべて満たしてください。

**確認ポイント**

1. `<h1>` の見出しの文字を自分の好きな言葉に変える(HTML の変更)
2. `<style>` の中で `h1` の色を `steelblue` から別の色(例: `tomato`)に変える(CSS の変更)
3. JavaScript が書き込む文章を自分の好きな言葉に変える(JavaScript の変更)

3 つともプレビューに反映されたら「✔ できた」を押してください。
