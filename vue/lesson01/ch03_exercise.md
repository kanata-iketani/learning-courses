# lesson01 ch03 演習: ブラウザの開発者ツールと console.log

starter の `<script>` の中を編集して、コンソールへの出力を練習しましょう。「▶ プレビュー」を押してから F12(Mac は Command + Option + I)で開発者ツールを開き、Console タブで結果を確かめてください。

**確認ポイント**

1. コンソールに自分で考えたメッセージ(好きな言葉)が表示されている
2. `console.log(7 * 6)` のように計算式を書いた行があり、計算の結果(数値)が表示されている
3. `console.log` の行を増やして、合計 3 行以上の出力が表示されている

すべて満たせたら「✔ できた」を押してください。
