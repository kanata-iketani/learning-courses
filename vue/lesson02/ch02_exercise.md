# lesson02 ch02 演習: リストとリンク(ul/ol/li, a href)

starter を編集して、自分の「おすすめ紹介ページ」を作りましょう。リストで項目を並べ、ページ内リンクでジャンプできるようにします。

**確認ポイント**

1. `<ul>` の番号なしリストがあり、`<li>` の項目が 3 つ以上、黒丸付きで表示されている
2. `<ol>` の番号付きリストがあり、項目に 1. 2. 3. と自動で番号が付いている
3. ページ上部の `<a>` リンクをクリックすると、`id` を付けた下の見出しまでジャンプする

すべて満たせたら「✔ できた」を押してください。
