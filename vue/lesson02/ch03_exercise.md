# lesson02 ch03 演習: 画像と代替テキスト(img src alt)

starter を編集して、「思い出アルバム」ページを作りましょう。画像ファイルは無いので、alt の説明文がきちんと表示されることを確認します。

**確認ポイント**

1. `<img>` タグが 2 つ以上あり、それぞれに `src` と `alt` の両方の属性が書いてある
2. プレビューの img の場所に、自分で書いた alt の説明文が表示されている
3. alt の説明文が「写真1」のような番号ではなく、「夕日にそまる海辺」のように内容が伝わる文になっている

すべて満たせたら「✔ できた」を押してください。
