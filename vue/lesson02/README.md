# Lesson 02 HTML基礎

ページの中身と構造を作る言語 HTML を集中的に学ぶレッスンです。見出し・リスト・画像・入力部品・div と span まで、よく使うタグを自分の手で一通り書けるようになります。

## ch01 見出しと段落(h1〜h3, p, br)

文章の骨組みを作る基本タグを学びます。`<h1>`〜`<h6>` は**見出し**(章のタイトル)のタグで、h1 が最も大きく、数字が増えるほど小さな見出しになります。`<p>` は**段落**(ひとまとまりの文章)のタグで、段落どうしの間には自動で行間が空きます。`<br>` は段落の中で**改行**だけしたいときに使うタグで、中身を持たないので終了タグはありません(L01 で見た `<hr>` と同じ空要素です)。🔴 見出しの大小で文章に階層を付ける感覚は、この先ずっと使うのでここで固めましょう。

```html
<h1>いちばん大きな見出し</h1>
<h2>その次の見出し</h2>
<p>本文の段落です。<br>br でここから改行されます。</p>
```

### 基礎の基礎: HTML では「ソースの改行」は表示に出ない

HTML を書くときにエディタで Enter を押して改行しても、ブラウザの表示は改行されません。ブラウザは、ソースの改行や連続した空白をまとめて「半角スペース 1 つ」として扱います(日本語の文字どうしの間では、ブラウザによってはスペースも入らずにそのままつながります)。

```html
<p>朝早く家を出ました。
電車の窓から海が見えました。</p>
```

表示結果(1 行につながります):

```text
朝早く家を出ました。 電車の窓から海が見えました。
```

表示の上でも改行したいときに `<br>` を書きます。段落そのものを分けたいときは `<p>` を 2 つにします。

| 書き方 | 表示 |
|---|---|
| `<p>A<br>B</p>` | A と B が改行されて 2 行になる。行の間は詰まったまま |
| `<p>A</p><p>B</p>` | 別の段落になり、間に 1 行ぶんほどの空きができる |

### 見出しの大きさ

ブラウザが最初から持っている見た目(何も CSS を書かないときの見た目)では、見出しはすべて太字で、次のように小さくなっていきます。本文の `<p>` は 16px(px は画面の点の数を表す単位。L03 で学びます)です。

| タグ | 大きさの目安 | 使いどころ |
|---|---|---|
| `<h1>` | 32px | ページの題名。1 ページに 1 つが基本 |
| `<h2>` | 24px | 大きな話題の区切り |
| `<h3>` | 約 19px | h2 の中の小さな話題 |
| `<h4>`〜`<h6>` | 16px 〜 さらに小さい | あまり使いません |

見出しは「文字を大きくするためのタグ」ではなく、「ここから○○の話」という構造を表すタグです。大きさを変えたいだけなら L03 の CSS を使います。

### サンプルの構造

サンプルの旅行記は、見出しで次のような階層になっています。

```text
h1 わたしの旅行記
├─ h2 1日目: 出発
└─ h2 2日目: 観光
    ├─ h3 午前の予定
    └─ h3 午後の予定
```

`<p>朝早く家を出ました。<br>電車の窓から海が見えて、わくわくしました。</p>` は、1 つの段落の中で `<br>` の位置から 2 行目に折り返して表示されます。

## ch02 リストとリンク(ul/ol/li, a href)

箇条書きとリンクのタグを学びます。`<ul>` は**番号なしリスト**(黒丸の箇条書き)、`<ol>` は**番号付きリスト**(1. 2. 3. と自動で番号が付く)のタグで、どちらも項目 1 つ 1 つを `<li>`(リスト項目のタグ)で書きます。`<a>` は**リンク**(クリックで別の場所へ飛ぶ文字)のタグで、飛び先は `href` という**属性**(タグに付ける追加情報)で指定します。🔴 `href="#id名"` と書くと同じページ内の `id` を付けた場所へジャンプできるので、まずはこれで動きを確かめましょう。

```html
<ul>
  <li>りんご</li>
  <li>みかん</li>
</ul>
<a href="#footer">ページの下へジャンプ</a>
```

### リストの組み立て方

`<li>` は必ず `<ul>` か `<ol>` の中に入れます。外側の `ul` / `ol` が「どんなリストか」、内側の `li` が「1 つ 1 つの項目」です。

```html
<ol>
  <li>野菜を切る</li>
  <li>いためて煮こむ</li>
</ol>
```

表示結果:

```text
1. 野菜を切る
2. いためて煮こむ
```

番号は `ol` が自動で付けるので、`<li>1. 野菜を切る</li>` のように自分で番号を書く必要はありません(書くと「1. 1. 野菜を切る」と二重になります)。`ul` にすると番号の代わりに黒丸 `•` が付きます。ul は unordered list(順番のないリスト)、ol は ordered list(順番のあるリスト)、li は list item の略です。

### 属性の書き方

**属性**は開始タグの中に `属性名="値"` の形で書きます。タグ名との間は半角スペースで区切り、値は `"` で囲みます。

```html
<a href="#point">コツを見る</a>
<h2 id="point">おいしく作るコツ</h2>
```

- `href="#point"`: a タグの飛び先。`#` で始まると「このページの中の、id が point の場所」という意味です
- `id="point"`: その要素に付けた名前。**1 ページの中で同じ id は 1 回しか使えません**(飛び先が 1 つに決まるようにするため)
- `href` の `#` の後ろと `id` の値は、1 文字も違わずにそろえます。`#Point` と `point` のように大文字と小文字が違うと飛びません

### クリックしたときに起きること

1. `<a href="#point">` の文字をクリックします
2. ブラウザは `#` の後ろの `point` を読み、ページの中から `id="point"` の要素を探します
3. 見つかった要素(ここでは h2 の見出し)が表示領域のいちばん上に来るように、画面をスクロールします

ページが短くて全体がプレビュー枠に収まっていると、スクロールする余地がないので画面は動きません。動きを確かめたいときは、ブラウザのウィンドウを小さくするか、段落を増やしてページを縦に長くしてみてください。

### 別のページへのリンク

`href` に Web ページの住所(**URL**。`https://` で始まる文字列)を書くと、別のサイトへ移動するリンクになります。

```html
<a href="https://ja.wikipedia.org/">ウィキペディアへ</a>
```

この講座の演習では、ページ内リンク(`#` で始まるもの)だけを使います。

## ch03 画像と代替テキスト(img src alt)

画像を表示するのが `<img>` タグです。中身を持たないので終了タグはなく(空要素)、`src`(画像ファイルの場所)と `alt`(**代替テキスト**。画像を表示できないときに代わりに出す説明文)の 2 つの属性を付けます。alt は目の不自由な人向けの読み上げにも使われる大切な情報です。この学習画面には画像ファイルが無いため画像は出ませんが、そのぶん alt の文字が代わりに表示され、alt の働きを体験できます。🟡 img には必ず alt を書く習慣をここで付けましょう。

```html
<img src="cat.png" alt="ひなたぼっこする猫">
```

画像が無い環境では、この場所に「ひなたぼっこする猫」という文字が表示されます。

### 1 行の中身

| 部分 | 意味 |
|---|---|
| `<img` | 画像(image)を置くタグの始まり |
| `src="cat.png"` | 表示する画像ファイルの場所(source)。ファイル名だけを書くと「この HTML ファイルと同じフォルダにある cat.png」という意味になります |
| `alt="ひなたぼっこする猫"` | 画像の代わりの説明文(alternative text) |
| `>` | タグの終わり。`</img>` は書きません |

属性は L02 ch02 で見たとおり `属性名="値"` の形で、半角スペースで区切って何個でも並べられます。順番は自由です。

### ブラウザの中で起きること

1. ブラウザは `<img>` を見つけると、`src` に書かれた場所から画像ファイルを読み込もうとします
2. 読み込めたら、その場所に画像を表示します
3. ファイルが見つからないなど読み込めなかったときは、代わりに `alt` の文字を表示します。Chrome や Edge では、文字の横に「画像が壊れている」ことを示す小さなアイコンも出ます

この学習画面のプレビューには `cat.png` などのファイルが無いので、必ず 3 の動きになります。

### alt に何を書くか

| 書き方 | 読み上げや画像が出ないときの結果 |
|---|---|
| `alt="ボールをくわえた柴犬"` | 内容が伝わる。良い例 |
| `alt="写真1"` | 何の写真か伝わらない |
| `alt=""`(空) | 何も表示されず、読み上げもされない |

`alt=""` は「飾りの線や模様など、意味を持たない画像」に使う正式な書き方です。内容のある写真やイラストでは空にせず、何が写っているかを短い文で書きます。

### 画像の場所の書き方

`src` にはファイル名のほか、Web 上の画像の URL(`https://` で始まる住所)も書けます。

```html
<img src="images/cat.png" alt="猫">            <!-- 同じ場所にある images フォルダの中の cat.png -->
<img src="https://example.com/cat.png" alt="猫"> <!-- Web 上の画像 -->
```

## ch04 入力部品(input, button, textarea, select)

ユーザーに何かを入力してもらう部品(**フォーム部品**。アンケートや申込画面で使う入力欄やボタンのこと)を学びます。`<input>` は**1 行の入力欄**(終了タグなし。`placeholder` 属性で薄い案内文を出せます)、`<textarea>` は**複数行の入力欄**、`<button>` は**押せるボタン**、`<select>` は**プルダウン**(クリックで選択肢が開くメニュー)で、選択肢 1 つ 1 つを `<option>` タグで書きます。今はまだ押しても何も起きませんが、後で JavaScript や Vue とつなぐと本物のアプリになります。🔴 4 種類の部品を実際に並べて、触って動きを確かめましょう。

```html
<input placeholder="名前">
<select>
  <option>りんご</option>
  <option>みかん</option>
</select>
<button>送信</button>
```

### 4 つの部品のまとめ

| タグ | 見た目 | 終了タグ | よく使う属性 |
|---|---|---|---|
| `<input>` | 1 行の入力欄 | なし(空要素) | `placeholder`(薄い案内文) |
| `<textarea>` | 複数行の入力欄 | `</textarea>` が必要 | `rows`(見える行数)、`cols`(1 行の文字数の目安)、`placeholder` |
| `<select>` + `<option>` | プルダウン | どちらも必要 | 選択肢 1 つ = `<option>` 1 つ |
| `<button>` | ボタン | `</button>` が必要 | 開始タグと終了タグの間の文字がボタンに書かれます |

### サンプルの見どころ

- `<input placeholder="山田はなこ">`: 空の入力欄に薄い灰色で「山田はなこ」と出ます。これは**入力済みの文字ではなく案内**で、1 文字打つと消えます
- `<select>` の中の 4 つの `<option>`: 最初の「春」が選ばれた状態で表示され、クリックすると 4 つの選択肢が開きます
- `<textarea rows="4" cols="40" ...>`: 4 行ぶんの高さ、半角 40 文字ぶんほどの幅の欄になります。入りきらない量を書くと、欄の中にスクロールバーが出ます
- `<button>送信する</button>`: 押すとへこむ見た目になりますが、何も起きません

### なぜボタンを押しても何も起きないのか

HTML は「部品を置く」ところまでしか担当しません。「押されたら何をするか」は JavaScript の仕事で、まだ何も書いていないので何も起きないのです。L01 ch01 の表のとおり、動きは JavaScript の担当です。この講座の後半では、Vue を使って「入力した文字を画面に表示する」「ボタンを押したら数を増やす」といった動きを付けます。

入力した文字はページの中にだけあり、どこにも保存・送信されません。プレビューを押し直すと空に戻ります。

## ch05 div と span でまとまりを作る

ページの部品をグループ化する 2 つのタグを学びます。`<div>` は**ブロックのまとまり**を作る「箱」のタグで、前後で行が変わり、関連する要素をひとまとめにできます。`<span>` は**行の中の一部分**だけを包む「印」のタグで、行は変わりません。どちらも見た目は変えないタグですが、CSS(次のレッスンで学ぶ言語)で色を付けると、まとまりの範囲がはっきり見えます。🟡 「かたまりは div、行の中の一部は span」という使い分けを体験しましょう。

```html
<div style="background-color: lightyellow;">
  <p>この段落は <span style="color: red;">この部分だけ</span> 赤字です</p>
</div>
```

`style` 属性はタグに直接 CSS を書く方法で、`background-color` は背景色の指定です。

### ブロック要素とインライン要素

HTML のタグは、並び方で大きく 2 種類に分かれます。

| 種類 | 並び方 | 横幅 | 例 |
|---|---|---|---|
| **ブロック要素** | 前後で必ず行が変わり、縦に積み重なる | 親の横幅いっぱいに広がる | `div`、`p`、`h1`〜`h6`、`ul`、`li` |
| **インライン要素** | 文章の流れの中に入り、行は変わらない | 中身の文字の幅だけ | `span`、`strong`、`em`、`a`、`mark` |

`div` は「意味を持たないブロック要素」、`span` は「意味を持たないインライン要素」です。`strong` などと違って見た目も意味も足さないので、「ここからここまでをひとまとめにしたい」ときに自由に使えます。

### style 属性の書き方

```html
<span style="color: red;">赤い文字</span>
```

- `style="…"` の中に CSS を書きます
- `プロパティ: 値;` の形で、`color`(文字色)を `red`(赤)にする、という意味です。`:`(コロン)で名前と値を区切り、`;` で 1 つの指定を終えます
- `style="background-color: lightyellow; color: red;"` のように `;` で区切って複数並べられます

### サンプルで起きること

- 1 つ目の `div` に `background-color: lightyellow` を付けているので、div の中の h2 と 2 つの p がまとめて薄い黄色の背景になります。div はブロック要素なので、色は横幅いっぱいに広がります
- 2 つ目の `div` は別の箱なので、別の色(lightcyan = 薄い水色)になります
- `<span style="color: red;">この赤い部分だけが span</span>` は文の途中にありますが、span はインライン要素なので行は変わらず、その部分の文字だけが赤になります

span で包む範囲を文の別の場所に移しても、行が変わらずに色だけが変わることを確かめてみてください。
