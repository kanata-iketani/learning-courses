# lesson02 ch04 演習: 入力部品(input, button, textarea, select)

starter を編集して、「プロフィール登録フォーム」を作りましょう。実際に文字を打ったり選択肢を選んだりして、部品の動きを確かめてください。

**確認ポイント**

1. `<input>` の 1 行入力欄があり、クリックして文字を入力できる
2. `<select>` のプルダウンに `<option>` の選択肢が 3 つ以上あり、切り替えて選べる
3. `<textarea>` の複数行入力欄があり、改行しながら文章を書ける
4. `<button>` のボタンが表示され、マウスでクリックできる(何も起きなくて OK)

すべて満たせたら「✔ できた」を押してください。
