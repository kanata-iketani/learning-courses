# lesson10 ch03 演習: {{ }} で表示 — マスタッシュ構文

「買い物メモ」アプリを作りましょう。data に単価 `price` と個数 `count` を持たせ、`{{ }}` の中の式で小計と税込価格(10% 増し)を表示してください。税込価格は `Math.floor(price * count * 1.1)` のように、`{{ }}` の中で関数を呼んで小数点以下を切り捨てます。

**確認ポイント**

1. 小計として `price × count` の計算結果が表示される(単価 150・個数 2 なら 300)
2. 税込価格が小計の 1.1 倍(小数点以下切り捨て)で表示される(300 なら 330)
3. data の `count` を変えて再プレビューすると、小計と税込の両方が計算し直される

すべて満たせたら「✔ できた」を押してください。
