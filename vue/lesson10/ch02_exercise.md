# lesson10 ch02 演習: createApp と data — アプリの起動と状態

`createApp` と `data` を使って「自己紹介アプリ」を作りましょう。starter には HTML 側の `{{ name }}` と `{{ hobby }}` だけ用意してあります。`<script>` 内に Vue アプリの起動コードを書き、データを表示させてください。

**確認ポイント**

1. プレビューに `{{ name }}` という文字がそのまま出ておらず、data に入れた名前が表示される
2. 趣味も同じように data の値が表示される
3. data の値を別の文字列に書きかえて再プレビューすると、HTML を触らなくても表示が変わる

すべて満たせたら「✔ できた」を押してください。
