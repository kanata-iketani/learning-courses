# Lesson 10 はじめてのVue

いよいよ Vue の登場です。前のレッスンで体験した「DOM を自分で書きかえる大変さ」を出発点に、「データを変えれば画面が自動で変わる」という Vue の考え方と、最初のアプリの作り方(createApp・data・{{ }})を学びます。

## ch01 Vue とは — データを変えれば画面が変わる

L9 では `textContent` で画面を自分で書きかえました。部品が増えると「どこを・いつ書きかえるか」の管理が大変になります。**Vue**(ビュー。画面作りを楽にする JavaScript の**フレームワーク**=よく使う仕組みをまとめた土台)は、データと画面を結びつけておき、**データを変えるだけで画面を自動更新**してくれます。これを**宣言的 UI**(あるべき姿を書いておき、書きかえは道具に任せるスタイル)と呼びます。🟡 サンプルで同じカウンターを素の JS と Vue で見比べてください。

```js
// 素の JS: 値の更新と画面の書きかえを両方自分でやる
count = count + 1;
countEl.textContent = count;

// Vue: データを変えるだけ。画面は Vue が書きかえる
count++
```

Vue 側の細かい書き方は、この後のチャプターで順に学びます。

### Vue を使えるようにする

`<head>` の中の `<script src="/vendor/vue.global.prod.js"></script>` が、Vue 本体のファイルを読み込む行です。`src` に書いたファイルを読み込むと、`Vue` という名前のオブジェクトが使えるようになります。この講座では Vue 本体を学習アプリに同梱しているので、ネット接続なしで動きます。

### サンプルの Vue 版を 1 行ずつ

- `<div id="app">`: ここから `</div>` までが Vue の担当する範囲です
- `<button @click="count++">`: クリックされたら `count++` を実行する、という指示です。`@click` は L12 で詳しく学びます。`++` は L6 の for 文で見た「1 増やす」です
- `<span>{{ count }}</span>`: データ `count` の今の値をここに表示します。`{{ }}` は ch03 で詳しく学びます
- `const { createApp } = Vue;`: Vue からアプリを作る関数を取り出します(ch02 で説明)
- `data() { return { count: 0 }; }`: アプリが覚えておくデータ `count` を初期値 0 で用意します
- `.mount("#app")`: id が app の要素を Vue に担当させます

### クリックしたときに起きること

| 順番 | 素の JS 版 | Vue 版 |
|---|---|---|
| 1 | `count = count + 1` で変数を増やす | `count++` でデータを増やす |
| 2 | `textContent` で画面を書きかえる(自分で書く) | Vue が「count を表示している場所」を見つけて書きかえる(書かなくてよい) |

データの変化を Vue が自動で検知して画面に反映する性質を **リアクティブ**(データの変化に反応する、という意味)と呼びます。表示する場所が 10 か所に増えても、Vue 版はデータを 1 か所変えるだけで済みます。

### += の意味

演習で使う `count += 10` は `count = count + 10` の短い書き方です。同じように `-=` は引き算です。

| いまの count | 実行する式 | 実行後の count |
|---|---|---|
| 100 | `count++` | 101 |
| 100 | `count += 10` | 110 |
| 100 | `count -= 4` | 96 |

## ch02 createApp と data — アプリの起動と状態

Vue アプリは 3 ステップで動きます。(1) `<script>` タグで Vue 本体を読み込む、(2) `createApp(設定)` でアプリを作る、(3) `.mount("#app")` で「この要素の中を Vue が担当する」と割り当てる(**マウント**と呼びます)。設定の `data()` は、アプリの**状態**(アプリが覚えておく値)をオブジェクトで返す関数です。ここで返したプロパティは、マウント先の HTML の中で `{{ 名前 }}` として表示できます。🔴 この 3 ステップの型は、今後すべてのチャプターで使う土台です。

```js
const { createApp } = Vue;
createApp({
  data() {
    return { name: "いけたに", age: 20 };
  }
}).mount("#app");
```

### 1 行ずつの意味

- `const { createApp } = Vue;`: **分割代入**(オブジェクトから同じ名前のプロパティを取り出して変数にする書き方)です。`const createApp = Vue.createApp;` と書くのと同じ意味で、以後 `createApp` だけで呼べるようになります
- `createApp({ ... })`: アプリを作る関数です。引数の `{ ... }` は L7 で見たオブジェクトで、アプリの設定を書きます。この設定を **オプション** と呼びます
- `data() { return { ... }; }`: `data: function() { return { ... }; }` の省略形です(オブジェクトの中に関数を書くときの短い書き方)。Vue がこの関数を呼び、返ってきたオブジェクトをアプリの状態として使います。関数にしてある理由は L15 ch03 で分かります
- `{ name: "いけたに", age: 20 }`: 状態の中身です。キーがデータ名、値が初期値です。キーとキーの間はカンマで区切ります
- `.mount("#app")`: `"#app"` は「id が app の要素」を指す書き方です。L3 で class を `.名前` で選んだのと同じ CSS のセレクタで、id は `#名前` で選びます。`createApp(...)` が返したアプリに続けて `.mount` を呼んでいます

### サンプルの画面

| HTML に書いたもの | 場所 | 画面の表示 |
|---|---|---|
| `{{ title }}` | #app の中 | はじめての Vue アプリ |
| `{{ name }}` | #app の中 | いけたに |
| `{{ food }}` | #app の中 | カレー |
| `{{ title }}` | #app の外 | `{{ title }}`(そのままの文字) |

Vue が担当するのは mount した要素の中だけなので、外に書いた `{{ }}` はただの文字として表示されます。

### よくあるつまずき

| 症状 | 原因 |
|---|---|
| `{{ name }}` がそのまま表示される | `.mount("#app")` を忘れた、または id の名前が違う |
| 何も表示されない(空になる) | data に書いた名前と `{{ }}` の名前が一致していない(大文字・小文字も区別されます) |
| どれも表示されない | data の中のカンマ忘れなどで JS がエラーになっている。開発者ツール(L1 ch03)のコンソールに赤い文字が出ます |

## ch03 {{ }} で表示 — マスタッシュ構文

`{{ }}` は**マスタッシュ構文**(口ひげのような見た目から付いた名前)といい、中に書いた結果をその場に表示します。data の値をそのまま出すだけでなく、**式**(計算して 1 つの値になるもの)なら何でも書けます。計算式、文字列の連結、`length` などのプロパティ、三項演算子も使えます。ただし `if` 文や `for` 文などの**文**は書けません。🔴 「{{ }} の中は式だけ」というルールを、サンプルを動かしながら確かめましょう。

```html
<p>{{ price * count }} 円</p>
<p>{{ name.length }} 文字</p>
<p>{{ stock > 0 ? "在庫あり" : "売り切れ" }}</p>
```

`{{ }}` の中では、data の名前をそのまま書けます(`this` などは付けません)。

### 式と文の違い

| 書いたもの | 種類 | {{ }} に書けるか |
|---|---|---|
| `price * count` | 式(計算して 1 つの値になる) | 書ける |
| `"あり" + stock` | 式 | 書ける |
| `let x = 1` | 文(変数を作る命令) | 書けない |
| `if (stock > 0) { ... }` | 文(処理の流れを決める命令) | 書けない |

### 三項演算子

`条件 ? 真のときの値 : 偽のときの値` と書くと、条件が true なら `?` の後ろ、false なら `:` の後ろの値になります。if 文と違って全体が 1 つの値になる式なので、`{{ }}` の中に書けます。

| stock | `stock > 0` | `stock > 0 ? "在庫あり" : "売り切れ"` |
|---|---|---|
| 5 | true | 在庫あり |
| 0 | false | 売り切れ |

### サンプルを 1 行ずつ

| テンプレート | 計算 | 表示 |
|---|---|---|
| `{{ shopName }}` | data をそのまま | Vue 商店 |
| `{{ item.length }}` | 文字列の文字数(L7 で見た length は文字列にもある) | 7 |
| `{{ price }} 円 × {{ count }} 個` | data をそのまま | 120 円 × 3 個 |
| `{{ price * count }}` | 120 × 3 | 360 |
| `{{ stock > 0 ? "あり(残り" + stock + "個)" : "売り切れ" }}` | stock は 5 なので前半 | あり(残り5個) |

data の `stock` を 0 に書きかえて再プレビューすると「売り切れ」に変わります。

### Math.floor を使う理由

演習の税込計算では `Math.floor`(小数点以下を切り捨てる関数。L9 ch02 で見た)を使います。コンピュータの小数の計算には小さな誤差が出ることがあり、`150 * 2 * 1.1` は `330` ではなく `330.00000000000006` になります。`Math.floor(150 * 2 * 1.1)` と切り捨てれば `330` と表示されます。
