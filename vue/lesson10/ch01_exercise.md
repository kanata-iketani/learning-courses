# lesson10 ch01 演習: Vue とは — データを変えれば画面が変わる

サンプルとほぼ同じ「素の JS 版と Vue 版のカウンター」が starter に入っています。まず両方のボタンを押して、同じ動きをすることを確かめましょう。そのうえで、初期値と増え方を書きかえて、2 つの書き方の違いを観察してください。

**確認ポイント**

1. 素の JS 版・Vue 版どちらのボタンでも、押すと数字が 1 増える
2. 両方の初期値を 0 から 100 に変える(素の JS 版は `let count = 100;` と HTML の表示の 2 か所、Vue 版は `data` の 1 か所だけで済むことを確かめる)
3. Vue 版の `@click="count++"` を `@click="count += 10"` に変えると、押すたびに 10 増える

すべて満たせたら「✔ できた」を押してください。
