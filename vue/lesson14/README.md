# Lesson 14 条件とくり返し（v-if / v-for）

「条件によって表示を切り替える」「配列の数だけくり返して表示する」を学ぶレッスンです。v-if / v-else / v-show / v-for と、くり返しに必須の :key の役割を身につけます。

## ch01 v-if と v-else：条件で表示を切り替える

**v-if**(条件が成り立つときだけ要素を表示するディレクティブ)を学びます。ディレクティブとは v- で始まる Vue 専用の属性のことでした(L11 ch01)。`v-if="条件"` の条件が true のとき要素が表示され、false のときは要素ごと画面から消えます。直後の要素に **v-else** を付けると「そうでないとき」の表示を書けます。🔴 「状態によって見せるものを切り替える」はアプリ作りの基本中の基本です。

```html
<p v-if="agree">ありがとうございます！</p>
<p v-else>チェックを入れてください</p>
```

条件を 3 つ以上に分けたいときは、間に `v-else-if="条件"` をはさめます。

### 書き方のきまり

- `v-if="..."` の `" "` の中は式です。data の名前や、`score >= 80` のような比較(L5)が書けます
- v-else と v-else-if は、v-if を付けた要素の**すぐ次の要素**に付けます。間に別の要素をはさむと、正しく動きません
- v-else には条件を書きません

### サンプルを 1 行ずつ

- `<input type="checkbox" v-model="agree">`: チェックボックスと data の agree をつなぎます(L13 ch02)
- `<p v-if="agree">`: agree が true のときだけ表示されます
- `<p v-else>`: agree が false のときだけ表示されます。2 つが同時に出ることはありません

| agree | 表示される段落 |
|---|---|
| false | まだ同意されていません。チェックを入れてください。 |
| true | ありがとうございます！次へ進めます。 |

### v-else-if は上から順に調べる

```html
<p v-if="score >= 80">合格！</p>
<p v-else-if="score >= 60">あと少し！</p>
<p v-else>がんばろう</p>
```

上から順に条件を調べ、最初に true になった 1 つだけを表示します。

| score | `score >= 80` | `score >= 60` | 表示 |
|---|---|---|---|
| 90 | true | (調べない) | 合格！ |
| 70 | false | true | あと少し！ |
| 30 | false | false | がんばろう |

90 は `score >= 60` も満たしますが、先に「合格！」が選ばれるので「あと少し！」は出ません。条件は厳しいものから順に並べます。

### type="number" と v-model

演習の `<input type="number" v-model="score">` のように、`type="number"` の入力欄に v-model を付けると、Vue が入力を数に変換して data に入れます(L9 ch03 の `Number()` を自分で書かなくてよい)。そのため `score >= 80` のような比較がそのまま使えます。

## ch02 v-show との違い：隠すだけか、DOM から消えるか

v-if とよく似た **v-show**(要素を CSS で見えなくするディレクティブ)との違いを学びます。v-if が false のとき要素を **DOM**(L9 ch01 で見た、ブラウザが持つページの部品の一覧)から丸ごと取り除くのに対し、v-show は要素を DOM に残したまま `display: none` という CSS で隠すだけです。見た目は同じでも、消し方が違います。🟡 使い分けの目安は、頻繁にパタパタ切り替えるなら作り直しの手間がかからない v-show、めったに切り替えないなら v-if です。

```html
<p v-if="visible">v-if の段落(DOM から消える)</p>
<p v-show="visible">v-show の段落(隠れるだけ)</p>
```

`display: none` は、L3 ch05 で見た display プロパティに `none`(表示しない)を指定したものです。要素は残っていますが、場所も取らず画面に何も描かれません。

### false のときの DOM の違い

| | visible が true | visible が false |
|---|---|---|
| v-if の段落 | `<p>私は v-if。…</p>` | 段落がなくなる |
| v-show の段落 | `<p>私は v-show。…</p>` | `<p style="display: none;">私は v-show。…</p>` |

開発者ツール(L1 ch03)の Elements タブを開いたままボタンを押すと、v-if の段落は行ごと消え、v-show の段落は `style="display: none;"` が付くだけなのが見えます。v-if で消した要素は、true に戻るたびに作り直されます。

### サンプルを 1 行ずつ

- `<button v-on:click="visible = !visible">`: クリックで visible を反対の値にします(`!` は L11 ch02 で見た否定)
- `<p>いまの visible: {{ visible }}</p>`: いまの値を true / false で表示します
- `<p v-if="visible">` / `<p v-show="visible">`: 同じ条件で、消し方だけが違う 2 つの段落です

| 操作 | visible | 見た目 |
|---|---|---|
| 開いた直後 | true | 2 つの段落が両方見える |
| 1 回押す | false | 2 つとも見えなくなる |
| もう 1 回押す | true | 2 つとも戻る |

なお、v-show には v-else がありません。「そうでないとき」を書きたいときは v-if / v-else を使います。

### 演習のヒント

ボタンは `@click="showHint = !showHint"` と `@click="showAnswer = !showAnswer"` のように、それぞれ別の data を切り替えます。ヒントの段落には `v-show="showHint"`、答えの段落には `v-if="showAnswer"` を付けます。

## ch03 v-for でリストを表示する

**v-for**(配列の要素の数だけタグをくり返すディレクティブ)を学びます。`v-for="item in items"` と書くと、配列 items の要素が 1 つずつ item に入り、そのタグが要素の数だけ描画されます。`(item, index)` の形にすると **index**(0 から始まる「何番目か」の番号)も一緒に使えます。配列に push で要素を足すと、画面のリストも自動で増えます。🔴 一覧表示はほぼすべてのアプリに登場する、v-if と並ぶ最重要ディレクティブです。

```html
<li v-for="(fruit, index) in fruits">{{ index + 1 }} 番目: {{ fruit }}</li>
```

### 記法を 1 つずつ

- `fruits`: data にある配列の名前です
- `in`: 「この配列の中から 1 つずつ取り出す」という Vue の書き方です(L6 の for...of に近い働き)
- `(fruit, index)`: 取り出した要素を入れる名前と、その番号を入れる名前です。名前は自由に付けられ、このタグの中だけで使えます。番号がいらなければ `fruit in fruits` だけで書けます
- `{{ index + 1 }}`: index は 0 から始まるので、1 を足して「1 番目」から数えます
- v-for を付けたタグ(ここでは `<li>`)そのものがくり返されます。`<ul>` は 1 つのまま、その中の `<li>` が増えます

### 展開されるとこうなる

data が `fruits: ["りんご", "バナナ", "みかん"]` のとき、Vue は次の HTML を作ります。

```html
<li>1 番目: りんご</li>
<li>2 番目: バナナ</li>
<li>3 番目: みかん</li>
```

| くり返しの回 | fruit | index | 表示 |
|---|---|---|---|
| 1 回目 | りんご | 0 | 1 番目: りんご |
| 2 回目 | バナナ | 1 | 2 番目: バナナ |
| 3 回目 | みかん | 2 | 3 番目: みかん |

### サンプルの追加ボタン

- `<p>好きな果物リスト({{ fruits.length }} 件)</p>`: 配列の長さを表示します
- `<input v-model="newFruit">`: 入力した文字が data の newFruit に入ります(L13)
- `<button v-on:click="addFruit">`: クリックで addFruit を呼びます
- `this.fruits.push(this.newFruit);`: 入力された文字を配列の最後に足します(L7 ch02 の push)
- `this.newFruit = "";`: newFruit を空にします。v-model でつながっているので入力欄も空になります

「ぶどう」と入力して追加を押すと、配列が 4 件になり、Vue が `<li>4 番目: ぶどう</li>` を自動で足し、件数の表示も 4 件に変わります。

### 演習のヒント

追加ボタンに `@click="addPlace"` を付け、methods に `addPlace() { ... }` を書きます。中身はサンプルの addFruit と同じ形で、`places` と `newPlace` を使います。

## ch04 :key の意味と v-for + v-if の注意

v-for には **:key**(くり返される要素 1 つ 1 つに付ける目印)を付けるのが基本です。Vue は key を手がかりに「どの要素が増えた・減った・入れ替わった」を見分けるので、key には id のような**重複しない値**を渡します。もうひとつの注意は、v-for と v-if を同じタグに書かないことです。Vue 3 では v-if が先に評価されるため、v-for の変数がまだ使えずエラーになります。🟡 `<template>`(画面には描画されない透明な入れ物タグ)で 2 つを別のタグに分けるのが定番の解決策です。

```html
<template v-for="task in tasks" :key="task.id">
  <li v-if="!task.done">{{ task.text }}</li>
</template>
```

### key がないと何が困るか

key がないと、Vue は「前から何番目か」だけを頼りに、すでにある要素を使い回します。そのため、リストの途中を削除したり並べ替えたりしたとき、入力途中の文字のような「データとつながっていない状態」が、隣の行にずれて残ることがあります。`:key="task.id"` を付けると、Vue は id で「どのデータの行か」を見分けるので、正しい行が消えたり動いたりします。

| key に使う値 | 良し悪し | 理由 |
|---|---|---|
| `task.id`(1, 2, 3…) | よい | データごとに決まっていて変わらない |
| index(何番目か) | 避ける | 途中を削除すると後ろの行の番号が変わってしまう |

L15 ch02 のサンプルのように、末尾に足すだけで削除や並べ替えをしない一覧なら、index を key にしても問題は起きません。

### 配列の中のオブジェクト

サンプルの tasks は、L7 で見たオブジェクトを並べた配列です。v-for の `task` には 1 件分のオブジェクトが入るので、`task.text` や `task.done` のようにドットで中身を取り出します。

| task | task.id | task.text | task.done |
|---|---|---|---|
| 1 件目 | 1 | 宿題をやる | false |
| 2 件目 | 2 | 犬の散歩 | false |
| 3 件目 | 3 | 部屋のそうじ | true |

上の一覧の `<input type="checkbox" v-model="task.done">` は、その行のオブジェクトの done とチェックボックスをつなぎます。チェックを付けると、その行の done だけが true になります。

### v-for と v-if を分ける

- `<template v-for="task in tasks" :key="task.id">`: template タグ自体は画面に出ません。中身の `<li>` だけが、要素の数だけくり返されます
- `<li v-if="!task.done">`: `!task.done` は「done が false なら true」(`!` は L11 ch02 の否定)です。まだ終わっていないタスクだけ表示します

開いた直後の「残りタスク」に表示されるのは、done が false の「宿題をやる」「犬の散歩」の 2 件です。上の一覧で「宿題をやる」にチェックを付けると、その done が true になり、下の一覧からすぐ消えます。

同じタグに `v-for` と `v-if` を書くと、v-if が先に動いて `task` がまだ決まっていないので、エラーになります。「条件に合うものだけの一覧」は、L15 で学ぶ computed で配列をしぼり込んでから v-for で表示する方法もよく使われます。
