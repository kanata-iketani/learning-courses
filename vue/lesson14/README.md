# Lesson 14 条件とくり返し（v-if / v-for）

「条件によって表示を切り替える」「配列の数だけくり返して表示する」を学ぶレッスンです。v-if / v-else / v-show / v-for と、くり返しに必須の :key の役割を身につけます。

## ch01 v-if と v-else：条件で表示を切り替える

**v-if**(条件が成り立つときだけ要素を表示するディレクティブ)を学びます。ディレクティブとは v- で始まる Vue 専用の属性のことでした。`v-if="条件"` の条件が true のとき要素が表示され、false のときは要素ごと画面から消えます。直後の要素に **v-else** を付けると「そうでないとき」の表示を書けます。🔴 「状態によって見せるものを切り替える」はアプリ作りの基本中の基本です。

```html
<p v-if="agree">ありがとうございます！</p>
<p v-else>チェックを入れてください</p>
```

条件を 3 つ以上に分けたいときは、間に `v-else-if="条件"` をはさめます。

## ch02 v-show との違い：隠すだけか、DOM から消えるか

v-if とよく似た **v-show**(要素を CSS で見えなくするディレクティブ)との違いを学びます。v-if が false のとき要素を **DOM**(ブラウザが持つページの部品の木構造)から丸ごと取り除くのに対し、v-show は要素を DOM に残したまま `display: none` という CSS で隠すだけです。見た目は同じでも、消し方が違います。🟡 使い分けの目安は、頻繁にパタパタ切り替えるなら作り直しコストの低い v-show、めったに切り替えないなら v-if です。

```html
<p v-if="visible">v-if の段落(DOM から消える)</p>
<p v-show="visible">v-show の段落(隠れるだけ)</p>
```

## ch03 v-for でリストを表示する

**v-for**(配列の要素の数だけタグをくり返すディレクティブ)を学びます。`v-for="item in items"` と書くと、配列 items の要素が 1 つずつ item に入り、そのタグが要素の数だけ描画されます。`(item, index)` の形にすると **index**(0 から始まる「何番目か」の番号)も一緒に使えます。配列に push で要素を足すと、画面のリストも自動で増えます。🔴 一覧表示はほぼすべてのアプリに登場する、v-if と並ぶ最重要ディレクティブです。

```html
<li v-for="(fruit, index) in fruits">{{ index + 1 }} 番目: {{ fruit }}</li>
```

## ch04 :key の意味と v-for + v-if の注意

v-for には **:key**(くり返される要素 1 つ 1 つに付ける目印)を付けるのが基本です。Vue は key を手がかりに「どの要素が増えた・減った・入れ替わった」を見分けるので、key には id のような**重複しない値**を渡します。もうひとつの注意は、v-for と v-if を同じタグに書かないことです。Vue 3 では v-if が先に評価されるため、v-for の変数がまだ使えずエラーになります。🟡 `<template>`(画面には描画されない透明な入れ物タグ)で 2 つを別のタグに分けるのが定番の解決策です。

```html
<template v-for="task in tasks" :key="task.id">
  <li v-if="!task.done">{{ task.text }}</li>
</template>
```
