# lesson14 ch02 演習: v-show との違い：隠すだけか、DOM から消えるか

なぞなぞページを作りましょう。「パンはパンでも食べられないパンは？」という問題に対して、ヒントは頻繁に見たり隠したりするので `v-show`、答えは一度見たら終わりなので `v-if` で表示を切り替えます。

**確認ポイント**

1. 「ヒントを見る/隠す」ボタンを押すたびに、ヒントの文が出たり消えたりする(v-show を使う)
2. 「答えを見る/隠す」ボタンを押すたびに、答えの文が出たり消えたりする(v-if を使う)
3. ヒントだけ表示・答えだけ表示・両方表示、のどの組み合わせも作れる(ボタンが独立して動く)

すべて満たせたら「✔ できた」を押してください。
