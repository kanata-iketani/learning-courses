# lesson14 ch01 演習: v-if と v-else：条件で表示を切り替える

テストの点数で表示が変わる判定ページを作りましょう。starter の点数入力欄はできています。`v-if` / `v-else-if` / `v-else` を使って、点数に応じたメッセージを 1 つだけ表示してください。

**確認ポイント**

1. 点数に 80 以上を入れると「合格！」だけが表示される
2. 60〜79 を入れると「あと少し！」だけが表示される
3. 59 以下を入れると「がんばろう」だけが表示される(同時に 2 つ以上のメッセージが出ないこと)

すべて満たせたら「✔ できた」を押してください。
