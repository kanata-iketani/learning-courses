# lesson03 ch04 演習: classで使い分ける(.クラス名)

starter の予定リストを、class を使って色分けしましょう。「大事な予定」と「済んだ予定」で見た目を変えます。

**確認ポイント**

1. CSS に `.taisetsu`(大事)のような class セレクタを作り、class を付けた `<li>` だけが赤い太字になっている
2. 別の class(例: `.sumi`)を作り、済んだ予定の `<li>` だけが灰色になっている
3. 同じ class を 2 つ以上の `<li>` に付けて、まとめて同じ見た目になることを確かめた

すべて満たせたら「✔ できた」を押してください。
