# lesson03 ch02 演習: 文字の大きさと太さ(font-size, font-weight, text-align)

starter を編集して、「本日のセール」のポスターを作りましょう。文字の大きさ・太さ・位置で情報のメリハリを付けます。

**確認ポイント**

1. `h1` の `font-size` を `40px` 以上にして、タイトルが大きく表示されている
2. `h1` と `p` に `text-align: center;` を指定して、文字が中央にそろっている
3. 値段の段落だけ `font-weight: bold;` で太字になり、注意書きの段落は `font-size` を `12px` くらいに小さくしてある

すべて満たせたら「✔ できた」を押してください。
