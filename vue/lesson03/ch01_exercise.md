# lesson03 ch01 演習: styleタグとセレクタ・色(color, background-color)

starter の `<style>` の中を編集して、ページ全体の配色を自分好みに変えましょう。HTML 側は変えずに、CSS だけで見た目が変わることを体験します。

**確認ポイント**

1. `body` の `background-color` を変えて、ページ全体の背景色が白以外になっている
2. `h1` に `color` と `background-color` の両方を指定して、見出しが「背景色付きの色文字」になっている
3. `p` の `color` に `#` から始まるカラーコード(例: `#ff6600`)を使い、2 つの段落が同じ色で表示されている

すべて満たせたら「✔ できた」を押してください。
