# Lesson 03 CSS基礎

ページの見た目を整える言語 CSS を学ぶレッスンです。色・文字・余白・class・flexbox と、デザインに必要な基本のプロパティを順番に身につけます。

## ch01 styleタグとセレクタ・色(color, background-color)

ここからは見た目を整える言語 **CSS** を学びます。CSS は `<head>` の中の `<style>` タグに「`セレクタ { プロパティ: 値; }`」の形で書きます。**セレクタ**は「どのタグを飾るか」の指定(`p` と書けばすべての p タグが対象)、**プロパティ**は「何を変えるか」の指定です。`color` は文字色、`background-color` は背景色で、値には `red` などの色名や `#ff6600` のような**カラーコード**(色を数値で表す書き方)を使えます。🔴 セレクタで相手を選んで色を変える流れをつかみましょう。

```html
<style>
  h1 { color: white; background-color: steelblue; }
  p  { color: #ff6600; }
</style>
```

### 1 つのルールを部品に分ける

```css
h1 { color: white; background-color: steelblue; }
```

| 部品 | 意味 |
|---|---|
| `h1` | セレクタ。「ページの中のすべての h1 要素」を選びます |
| `{ … }` | 選んだ要素に当てる指定をこの中に並べます |
| `color` | プロパティ。文字色を変えます |
| `:` | プロパティと値の区切り |
| `white` | 値。白 |
| `;` | 1 つの指定の終わり。続けて次の指定を書けます |
| `background-color: steelblue;` | 2 つ目の指定。背景色をくすんだ青にします |

この 1 まとまり(セレクタ + `{ }`)を**ルール**と呼びます。改行や空白の入れ方は自由で、次のように縦に書いても意味は同じです。

```css
h1 {
  color: white;
  background-color: steelblue;
}
```

L02 ch05 で見た `style` 属性(`<p style="color: red;">`)は、その要素 1 つだけに CSS を書く方法でした。`<style>` タグに書くと、セレクタに合う要素すべてにまとめて効きます。

### カラーコードの読み方

`#ff6600` は、`#` の後ろの 6 文字を 2 文字ずつに分けて、光の三原色の赤・緑・青の強さを表します。

| 部分 | 色 | 値 | 強さ |
|---|---|---|---|
| `ff` | 赤 | ff | 最大 |
| `66` | 緑 | 66 | 少し |
| `00` | 青 | 00 | なし |

値は **16 進数**(0〜9 と a〜f の 16 文字で数える数え方)で、`00` が最小(0)、`ff` が最大(255)です。赤が最大で緑が少し、青なしなので、オレンジ色になります。`#000000` は黒、`#ffffff` は白、`#ff0000` は赤です。暗記は不要で、色名(`red`、`tomato`、`steelblue` など約 140 種類)を使ってもかまいません。

### サンプルで起きること

ブラウザは `<style>` のルールを読んでから、ページの要素を 1 つずつ見て、セレクタに合うルールを当てはめます。

1. `body { background-color: lightyellow; }`: ページ全体を表す body の背景が薄い黄色になります
2. `h1 { … }`: 見出し「色で遊ぼう」が、青い背景に白い文字になります。h1 はブロック要素なので、背景色は横幅いっぱいに広がります
3. `h2 { color: seagreen; }`: h2 の文字が緑になります
4. `p { color: #ff6600; }`: 2 つある p のどちらもオレンジ色になります。HTML の側には何も書いていないのに、セレクタが `p` なので両方に効きます

## ch02 文字の大きさと太さ(font-size, font-weight, text-align)

文字の見た目を細かく調整するプロパティを学びます。`font-size` は**文字の大きさ**で、`24px` のように **px**(ピクセル。画面の点の数を表す単位)で指定します。`font-weight` は**文字の太さ**で、`bold`(太字)や `normal`(標準)を指定します。`text-align` は**文字をそろえる位置**で、`center`(中央)、`left`(左)、`right`(右)から選びます。🔴 大きさ・太さ・位置の 3 つを組み合わせて、ポスターのようにメリハリのある文字を作ってみましょう。

```html
<style>
  h1 { font-size: 40px; text-align: center; }
  p  { font-size: 14px; font-weight: bold; }
</style>
```

### 3 つのプロパティ

| プロパティ | 変えるもの | 値の例 | 何も指定しないとき |
|---|---|---|---|
| `font-size` | 文字の大きさ | `12px`、`24px`、`44px` | p は 16px、h1 は 32px |
| `font-weight` | 文字の太さ | `normal`(標準)、`bold`(太字) | p は normal、見出しは bold |
| `text-align` | 行の中で文字をどこにそろえるか | `left`、`center`、`right` | left(左寄せ) |

- `px` は数字とくっつけて書きます。`24 px` のように間を空けたり、`24` だけで単位を忘れたりすると、その指定は無視されます
- `font-weight` には `700`(bold と同じ)や `400`(normal と同じ)のような数値も使えます
- `text-align: center;` は、要素の横幅の中で文字を中央に置く指定です。ブロック要素(p や h1)は横幅いっぱいに広がっているので、ページの中央に文字が来ます

### サンプルの `.date` について

サンプルと演習には `.date`、`.price`、`.note` のように**先頭にドットが付いたセレクタ**が出てきます。これは **class セレクタ**で、HTML 側で `class="date"` を付けた要素だけに効きます。詳しくは ch04 で学びます。いまは「`<p class="date">` には `.date { … }` のルールが効く」と読めれば十分です。

### サンプルで起きること

| 要素 | 当たるルール | 見た目 |
|---|---|---|
| `<h1>文化祭 2026</h1>` | `h1` | 44px・中央・赤(crimson)。見出しなので太字のまま |
| `<h2>〜 見出しなのに… 〜</h2>` | `h2` | 20px・中央・`font-weight: normal` で細字 |
| `<p class="date">10月10日…</p>` | `p` と `.date` | `p` から中央そろえ、`.date` から 24px と太字。`font-size` は両方にありますが、class の指定が優先されて 24px になります(優先の理由は ch04) |
| `<p>text-align: center で…</p>` | `p` | 16px・中央 |

1 つの要素に複数のルールが当たると、指定がすべて合わさって効きます。

## ch03 余白の考え方(margin と padding の違い)

要素のまわりの**余白**(何も表示しない空間)を学びます。CSS では要素を「箱」と考え、`border`(箱の枠線)を境に、**外側**の余白を `margin`、**内側**の余白を `padding` と呼び分けます。margin を増やすと箱どうしの間隔が広がり、padding を増やすと枠線と中身の文字の間が広がります。`border: 2px solid black;` は「太さ 2px・実線・黒」の枠線の指定で、これを付けると余白の違いが目で見て分かります。🟡 同じ 30px でも margin と padding で見た目が全く違うことを、枠線付きの箱で確かめましょう。

```html
<style>
  .a { border: 2px solid tomato; margin: 30px; }
  .b { border: 2px solid seagreen; padding: 30px; }
</style>
```

### 箱の 4 つの層

ブラウザはすべての要素を、内側から次の 4 層でできた四角い箱として並べます。

```text
margin(外側の余白。透明)
 └ border(枠線)
    └ padding(内側の余白)
       └ 中身(文字など)
```

| 層 | 背景色は付く? | 増やすと |
|---|---|---|
| 中身 | 付く | — |
| padding | 付く(中身と同じ背景色) | 枠線と文字の間が広がる。箱そのものが大きくなる |
| border | 枠線の色 | 枠線が太くなる |
| margin | 付かない(透明) | 箱のまわりのすき間が広がり、隣の箱や画面の端から離れる |

### border の値の読み方

`border: 2px solid tomato;` は、3 つの値を半角スペースで区切って並べています。

- `2px`: 線の太さ
- `solid`: 線の種類。実線です(`dashed` にすると破線、`dotted` で点線)
- `tomato`: 線の色

### margin: 30px の意味

`margin: 30px;` のように値を 1 つだけ書くと、上・右・下・左の 4 方向すべてが 30px になります。1 方向だけ変えたいときは `margin-top`(上)、`margin-bottom`(下)、`padding-left`(左)のように方向付きのプロパティを使います。

### サンプルで起きること

サンプルの CSS は `div { border: …; background-color: lightyellow; }` で全部の div に枠線と背景を付け、2 つ目と 3 つ目だけに class で余白を足しています。

| 箱 | 見た目 |
|---|---|
| 1 つ目(余白なし) | 枠線のすぐ内側に文字がくっついている |
| 2 つ目(`margin: 30px`) | 枠線の外側に 30px のすき間ができ、箱全体が左右の端から内側に寄る。上下の箱とも離れる。枠の中の文字は 1 つ目と同じくくっついたまま |
| 3 つ目(`padding: 30px`) | 枠線の位置は左右いっぱいのままで、枠の内側に 30px の空間ができる。黄色い背景が広がり、箱が縦に太くなる |
| 4 つ目(余白なし) | 3 つ目の箱とすき間なく接している |

「背景色が広がったら padding、透明なすき間ができたら margin」と見分けられます。

## ch04 classで使い分ける(.クラス名)

同じ p タグでも「重要なお知らせだけ赤くしたい」ことがあります。そこで使うのが **class 属性**(タグに付ける自分で決めた名前)です。HTML 側で `<p class="important">` のように名前を付け、CSS 側で `.important { ... }` のように**先頭にドット**を付けたセレクタで指定すると、その名前を持つ要素だけに飾りが効きます。同じ class は何個の要素に付けてもよく、まとめて同じ見た目にできます。🔴 「タグ名セレクタは全部に効く、class セレクタは名前を付けた要素だけに効く」の違いをつかみましょう。

```html
<style>
  .important { color: red; font-weight: bold; }
</style>
<p class="important">ここだけ赤い太字</p>
<p>ふつうの段落</p>
```

### HTML 側と CSS 側の対応

| 場所 | 書き方 | ドット |
|---|---|---|
| HTML(付ける側) | `<p class="important">` | 付けない |
| CSS(選ぶ側) | `.important { … }` | 付ける |

ドットは CSS で「これは class の名前です」と示す印です。HTML の `class="…"` の中には書きません。class の名前は自分で決めてよく、半角英数字と `-`(ハイフン)を使うのが一般的です。大文字と小文字は区別されます。

1 つの要素に class を 2 つ以上付けるときは、半角スペースで区切ります。

```html
<p class="important memo">赤い太字で、背景も黄色</p>
```

### 2 つのルールが同じプロパティを指定したら

サンプルでは `p { color: dimgray; }` と `.important { color: red; }` の両方が `<p class="important">` に当たり、どちらも `color` を指定しています。結果は赤になります。

CSS には「より狙いをしぼったセレクタの指定が勝つ」という決まり(**詳細度**)があります。タグ名セレクタ `p` は「すべての p」、class セレクタ `.important` は「important と名前を付けた要素だけ」なので、class のほうが強く、`color` は red になります。ぶつかっていないプロパティは両方とも効きます。

| 要素 | 当たるルール | 結果 |
|---|---|---|
| `<p>ここはふつうの段落…</p>` | `p` | 灰色 |
| `<p class="important">…</p>` | `p` と `.important` | color はぶつかり `.important` が勝って赤。font-weight: bold も効いて太字 |
| `<p class="memo">…</p>` | `p` と `.memo` | ぶつからないので両方効く。文字は灰色、背景は黄色 |
| 4 つ目の `<p class="important">` | `p` と `.important` | 2 つ目と同じ赤い太字 |

同じ強さのセレクタどうしがぶつかったときは、CSS の中で後に書いたルールが勝ちます。

### class と id の違い

L02 ch02 で見た `id` も要素に名前を付ける属性ですが、使い方が違います。

| | class | id |
|---|---|---|
| 同じ名前を付けられる数 | 何個でも | 1 ページに 1 つだけ |
| 主な用途 | 見た目をまとめて指定する | ページ内リンクの飛び先、JavaScript から 1 つを探す |
| CSS のセレクタ | `.名前` | `#名前`(この講座ではほとんど使いません) |

## ch05 flexboxで横に並べる(display:flex)

div は本来、縦に積み重なっていきます。横に並べたいときに使うのが **flexbox**(フレックスボックス。要素を柔軟に並べる CSS のしくみ)です。並べたい要素たちの**親**(それらを囲んでいる要素)に `display: flex;` と書くと、中の子要素が横一列に並びます。あわせて `gap`(子どうしの間隔)や `justify-content`(横方向の寄せ方。`center` で中央寄せ、`space-between` で両端に広げる)もよく使います。🟡 「指定するのは並べたい子ではなく親」という点が最大のポイントです。

```html
<style>
  .row { display: flex; gap: 16px; justify-content: center; }
</style>
<div class="row">
  <div>A</div><div>B</div><div>C</div>
</div>
```

### 親と子

入れ子になったタグのうち、外側を**親要素**、そのすぐ内側を**子要素**と呼びます。

```html
<div class="row">     ← 親
  <div>A</div>        ← 子
  <div>B</div>        ← 子
  <div>C</div>        ← 子
</div>
```

L02 ch05 のとおり、div はブロック要素なので、何もしなければ A・B・C は縦に 3 行で積み重なります。親の `.row` に `display: flex;` を付けると、親は「中の子を横一列に並べる箱」に切り替わり、A B C が 1 行に並びます。子の側には何も書きません。

### よく使う指定(すべて親に書く)

| 指定 | 意味 |
|---|---|
| `display: flex;` | 子を横一列に並べる。何も足さなければ左に寄せる |
| `gap: 8px;` | 子どうしの間に 8px のすき間を空ける |
| `justify-content: center;` | 列全体を中央に寄せる |
| `justify-content: space-between;` | 最初の子を左端、最後の子を右端に置き、残りの空きを子の間に均等に配る |

ページの横幅を `[ ]` で表すと、並び方は次のようになります。

```text
display: flex だけ                 [ABC                      ]
gap: 8px を足す                    [A B C                    ]
justify-content: center            [          A B C          ]
justify-content: space-between     [A           B           C]
```

flex にした子は、横幅いっぱいには広がらず、中身の文字に合った幅に縮みます。これがブロック要素のときとの大きな違いです。

### サンプルで起きること

- `.box` は各子に枠線・背景・`padding: 16px` を付ける指定です。どの行でも同じ見た目の箱になります
- 1 行目(`.row1`): `display: flex; gap: 8px;` なので、A B C が 8px ずつ空けて左寄せで並びます
- 2 行目(`.row2`): さらに `justify-content: center;` が加わり、3 つのかたまりがページの中央に来ます
- 3 行目(`.row3`): `gap` はなく `justify-content: space-between;` なので、A が左端、C が右端、B がちょうど真ん中に置かれます

親の class を `.row1` から `.row3` に書きかえるだけで並び方が変わる、という点を確かめてください。
