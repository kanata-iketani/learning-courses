# lesson03 ch03 演習: 余白の考え方(margin と padding の違い)

starter には枠線だけ付けた「お知らせカード」が 3 枚あります。margin と padding を追加して、読みやすいカードに整えましょう。

**確認ポイント**

1. すべてのカードに `padding` を付けて、枠線と文字の間に空間ができている
2. すべてのカードに `margin` を付けて、カードどうしの間隔が空いている
3. `padding` の値を大きくすると枠線の内側が広がり、`margin` の値を大きくするとカードの間隔が広がることを、値を変えて確かめた

すべて満たせたら「✔ できた」を押してください。
