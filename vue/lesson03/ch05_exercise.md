# lesson03 ch05 演習: flexboxで横に並べる(display:flex)

starter には縦に積み重なった 3 枚のメニューカードがあります。flexbox で横一列に並べ替えましょう。

**確認ポイント**

1. 3 枚のカードを囲む親の div(`class="menu"`)に `display: flex;` を指定して、カードが横一列に並んでいる
2. `gap` を指定して、カードどうしの間にすき間が空いている
3. `justify-content: center;` を指定して、カードの列がページの中央に寄っている

すべて満たせたら「✔ できた」を押してください。
