# lesson11 ch01 演習: v-bind の基本 — 属性に data の値を割り当てる

「イベント申し込みカード」を作りましょう。starter の HTML には属性がまだ固定で書かれていません。data に用意された値を `:href`・`:placeholder`・`:disabled` で属性に割り当ててください。

**確認ポイント**

1. リンクの文字が data の `siteName` で表示され、`:href` で data の `url` が割り当てられている
2. 入力欄に data の `hint` の文字がうすく表示される
3. data の `isClosed` が `true` のときボタンが押せず、`false` に書きかえて再プレビューすると押せるようになる

すべて満たせたら「✔ できた」を押してください。
