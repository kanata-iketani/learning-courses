# lesson11 ch02 演習: :class で見た目を切り替える(オブジェクト構文)

「合格判定カード」を作りましょう。data の `isPassed` が `true` のときは `pass` class(緑・太字)、`false` のときは何も付かないように、`:class` のオブジェクト構文で宣言してください。切り替えボタン(`@click="isPassed = !isPassed"`)は starter に用意してあります。

**確認ポイント**

1. 最初は「判定待ち」の文字がふつうの黒い文字で表示されている
2. ボタンを押すと文字が緑の太字に変わる(`pass` class が付く)
3. もう一度押すと黒い文字に戻る(class の付け外しを JS で書いていないのに切り替わる)

すべて満たせたら「✔ できた」を押してください。
