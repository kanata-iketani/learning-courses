# lesson11 ch03 演習: :style と省略記法まとめ

「見出しデザイナー」を作りましょう。data の `headColor`(色)と `headSize`(数値)を `:style` のオブジェクト構文で見出しに割り当ててください。starter には色とサイズを変えるボタン(`@click`)を用意してあります。

**確認ポイント**

1. 見出しが data の `headColor` の色・`headSize` px のサイズで表示される
2. 「大きく」ボタンを押すたびに見出しが少しずつ大きくなる
3. 色のボタンを押すと見出しの色が変わる

すべて満たせたら「✔ できた」を押してください。
