# Lesson 06 JavaScript基礎3：くり返し

同じ処理をくり返す構文を学びます。Python の for / while と目的は同じですが、JavaScript の for 文は書き方が大きく違います。Vue で一覧表示を作るときの土台になる、配列のくり返し(for...of)もここで先取りします。

## ch01 for 文

決まった回数くり返すには **for 文**を使います。Python の `for i in range(5):` にあたりますが、書き方が大きく違い、`( )` の中に「初期化・続ける条件・更新」の 3 つの部品をセミコロンで区切って書きます。**i++** は「i を 1 増やす」という書き方で、`i = i + 1` と同じ意味です。カウンタの変数は値が変わっていくので `let` で宣言します。🔴 「0 から始めて、条件が成り立つ間くり返し、毎回 1 増やす」という 3 つの部品の役割を覚えましょう。

```js
// Python: for i in range(5):
for (let i = 0; i < 5; i++) {
  console.log(i);  // 0 1 2 3 4
}
```

### 3 つの部品

```js
for (let i = 0; i < 5; i++) {
```

| 部品 | 意味 | 実行されるタイミング |
|---|---|---|
| `let i = 0` | **初期化**。数を数える変数(**カウンタ**)i を 0 で作る | 最初の 1 回だけ |
| `i < 5` | **続ける条件**。true の間はくり返す | 毎回、ブロックに入る前 |
| `i++` | **更新**。i を 1 増やす | 毎回、ブロックを実行し終わった後 |

### 動く順番を追う

1. 初期化: i = 0
2. 条件 `0 < 5` は true → ブロックを実行して `0` を表示 → 更新で i = 1
3. 条件 `1 < 5` は true → `1` を表示 → i = 2
4. 同じように `2`、`3`、`4` を表示 → 最後の更新で i = 5
5. 条件 `5 < 5` は false → くり返しを終えて、`}` の次の行へ進む

| 回 | ブロックに入る前の i | 条件 `i < 5` | 表示 |
|---|---|---|---|
| 1 | 0 | true | 0 |
| 2 | 1 | true | 1 |
| 3 | 2 | true | 2 |
| 4 | 3 | true | 3 |
| 5 | 4 | true | 4 |
| — | 5 | false | (終了) |

5 は表示されません。`i < 5` は「5 未満」なので、ちょうど 5 になった時点で止まるからです。Python の `range(5)` が 0〜4 になるのと同じです。

### `i++` について

`i++` は `i = i + 1` の短い書き方で、**インクリメント**と呼びます。1 減らす `i--` もあります。Python にはない書き方です。カウンタ `i` は for の `( )` の中で `let` を使って作るので、くり返しが終わると消え、for の外では使えません。

### サンプルの残りの部分

- `for (let i = 1; i <= 3; i++)`: 1 から始め、`<=`(以下)なので 3 も含みます。テンプレートリテラルで `1回目`、`2回目`、`3回目` を表示します
- 3 つ目の for は同じく i が 1〜3 で、`i * 10` を表示するので `10`、`20`、`30` になります

実行結果(Node.js で実際に動かした出力):

```text
0
1
2
3
4
1回目
2回目
3回目
10
20
30
```

### 演習のヒント

演習の期待出力にある `×` は、かけ算の記号として文字列の中にそのまま書く文字です(計算には `*` を使います)。テンプレートリテラルの中で、表示したい文字の `×` と、計算する `${3 * i}` を書き分けます。

## ch02 while と break

**while 文**は、条件が true の間くり返す構文で、Python の while とほぼ同じ書き方です。回数が事前に決まっていないくり返しに向いています。ループの中で条件が false に近づく更新を忘れると、永遠に止まらない**無限ループ**になるので注意してください。**break** はループをその場で打ち切る命令です。`while (true)` と break を組み合わせると「条件を満たした瞬間にやめる」処理が書けます。🟡 回数が決まっているくり返しは for を優先し、while は「いつ終わるかわからない」場面で使い分けましょう。

```js
let count = 3;
while (count > 0) {
  console.log(count);
  count = count - 1;  // 更新を忘れると無限ループ！
}
```

**ループ**は「くり返し」のことです。for も while もループです。

### while の動く順番

`while (条件) { … }` は、「条件を調べる → true ならブロックを実行 → また条件を調べる」をくり返し、条件が false になったら `}` の次へ進みます。サンプルの前半を追うと次のとおりです。

| 回 | 調べる前の count | 条件 `count > 0` | 表示 | ブロックの後の count |
|---|---|---|---|---|
| 1 | 3 | true | 3 | 2 |
| 2 | 2 | true | 2 | 1 |
| 3 | 1 | true | 1 | 0 |
| — | 0 | false | (ループを抜ける) | |

ループを抜けた後に `console.log("発射！");` が実行されます。

`count = count - 1;` を書き忘れると count は 3 のまま変わらず、`count > 0` がずっと true なので、`3` を永遠に表示し続けます。この学習画面では、15 秒たっても終わらないプログラムは強制的に止められます。

### `while (true)` と break

`while (true)` は、条件が常に true なので、それだけでは終わりません。ブロックの中で `break` を実行したときにだけ抜けます。

| 回 | n | `n > 3` | 動き |
|---|---|---|---|
| 1 | 1 | false | break しない。`1` を表示して `n++` で 2 に |
| 2 | 2 | false | `2` を表示して 3 に |
| 3 | 3 | false | `3` を表示して 4 に |
| 4 | 4 | true | `break` でループを打ち切る |

`n++` は L06 ch01 で見た「n を 1 増やす」書き方です。break はループの中のどこに書いてもよく、実行された瞬間に残りの行を飛ばしてループの外へ出ます。

実行結果(Node.js で実際に動かした出力):

```text
3
2
1
発射！
1
2
3
```

### 演習のヒント

「足す数 i を 1 増やす → total に i を足す → total が 20 を超えたら break」の順でくり返すと、次のように進みます。

| i | total |
|---|---|
| 1 | 1 |
| 2 | 3 |
| 3 | 6 |
| 4 | 10 |
| 5 | 15 |
| 6 | 21 ← ここで初めて 20 を超えるので break |

break の後、ループの外で `i` と `total` を表示します。i と total は while の前に `let` で作ってあるので、ループを抜けた後でも使えます。

## ch03 for...of 〜配列をくり返す

**配列**(複数の値を順番に並べて入れる箱。次のレッスンで詳しく学びます)は `[ ]` で作ります。配列の中身を先頭から順に取り出してくり返すのが **for...of** です。Python の `for fruit in fruits:` と同じ感覚で書けます。カウンタの番号が不要なら、for 文より for...of のほうが読みやすくおすすめです。取り出した変数はループのたびに新しく作られるので `const` で宣言できます。Vue で一覧表示に使う `v-for` もこの発想です。🔴 「配列 of ではなく、変数 of 配列」という語順に注意しましょう。

```js
const fruits = ["りんご", "みかん"];
for (const fruit of fruits) {
  console.log(fruit);  // Python: for fruit in fruits:
}
```

### 1 行の読み方

`for (const fruit of fruits) {` は「配列 `fruits` から 1 つずつ取り出して `fruit` に入れ、ブロックを実行する」という意味です。

| 部品 | 意味 |
|---|---|
| `const fruit` | 取り出した要素を入れる変数。名前は自由ですが、配列名の単数形にすると読みやすくなります |
| `of` | 「〜から取り出す」 |
| `fruits` | くり返す配列 |

`["りんご", "みかん", "ぶどう"]` なら、1 回目は fruit が `"りんご"`、2 回目は `"みかん"`、3 回目は `"ぶどう"` になり、要素がなくなったら終わります。L06 ch01 の for 文のような「初期化・条件・更新」は書かなくてかまいません。

### 合計を求める部分を追う

```js
const prices = [100, 250, 80];
let total = 0;
for (const price of prices) {
  total = total + price;
}
console.log(total);  // 430
```

| 回 | price | 計算 | ブロックの後の total |
|---|---|---|---|
| 始める前 | — | — | 0 |
| 1 | 100 | 0 + 100 | 100 |
| 2 | 250 | 100 + 250 | 350 |
| 3 | 80 | 350 + 80 | 430 |

`total` はくり返しの中で値が変わるので `let`、`price` は毎回新しく作られて途中で変わらないので `const` です。`console.log(total)` はループの外(`}` の後)にあるので、合計が出来上がった後に 1 回だけ表示されます。

実行結果(Node.js で実際に動かした出力):

```text
りんご
みかん
ぶどう
430
```

### of と in を間違えない

JavaScript には `for (const x in 配列)` という書き方もありますが、これは要素ではなく番号(`"0"`、`"1"`、…)を取り出します。Python の `in` に引きずられて `in` と書くと、`りんご` の代わりに `0` が表示されます。配列の要素を取り出すときは必ず `of` を使います。
