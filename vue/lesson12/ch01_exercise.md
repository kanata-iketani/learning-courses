# lesson12 ch01 演習: @click と methods

「あいさつ切り替えアプリ」を作りましょう。ボタンを押すと、表示中のメッセージが「おはようございます！」に変わるようにしてください。`methods` に `sayMorning` メソッドを定義し、`this.message` を書きかえ、ボタンの `@click` から呼び出します。

**確認ポイント**

1. 最初は「こんにちは」と表示されている
2. ボタンを押すと表示が「おはようございます！」に変わる
3. `@click` には式ではなくメソッド名(`sayMorning`)が書かれており、処理は `methods` の中にある

すべて満たせたら「✔ できた」を押してください。
