# Lesson 12 イベント処理（v-on）

クリックなどのイベントに反応する v-on(省略形は @)を学びます。処理は methods にメソッドとしてまとめ、this でデータを書きかえます。仕上げに、増減とリセットができるカウンターアプリを完成させます。

## ch01 @click と methods

クリックに反応させるには **v-on**(ブイオン)ディレクティブを使います。`v-on:click="処理"` の省略形が `@click="処理"` です。短い処理は直接書けますが、ふつうは設定オブジェクトの **methods**(アプリが実行できる関数をまとめる場所)に**メソッド**(オブジェクトに属する関数)を定義し、`@click="メソッド名"` で呼びます。data の値には `this.count` のように **this**(動いているアプリ自身を指すことば)を付けてアクセスします。🔴 「@click → methods → this.データ名」の流れを手で覚えましょう。

```js
createApp({
  data() { return { message: "こんにちは" }; },
  methods: {
    change() {
      this.message = "クリックされました！";  // this を忘れずに
    }
  }
}).mount("#app");
```

## ch02 メソッドに引数を渡す

似たボタンを何個も作るとき、ボタンごとにメソッドを用意するのは大変です。`@click="greet('おはよう')"` のように**引数**(関数に渡す値)付きでメソッドを呼べば、1 つのメソッドを使い回せます。テンプレート内の文字列は、属性の `"` と区別するためシングルクォート `'` で囲むのが定番です。🔴 「ボタンが 3 つあってもメソッドは 1 つ」という書き方に慣れましょう。

```html
<button @click="greet('おはよう')">朝</button>
<button @click="greet('こんばんは')">夜</button>
```

```js
methods: {
  greet(word) {
    this.message = word + "、いけたにさん！";
  }
}
```

## ch03 カウンターアプリを作る(増減・リセット)

ここまでの知識を組み合わせて、レッスンの総仕上げにカウンターアプリを作ります。使うのは、data(状態 `count`)、methods(`increment`・`decrement`・`reset`)、`@click`、`{{ }}`、そして前のレッスンの `:class`(数に応じた色分け)です。🔴 このアプリの形、つまり「状態は data に 1 か所、操作は methods、見た目はテンプレートに宣言」は、この先どんな Vue アプリを作るときも変わらない基本形です。サンプルを動かしてから、自分の手で組み立ててみましょう。

```js
methods: {
  increment() { this.count++; },
  decrement() { this.count--; },
  reset()     { this.count = 0; }
}
```
