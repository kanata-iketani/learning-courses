# Lesson 12 イベント処理（v-on）

クリックなどのイベントに反応する v-on(省略形は @)を学びます。処理は methods にメソッドとしてまとめ、this でデータを書きかえます。仕上げに、増減とリセットができるカウンターアプリを完成させます。

## ch01 @click と methods

クリックに反応させるには **v-on**(ブイオン)ディレクティブを使います。`v-on:click="処理"` の省略形が `@click="処理"` です。短い処理は直接書けますが、ふつうは設定オブジェクトの **methods**(アプリが実行できる関数をまとめる場所)に**メソッド**(オブジェクトに属する関数)を定義し、`@click="メソッド名"` で呼びます。data の値には `this.count` のように **this**(動いているアプリ自身を指すことば)を付けてアクセスします。🔴 「@click → methods → this.データ名」の流れを手で覚えましょう。

```js
createApp({
  data() { return { message: "こんにちは" }; },
  methods: {
    change() {
      this.message = "クリックされました！";  // this を忘れずに
    }
  }
}).mount("#app");
```

### 1 行ずつの意味

- `methods: { ... }`: 設定オブジェクトに methods というキーを足し、その値のオブジェクトの中に関数を並べます。data との間はカンマで区切ります
- `change() { ... }`: メソッドの定義です。L10 ch02 で見た `data() { }` と同じ省略形で、`change: function() { ... }` と同じ意味です。メソッドを複数書くときはカンマで区切ります
- `this.message = "..."`: data の message を書きかえます。書きかえると、`{{ message }}` を表示している場所が自動で新しい文字になります
- HTML 側の `<button @click="change">`: クリックされたら change を呼ぶ、という指示です。`()` を付けずにメソッド名だけ書けば、Vue がクリック時に呼びます(`@click="change()"` と書いても同じです)

### this が要る場所・要らない場所

| 書く場所 | data の message の書き方 |
|---|---|
| テンプレート(`{{ }}` や `@click="..."` の中) | `message` |
| methods の中 | `this.message` |

methods の中で `this` を忘れて `message = "..."` と書くと、「message という変数はない」というエラーになり、画面は何も変わりません。エラーの内容は開発者ツールのコンソール(L1 ch03)で見られます。また、methods の関数をアロー関数(`change: () => { }`)で書くと this がアプリを指さなくなるので、methods は `change() { }` の形で書きます。

### サンプルを 1 行ずつ

- `<button @click="addLike">`: クリックで addLike を呼びます
- `{{ likes >= 10 ? "🎉 大人気！" : "" }}`: L10 ch03 の三項演算子です。10 以上のときだけ文字が出ます
- `addLike() { this.likes = this.likes + 1; }`: likes を 1 増やします
- `reset() { this.likes = 0; }`: likes を 0 に戻します

### クリックしたときに起きること

| 順番 | 起きること |
|---|---|
| 1 | ボタンがクリックされる |
| 2 | Vue が `addLike` を呼ぶ |
| 3 | `this.likes` が 0 → 1 になる |
| 4 | Vue が `{{ likes }}` を表示している場所を「1 いいね」に書きかえる |

10 回押すと「10 いいね 🎉 大人気！」になり、リセットで「0 いいね」に戻ります。

## ch02 メソッドに引数を渡す

似たボタンを何個も作るとき、ボタンごとにメソッドを用意するのは大変です。`@click="greet('おはよう')"` のように**引数**(関数に渡す値)付きでメソッドを呼べば、1 つのメソッドを使い回せます。テンプレート内の文字列は、属性の `"` と区別するためシングルクォート `'` で囲むのが定番です。🔴 「ボタンが 3 つあってもメソッドは 1 つ」という書き方に慣れましょう。

```html
<button @click="greet('おはよう')">朝</button>
<button @click="greet('こんばんは')">夜</button>
```

```js
methods: {
  greet(word) {
    this.message = word + "、いけたにさん！";
  }
}
```

### 1 行ずつの意味

- `@click="greet('おはよう')"`: クリックされたら greet を呼び、引数として文字列 `'おはよう'` を渡します。`@click="greet"` と違い、`()` の中に渡す値を書きます
- `greet(word) { ... }`: 受け取った値が引数 `word` に入ります(L8 ch02 で見た引数)。どのボタンから呼ばれたかで、word の中身が変わります
- `this.message = word + "、いけたにさん！"`: 受け取った言葉を使って message を書きかえます

### どのボタンで何が表示されるか

| 押したボタン | word に入る値 | 表示 |
|---|---|---|
| 朝 | おはよう | おはよう、いけたにさん！ |
| 夜 | こんばんは | こんばんは、いけたにさん！ |

### サンプルのもう 1 つの例

- `<h1 :style="{ color: color }">`: L11 ch03 の :style です。キーの color は CSS のプロパティ、値の color は data の名前です
- `@click="setColor('steelblue')"`: 色の名前を引数で渡し、`setColor(c) { this.color = c; }` で data の color を書きかえます。見出しの色がすぐ変わります

### 引数を 2 つ渡すとき

演習の `order(name, price)` のように引数が 2 つのときは、カンマで区切って渡します。渡した順番に引数へ入ります。

| 呼び出し | name | price |
|---|---|---|
| `order('ラーメン', 900)` | ラーメン | 900 |
| `order('ぎょうざ', 400)` | ぎょうざ | 400 |

数は `900` のようにクォートなしで書きます。表示する文字は `name + "(" + price + "円)を注文しました"` のように `+` でつなぐか、L4 ch04 のテンプレートリテラル(`` `${name}(${price}円)を注文しました` ``)で作ります。

## ch03 カウンターアプリを作る(増減・リセット)

ここまでの知識を組み合わせて、レッスンの総仕上げにカウンターアプリを作ります。使うのは、data(状態 `count`)、methods(`increment`・`decrement`・`reset`)、`@click`、`{{ }}`、そして L11 ch02 の `:class`(数に応じた色分け)です。🔴 このアプリの形、つまり「状態は data に 1 か所、操作は methods、見た目はテンプレートに宣言」は、この先どんな Vue アプリを作るときも変わらない基本形です。サンプルを動かしてから、自分の手で組み立ててみましょう。

```js
methods: {
  increment() { this.count++; },
  decrement() { this.count--; },
  reset()     { this.count = 0; }
}
```

### 1 行ずつの意味

- `increment() { this.count++; }`: count を 1 増やします(`++` は L6 で見た「1 増やす」)
- `decrement() { this.count--; }`: `--` は「1 減らす」です
- `reset() { this.count = 0; }`: 0 に戻します
- 3 つのメソッドの間はカンマで区切ります。`{ }` の中が 1 行だけなら、このように 1 行にまとめて書いてもかまいません

### サンプルのテンプレート

- `<p class="num" :class="{ minus: count < 0 }">{{ count }}</p>`: いつも付く class `num` と、条件で付く class `minus` を両方書いています。`count < 0` は「count が 0 より小さいか」を true / false で返す式です(L5 の比較)
- `<button @click="decrement">−1</button>` など: それぞれのボタンから methods のメソッドを呼びます

### 画面はどう変わるか

| 操作 | count | 付く class | 見た目 |
|---|---|---|---|
| 開いた直後 | 0 | num | 0(大きな黒い文字) |
| −1 | -1 | num minus | -1(大きな赤い文字) |
| +1 を 2 回 | 1 | num | 1(黒に戻る) |
| リセット | 0 | num | 0 |

### 演習のヒント

- data の名前は `tickets` です。methods の中では `this.tickets` と書きます
- リセットは 0 ではなく 10 に戻します
- 「売り切れ」の表示は `{{ tickets === 0 ? "売り切れ" : "" }}` のように三項演算子(L10 ch03)で書けます。L11 ch01 の `:disabled="tickets === 0"` を使えば、0 枚のときに「1枚売る」を押せなくすることもできます
