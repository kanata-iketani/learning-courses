# lesson15 ch03 演習: コンポーネント：画面を部品として定義する

「いいねボタン」コンポーネントを作りましょう。押すたびに ♥ の数が増えるボタンを `like-button` という名前で登録し、3 つ並べます。

**確認ポイント**

1. `app.component("like-button", { ... })` で登録した自作タグが 3 つ表示されている
2. どれか 1 つを押しても、ほかのボタンの数は増えない(部品ごとに独立して数える)
3. タグ名にハイフンが入っている(`<like-button>` のような名前)

すべて満たせたら「✔ できた」を押してください。
