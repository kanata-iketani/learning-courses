# lesson15 ch04 演習: props：親から子へデータを渡す

本の一覧ページを作りましょう。`book-card` コンポーネントに props でタイトルと著者を渡し、data の配列 `books` から v-for で 3 冊分を表示します。

**確認ポイント**

1. `props: ["title", "author"]` を宣言した book-card コンポーネントが登録されている
2. data の配列 `books` の 3 冊が、v-for + `:title="book.title"` の形で 3 枚のカードとして表示される
3. 配列のどれか 1 冊のタイトルを書きかえて再プレビューすると、そのカードだけ表示が変わる

すべて満たせたら「✔ できた」を押してください。
