# lesson15 ch01 演習: computed：データから自動計算される値

SNS 風の文字数カウンタを作りましょう。メッセージ入力欄の下に「いま何文字か」と「あと何文字書けるか(140 文字まで)」を表示します。どちらも methods ではなく computed で作ってください。

**確認ポイント**

1. 入力欄に文字を打つたびに「いま ○ 文字」が自動で増減する
2. 「あと ○ 文字書けます」が computed(`remaining`)で計算され、140 から入力文字数を引いた値になっている
3. 表示側は `{{ remaining }}` のように `()` なしで書けている(methods 呼び出しではない)

すべて満たせたら「✔ できた」を押してください。
