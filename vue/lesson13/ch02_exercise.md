# lesson13 ch02 演習: checkbox と select で v-model を使う

簡単なアンケートフォームを作りましょう。starter を編集して、チェックボックスとセレクトボックスを v-model で data と同期させてください。

**確認ポイント**

1. 「メルマガを受け取る」のチェックを付け外しすると、下の表示が `true` / `false` に切り替わる
2. 好きな季節のセレクトボックスに選択肢を 3 つ以上用意し、選び直すと下の文章が即座に変わる
3. ページを開いた時点で、data の初期値(`season: "春"`)がセレクトボックスに選ばれた状態になっている

すべて満たせたら「✔ できた」を押してください。
