# lesson13 ch01 演習: v-model の基本：入力欄と data が同期する

自己紹介カードを作りましょう。starter には「ニックネーム」の入力欄だけがあります。「ひとこと」の入力欄を追加して、2 つの入力が下の紹介文へ打った瞬間に反映されるようにしてください。

**確認ポイント**

1. ニックネームの入力欄に文字を打つと、打った瞬間に下の紹介文が変わる
2. 「ひとこと」の入力欄を自分で追加し(data には `comment` を用意)、同じように即座に紹介文へ反映される
3. data の初期値(`nickname: "ゲスト"`)が、ページを開いた時点で入力欄の中に表示されている

すべて満たせたら「✔ できた」を押してください。
